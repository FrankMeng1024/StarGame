# PRD.md — 星捕少女 (StarCatcher)

**Version**: 1.0 (Sprint 0)
**Status**: Confirmed by user

---

## Product Vision
一款面向全年龄的休闲教育游戏。玩家控制一个小女孩，在新西兰绝美夜空背景下，用可伸缩网兜抓取天空中的星座星星，同时躲避宇宙垃圾。每完成一个星座，解锁该星座的故事与真实照片，逐渐建立对星座知识的感情。

## Feature Specifications

### F-001: 封面与主菜单
- 全屏夜空背景（含粒子星空动画）
- 游戏标题"星捕少女"（金色发光效果）
- 两个主入口按钮：[挑战关卡] [星座展厅]
- 背景音乐自动播放（可静音）

### F-002: 关卡选择
- 30个关卡卡片，6列×5行网格布局
- 每张卡片显示：星座中文名 + 英文名 + 星座图标符号 + 难度（1-5星）
- 已解锁：显示通关状态（金星评级）；未解锁：灰色锁定
- 第一关默认解锁；完成一关解锁下一关
- 背景随当前最高解锁关卡所属场景变化

### F-003: 核心游戏玩法
- **场景**：Canvas全屏，背景为对应场景图片，天空区域布置星星和垃圾
- **角色**：小女孩站在屏幕底部中央，持网兜杆
- **网兜机制**：
  - 网兜自动左右摆动（正弦摆动，摆幅约±60°）
  - 点击鼠标/空格键：网兜沿当前角度向上伸长
  - 伸长时碰到第一个物体：立即抓取，开始收回
  - 未碰到任何物体：伸到最长后自动收回
  - 收回后继续摆动
- **星星**：
  - 按该星座真实星图坐标分布在天空中
  - 大小按视觉星等映射（1等星最大，6等星最小）
  - 颜色按星型（蓝白/金黄/橙红）
  - 慢速闪烁动画
  - 抓到：金色粒子爆发，计入已抓数量，星星消失
- **宇宙垃圾**：
  - 分布在天空各处，遮挡星星
  - 类型：陨石、卫星碎片、火箭推进器、太空碎布
  - 自转动画
  - 抓到：网兜收回，不计星星，损失0.5-1秒时间惩罚
- **胜利条件**：在时间内抓完该星座所有星星
- **失败条件**：时间归零时未抓完所有星星
- **HUD**：关卡名、倒计时（紧张时变红）、已抓/总数

### F-004: 时间与金币
- 每关有固定时限（难度1: 90秒，难度2: 80秒，难度3: 70秒，难度4: 60秒，难度5: 50秒）
- 通关后：剩余秒数 × 10 = 金币奖励
- 失败：无金币奖励
- 金币累计存储，用于购买道具

### F-005: 道具系统
共8种道具，关卡结束后弹出商店：

| 道具 | 效果 | 价格 |
|---|---|---|
| 网兜加速 | 本关网兜伸缩速度+50% | 50金币 |
| 磁力星引 | 本关星星主动向网兜靠近（50px范围内） | 80金币 |
| 宇宙炸弹 | 点击使用，摧毁屏幕内所有垃圾 | 100金币 |
| 时间延长 | +20秒到当前关卡计时 | 60金币 |
| 缩小垃圾 | 本关所有垃圾缩小至50%大小 | 40金币 |
| 双倍金币 | 本关金币奖励×2 | 30金币 |
| 星图揭示 | 显示本关星座连线提示（半透明） | 20金币 |
| 宇航员手套 | 抓到垃圾时不损失时间 | 70金币 |

道具分为：
- **消耗型**（炸弹、时间延长）：购买后关卡内手动激活，用完即止
- **持续型**（其余）：本关全程生效

### F-006: 通关体验
抓完所有星星后：
1. 画面暂停，粒子庆祝效果（金色星光雨）
2. 星座连线动画：天空中该星座的星星逐一用金线相连，形成星座图案
3. 结算卡：分数、时间、获得金币、星评（1-3星）
4. 星座介绍展示：卡片展开动画，显示该星座的神话故事（200-300字）
5. 按钮：[下一关] [去商店] [返回选关]

### F-007: 星座展厅
- 入口从主菜单进入
- 网格展示30个星座卡片
- 已解锁：彩色展示，可点击进入
- 未解锁：轮廓剪影 + "未探索"
- 星座详情页：
  - 图片轮播（5-10张真实图片，包含：星空实拍、星座连线图、神话插图等）
  - 基本信息：中文名、英文名、所属天区、最佳观测时间、主要星星
  - 神话故事（完整版，500-800字）
  - 返回展厅按钮

### F-008: 存档系统
localStorage 存储：
- 每关最高分和星评
- 已解锁关卡列表
- 金币余额
- 已购买/持有道具
- 展厅已解锁星座

## Non-Functional Requirements
- 60fps 游戏帧率
- 初始加载 < 2秒（本地资源）
- 支持 1280×720 及以上分辨率
- Chrome / Firefox / Edge 最新版兼容
- 无后端，无网络请求（纯本地运行）
