# STORY-00281: 关卡选择卡片重设计

**Epic**: 视觉/UX对标Web版
**Sprint**: Sprint 23-mini
**Sprint Goal**: 全面对标Web版视觉体验
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the level select cards to look refined and well-proportioned, so that navigation feels like a premium game experience.

## Expected Result
Cards show constellation icon + smaller level number + name at legible size. Landscape uses 5 columns (wider cards). Score stars in corner badge. Cards have gradient border.

## Acceptance Criteria
- [ ] COLS in landscape changed from 6 to 5 (cards ~128px wide at H=375)
- [ ] Level number font reduced: `Math.round(w * 0.28)` (was 0.40)
- [ ] Constellation icon (c.icon) drawn above number at `Math.round(w * 0.22)` font size, y offset h*0.22
- [ ] Level number y offset adjusted to h*0.45 (was 0.38) to accommodate icon above
- [ ] Name font: `Math.max(8, Math.min(10, Math.round(w * 0.16)))` (was min 9 max 12)
- [ ] Score stars moved to bottom-right corner at x+w-4, y+h-4 (anchor right, small font w*0.12)
- [ ] Unlocked card border: gold gradient strokeStyle top-to-bottom (rgba(255,200,50,0.7) → rgba(120,50,200,0.5))
- [ ] Difficulty dot max radius reduced from 3 to 2.5
- [ ] All 30 level cards visible and scrollable without layout breakage at H=375 landscape

## Dependencies
None

## Notes
At H=375 landscape: W=667, COLS=5. usableW ≈ 667 - 24 - (4*8) = 611px. CARD_W = floor(611/5) = 122px. Icon at 0.22*122 ≈ 26px font. Number at 0.28*122 ≈ 34px font. Fits well.
Web reference: level card shows icon emoji (e.g. ♓ Pisces) + number + name + difficulty bar. Mini doesn't have difficulty bar (uses dots instead) — keep dots.
