# STORY-00279: 网兜物理手感修复

**Epic**: 视觉/UX对标Web版
**Sprint**: Sprint 23-mini
**Sprint Goal**: 全面对标Web版视觉体验
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want net extension to feel slower and more skillful, and hitting debris to feel physically real (like the net grabs it and gets weighed down), so that the game has satisfying physics.

## Expected Result
- Net extends at ~333px/s (down from 540px/s) — player can judge angle with skill
- Hitting debris causes slow retract (net is "holding" the debris) not instant bounce
- Time penalty (-1s) unchanged

## Acceptance Criteria
- [ ] NET_SPEED constant changed from 9 to 5 in `miniprogram/js/screens/game.js`
- [ ] Debris collision sets `_caughtDebris = d` instead of just triggering retract
- [ ] During retract, if `_caughtDebris` is set: retract speed = `NET_SPEED * 0.25 * scale` (slow drag)
- [ ] When retract completes (netLen ≤ 0): `_caughtDebris` cleared, time penalty -1s applied (unchanged), _netState = 'swing'
- [ ] Glove item still blocks the time penalty (unchanged)
- [ ] Screen shake and SFX on debris hit unchanged
- [ ] All 30 levels remain completable with reduced net speed (top stars still reachable at _netMaxLen = H*0.88 = 330px)

## Dependencies
None

## Notes
Current NET_SPEED=9 at scale=1 (60fps): 9px/frame × 60 = 540px/s.
New NET_SPEED=5: 5×60 = 300px/s. At H=375, netMaxLen=330px → extends in 1.1s. Much more deliberate.
Debris retract: slow = 5 * 0.25 = 1.25px/frame. netLen=330px / 1.25 = 264 frames = 4.4s drag. 
Adjust: NET_SPEED*0.30 = 1.5px/frame → 220 frames = 3.7s. Use 0.30 for slightly faster.
New variable: `let _caughtDebris = null;` at module level. Clear in _cleanup() and showGame().
