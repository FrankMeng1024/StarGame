## Description
As a player, I want the girl character to look beautiful and detailed, comparable to the web version's SVG sprite, so that the character feels like the hero of the game.

## Expected Result
Character is ~130px tall (was 78px), with large anime eyes, flowing hair, gradient dress, both arms visible, detailed hat, and a magical aura glow. Visually comparable to a 2D anime illustration.
