# STORY-00280: 主菜单按钮尺寸优化

**Epic**: 视觉/UX对标Web版
**Sprint**: Sprint 23-mini
**Sprint Goal**: 全面对标Web版视觉体验
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the home screen buttons to be properly sized and non-overlapping, so that the layout feels elegant and spacious.

## Expected Result
Title, constellation, and buttons all fit in the landscape right panel without crowding or overlap. Buttons are smaller and more elegant.

## Acceptance Criteria
- [ ] Landscape BH reduced: `Math.max(30, Math.min(36, (H - G.SAFE_TOP - G.SAFE_BOTTOM - 120) / 3))`
- [ ] Landscape GAP reduced from 10 to 8
- [ ] Title y-position moved to H*0.14, subtitle to H*0.14 + 28 (prevents overlap with tall constellation)
- [ ] Right panel width: `rightW = W - rightX - G.SAFE_RIGHT - 20` (was -14), prevents right-edge crowding
- [ ] Achievement button uses _drawMenuButton (same style as main buttons, not drawButton), fontSize=11, primary=false
- [ ] Portrait BH reduced from 48 to 40, GAP from 14 to 10
- [ ] No visual overlap between title, constellation stars, buttons, or mute button at H=375 landscape
- [ ] All 4 buttons (3 main + achievement) fully visible and tappable without scrolling

## Dependencies
None

## Notes
Current landscape layout: rightX = W*0.54 + G.SAFE_LEFT*0.3 ≈ 360. rightW = W - 360 - G.SAFE_RIGHT - 14 = 667 - 360 - 0 - 14 = 293px (if SAFE_RIGHT=0). BH range 36-44. 3 buttons + gap: 3*44 + 2*10 = 152px. + achievement 28px + 4 = 184px. Total from startY. startY = H/2 - 184/2 + 16 = 203. EndY = 203+184=387 > H=375. Buttons clip at bottom. Fix: smaller BH and better startY calculation.
