# STORY-00276: 开场动画强制播放修复

**Epic**: 视觉/UX对标Web版
**Sprint**: Sprint 23-mini
**Sprint Goal**: 全面对标Web版视觉体验
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see the intro animation every time I fresh-launch the game, so that the opening experience feels complete and cinematic.

## Expected Result
Every fresh game launch (cold start via QR code or DevTools) shows the intro animation. In-app navigation back to menu bypasses intro (correct existing behavior).

## Acceptance Criteria
- [ ] `miniprogram/game.js` boot() always sets startScreen = 'intro' — the `wx.getStorageSync('__initScreen')` line is removed
- [ ] Fresh launch triggers intro → menu navigation automatically after animation completes
- [ ] In-app navigate('menu') calls from game/gallery/shop go directly to menu (no intro re-trigger)
- [ ] No `__initScreen` key written anywhere in the codebase that would suppress intro

## Dependencies
None

## Notes
Root cause: line 85 in game.js reads `wx.getStorageSync('__initScreen') || 'intro'`. If this key was ever set to 'menu' by a previous session, intro is suppressed indefinitely. Fix: remove that line, hardcode startScreen = 'intro'.
