# STORY-00422: 图鉴蜂巢边线可见性提升

**Epic**: E-013 图鉴与视觉打磨
**Sprint**: Sprint 80-mini
**Sprint Goal**: 通过庆典动画、个人最佳记录、前期难度微调、图鉴连线可见性提升和选关星数汇总，全面提升游戏反馈感和可读性
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player browsing the gallery, I want the honeycomb connecting lines between unlocked constellations to be more visible, so that I can clearly see the network structure linking constellations within each group.

## Expected Result
The unlocked hex edge lines in the gallery screen increase from alpha 0.18 to 0.32, making the honeycomb structure noticeably more visible while still remaining subtle and not overpowering the node icons.

## Acceptance Criteria
- [ ] In gallery.js `_drawHexEdges()`, the unlocked edge strokeStyle changes from `'rgba(160,120,255,0.18)'` to `'rgba(160,120,255,0.32)'` (line ~439)
- [ ] Locked edge strokeStyle `'rgba(80,70,120,0.10)'` remains UNCHANGED
- [ ] Endpoint dots fillStyle `'rgba(180,140,255,0.25)'` remains UNCHANGED
- [ ] The hex edges are visually distinguishable against the dark background on both 375x667 and 414x896 viewports
- [ ] The edges do not visually compete with or overpower the node icons (subjective but edges should feel like connecting tissue, not primary elements)
- [ ] No console errors after the change
- [ ] Gallery scrolling between groups remains smooth (no rendering performance impact)

## Dependencies
- Depends on: none
- Blocks: none

## Notes
- gallery.js line 439: `ctx.strokeStyle = 'rgba(160,120,255,0.18)';` → change to `'rgba(160,120,255,0.32)'`
- This is a single-value change in one line. Risk is minimal.
- The 0.32 value was chosen as a balance: 0.18 was nearly invisible on many devices, 0.32 should be clearly visible without being heavy. If QA or UX finds it too strong or too weak, the value can be adjusted in a follow-up.
