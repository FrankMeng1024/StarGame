## Description
As a player on the level select screen, I want to see how many stars I have earned in the current galaxy group out of the maximum possible, so that I can gauge my completion progress per group and know which groups need more attention.

## Expected Result
Below the group name on the level select screen, a line reads "本星座已获 N/M ★" where N is the total stars earned across the 6 levels in the current group and M is the maximum possible (6 levels x 3 stars = 18). The text crossfades with the group name when swiping between groups.

## Acceptance Criteria
- [ ] Below the group name (currently rendered at `groupY = G.SAFE_TOP + 58`), a summary line displays "本星座已获 N/M ★" where N = sum of stars for levels in the current group, M = 18 (6 levels x 3 stars max)
- [ ] N is calculated by iterating the 6 levels in the group (indices `groupIdx*6` through `groupIdx*6+5`), calling `state.getScore(idx)` for each, and summing `score.stars` (0 if score is null)
- [ ] M is always 18 (hardcoded: 6 levels per group, 3 stars max each)
- [ ] The summary text is positioned approximately 16-18px below the group name, centered horizontally
- [ ] Text style: font size 11-12px, color matches the group's color but at 60% alpha (e.g., `group.color` with alpha 0.6), uses calligraphy font if loaded (Ma Shan Zheng)
- [ ] The "★" character renders in gold (#FFD700) when N > 0, in gray (rgba(200,200,220,0.4)) when N === 0
- [ ] The summary line participates in the existing crossfade animation during group swipe (same `nameAlpha`/`pendingAlpha` logic as the group name, lines 283-308 in levels.js)
- [ ] When swiping to a new group, the summary updates to reflect the pending group's star totals (using `_pendingGroup` index)
- [ ] If all 18 stars are earned for a group (N === M), the text color shifts to full gold (#FFD700) as a "complete" indicator
- [ ] Viewport: summary text is legible and does not overlap with nodes on 375x667 (smallest target). The node area clip starts at `padTop = G.SAFE_TOP + 72` — summary must fit between `groupY + 15` and `padTop`
- [ ] No console errors after the change
