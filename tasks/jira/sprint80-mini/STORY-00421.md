# STORY-00421: 前5关难度微调（时间+20s）

**Epic**: E-014 游戏性体验提升
**Sprint**: Sprint 80-mini
**Sprint Goal**: 通过庆典动画、个人最佳记录、前期难度微调、图鉴连线可见性提升和选关星数汇总，全面提升游戏反馈感和可读性
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new player, I want the first 5 levels to be more forgiving with extra time, so that I can learn the game mechanics without frustrating time-outs.

## Expected Result
Levels 0-4 (the first 5 levels) each receive +20 seconds of base time. This is implemented by changing the diffMap values for difficulty 1 and 2 (the only difficulties used by levels 0-4). The difficulty levels used by levels 5-29 that share difficulty 1 or 2 will also receive the +20s — this is acceptable as the intent is to make the early-to-mid game more relaxed.

## Acceptance Criteria
- [ ] `diffMap` in game.js (currently `[120, 100, 90, 80, 70]`) is changed to `[140, 120, 90, 80, 70]` — difficulty 1 goes from 120s to 140s, difficulty 2 goes from 100s to 120s
- [ ] Level 0 (猎户座, difficulty 1): base time = 140s (was 120s). With starCount=9, bonus = max(0,(9-7)*5) = 10s, total = 150s
- [ ] Level 1 (大熊座, difficulty 1): base time = 140s (was 120s). Verify via `_timeLeft` at level start
- [ ] Level 2 (天蝎座, difficulty 2): base time = 120s (was 100s). Verify via `_timeLeft` at level start
- [ ] Level 3 (狮子座, difficulty 2): base time = 120s (was 100s). Verify via `_timeLeft` at level start
- [ ] Level 4 (白羊座, difficulty 1): base time = 140s (was 120s). Verify via `_timeLeft` at level start
- [ ] Levels with difficulty 3, 4, 5 (diffMap indices 2-4) are UNCHANGED: 90s, 80s, 70s respectively
- [ ] The bonus formula `Math.max(0, (starCount - 7) * 5)` is NOT modified — only the diffMap array changes
- [ ] No other game mechanics (combo, scoring, star rating thresholds) are affected
- [ ] Viewport: N/A (logic-only change, no visual impact)
