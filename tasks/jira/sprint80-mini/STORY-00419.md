# STORY-00419: 抓完所有星星瞬间庆典动画

**Epic**: E-014 游戏性体验提升
**Sprint**: Sprint 80-mini
**Sprint Goal**: 通过庆典动画、个人最佳记录、前期难度微调、图鉴连线可见性提升和选关星数汇总，全面提升游戏反馈感和可读性
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a special celebration burst the instant I catch the final star (all stars caught), so that I feel the accomplishment of a perfect catch before the result card appears.

## Expected Result
When the last star is caught and `_caught === _total`, a 500ms celebration burst plays before the existing celebrate→starflash→linedraw→linger→result flow continues. The burst includes a radial golden particle explosion centered on the catch point and a "已全部抓住！" text overlay that fades out. After the burst, the normal victory flow resumes unchanged.

## Acceptance Criteria
- [ ] When `_caught === _total` at victory trigger, a new sub-phase "allcaught_burst" (or equivalent) runs for 500ms before `_phase = 'celebrate'`
- [ ] During the burst: 20-30 golden particles radiate outward from the last catch position (`_netHeadX`, `_netHeadY`) with gravity and fade
- [ ] During the burst: "已全部抓住！" text displays centered on screen in calligraphy font (Ma Shan Zheng if loaded, fallback serif), white with gold glow, font size 22-26px, alpha fades from 1.0 to 0.0 over the 500ms
- [ ] After burst completes (500ms elapsed), flow transitions to the existing `_phase = 'celebrate'` with `_celebrateTimer = 1.5` — the existing 40-particle victory celebration and starflash→linedraw→linger→result chain is NOT altered
- [ ] When `_caught < _total` at victory (partial catch), the burst does NOT trigger — flow goes directly to `_phase = 'celebrate'` as before
- [ ] When victory is false (time ran out), neither burst nor celebrate trigger — flow goes directly to `_phase = 'result'` as before
- [ ] Tapping during the burst skips to `_phase = 'result'` (consistent with existing tap-to-skip behavior for celebrate/starflash/linedraw/linger)
- [ ] The burst does not cause any console errors or frame rate drop below 30fps on WeChat DevTools simulator
- [ ] Viewport: burst renders correctly on 375x667 and 414x896 (particles and text within screen bounds)
