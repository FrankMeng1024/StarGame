# STORY-00420: 结算页个人最佳记录显示

**Epic**: E-014 游戏性体验提升
**Sprint**: Sprint 80-mini
**Sprint Goal**: 通过庆典动画、个人最佳记录、前期难度微调、图鉴连线可见性提升和选关星数汇总，全面提升游戏反馈感和可读性
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see my personal best record on the result card after completing a level, so that I can track my progress and know whether I improved.

## Expected Result
On victory, the result card displays "最高分: N ★" below the star rating. If the current run beat the previous best (more stars, or same stars with better time), a "新纪录！" badge appears next to it. On first-time completion (no previous best), "新纪录！" always shows.

## Acceptance Criteria
- [ ] Before `state.setScore(_levelIdx, ...)` is called in `_triggerResult`, the old best is captured via `state.getScore(_levelIdx)` and stored (e.g., `_result.prevBest = state.getScore(_levelIdx)`)
- [ ] On the victory result card, below the star rating row and above the constellation photo, a line reads "最高分: N ★" where N is the all-time best star count (max of previous best and current run)
- [ ] If current run stars > previous best stars, OR previous best was null (first completion), a "新纪录！" label displays in gold (#FFD700) to the right of the best score line, font size 12-14px
- [ ] If current run stars === previous best stars AND current `_timeLeft` > previous best time, "新纪录！" also displays (same stars but faster time is a new record)
- [ ] If current run did NOT beat previous best (lower stars, or same stars with less time remaining), "新纪录！" does NOT appear — only "最高分: N ★" shows
- [ ] On fail (victory=false), the personal best line does NOT appear on the result card
- [ ] Text styling: "最高分:" in rgba(200,200,220,0.7) at 11px, star count in white at 13px bold, "新纪录！" in #FFD700 at 12px with subtle glow (shadowBlur 4, shadowColor gold)
- [ ] The personal best display participates in the STORY-00373 card entrance animation (slides up and fades in with the card)
- [ ] Viewport: text fits within card width on 375px screen without overflow or truncation
