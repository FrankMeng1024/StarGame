# STORY-00400: 连击系统 — 快速连续抓星获得额外奖励

**Epic**: 游戏性提升
**Sprint**: Sprint 76-mini
**Sprint Goal**: 游戏性核心机制首Sprint — 动态难度+连击奖励+充能特效+里程碑动画
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to earn bonus rewards for catching stars in quick succession, so that skilled play feels more rewarding.

## Expected Result
Catching stars within 3 seconds of each other builds a combo multiplier that awards bonus time and particle effects.

## Acceptance Criteria
- [ ] 连击计数器 _comboCount，每次抓星后启动3秒倒计时 _comboTimer
- [ ] _comboTimer内再抓星 → _comboCount++ 并重置 _comboTimer
- [ ] _comboTimer归零或抓到垃圾 → _comboCount = 0
- [ ] _comboCount >= 2: 屏幕中央偏上(H*0.25)弹出金色 'x2 连击!' 文字，0.8s淡出
- [ ] _comboCount >= 3: 弹出 'x3 连击!!' + 额外+5秒时间奖励 + 12颗彩虹色粒子爆发
- [ ] 连击文字 bold 16px, fillStyle #FFD700, alpha从1→0历时800ms
- [ ] 不影响星评计算（时间奖励不计入星评的时间评估）

## Dependencies
- 无

## Notes
combo文字用canvas drawText + alpha动画实现，存储为 _comboPopup = {text, alpha, x, y}。每帧递减alpha，alpha<=0时清除。彩虹色粒子：随机hue 0-360的 `hsl(h, 100%, 60%)` 颜色，12颗，向四周散射。
