# STORY-00402: 星座完成里程碑动画 — 抓到50%/75%触发视觉事件

**Epic**: 游戏性提升
**Sprint**: Sprint 76-mini
**Sprint Goal**: 游戏性核心机制首Sprint — 动态难度+连击奖励+充能特效+里程碑动画
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want visible milestone celebrations as I progress through a level, so that I feel a sense of building momentum and stay engaged through the mid-game.

## Expected Result
At 50% and 75% star completion, the player sees a brief visual celebration that doesn't interrupt gameplay.

## Acceptance Criteria
- [ ] 抓到50%（Math.ceil(_total * 0.5)颗）时触发一次：
  - 屏幕短暂闪白（ctx.fillStyle='rgba(255,255,255,0.25)', 0.15s），已完成星座连线亮度提升（alpha从0.25→0.5）
  - HUD中央(W/2, H*0.35)弹出 '✦ 过半了！' 文字，bold 16px, #FFD700, 0.6s淡出
- [ ] 抓到75%（Math.ceil(_total * 0.75)颗）时触发一次：
  - 屏幕轻微震动（±2px, 4帧，复用现有_shakeFrames机制）
  - HUD弹出 '✦✦ 即将完成！'，同样样式，0.6s淡出
- [ ] 每个里程碑只触发一次（_milestone50Fired, _milestone75Fired布尔标志）
- [ ] 里程碑不暂停游戏，不影响timer
- [ ] _initStars时重置两个里程碑标志

## Dependencies
- 无

## Notes
_milestonePopup = {text, alpha, timer}，每帧递减alpha，0.6s=36帧。闪白效果：在_drawHUD之前绘制全屏白色矩形，alpha随timer衰减。连线亮度提升：在_drawConLines中检查_milestone50Fired，调整已完成段的strokeStyle alpha。
