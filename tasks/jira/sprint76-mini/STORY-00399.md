# STORY-00399: 动态难度缩放 — 根据表现实时调整游戏参数

**Epic**: 游戏性提升
**Sprint**: Sprint 76-mini
**Sprint Goal**: 游戏性核心机制首Sprint — 动态难度+连击奖励+充能特效+里程碑动画
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the game to subtly adjust difficulty based on my performance, so that each level feels engaging rather than too easy or frustrating.

## Expected Result
The game tracks recent shot accuracy and invisibly adjusts obstacle speed/count to keep the player in the flow zone — challenged but not frustrated.

## Acceptance Criteria
- [ ] 追踪最近5次发射中成功抓星的比例（_recentHits / _recentShots，循环队列长度5）
- [ ] 命中率 > 80%（连续5发4中以上）→ 障碍物移动速度系数 _dynamicObstacleScale *= 1.15，最高1.5x
- [ ] 命中率 < 30%（连续5发1中以下）→ _dynamicObstacleScale *= 0.8，最低0.5x
- [ ] _dynamicObstacleScale 应用于 _updateObstacles 中所有障碍物的移动速度
- [ ] 每30秒最多重新评估一次（_diffEvalTimer），避免频繁波动
- [ ] 调整过程无UI提示（玩家不察觉），不影响星评/金币计算
- [ ] _initObstacles时重置 _dynamicObstacleScale = 1.0

## Dependencies
- 无

## Notes
参考隐性难度调整机制（Flappy Bird-style rubber band）。每次发射网兜（_netState从swing→extend）记录一次shot，每次catch记录一次hit。队列长度5，循环覆盖。
