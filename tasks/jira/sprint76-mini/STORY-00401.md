# STORY-00401: 网兜充能特效 — 连续命中后网兜视觉升级

**Epic**: 游戏性提升
**Sprint**: Sprint 76-mini
**Sprint Goal**: 游戏性核心机制首Sprint — 动态难度+连击奖励+充能特效+里程碑动画
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want my net to visually 'power up' when I'm on a catching streak, so that skilled play is visually rewarding.

## Expected Result
After 3 consecutive successful catches (no debris collision), the net enters a "charged" visual state with bright color and the net moves slightly faster.

## Acceptance Criteria
- [ ] _chargeCount 追踪连续成功抓星数（碰垃圾或关卡初始化时重置为0）
- [ ] _chargeCount >= 3 → _netCharged = true：网袋meshline颜色改为 #ffffff，hoop lineWidth从1改为2，shadowBlur=10
- [ ] 充能态下 _netSpeed *= 1.2（通过临时乘数，不修改基础常量），碰垃圾时恢复
- [ ] 充能态失效时有0.3s颜色渐变回归（_chargeBlendT从0→1，颜色lerp回金色）
- [ ] 充能态激活瞬间：播放 SFX_CATCH（AudioAdapter.playSFX）以1.0x速率（无法改变播放速率时跳过速率变化，只播放）
- [ ] 充能态在HUD上不显示额外图标（保持HUD简洁）

## Dependencies
- STORY-00400（依赖 _comboCount 逻辑，或并行实现自己的 _chargeCount）

## Notes
_chargeCount 与 _comboCount 可以共享同一计数，也可独立维护。充能态视觉变化仅影响 _drawNet 中的颜色参数，不改变网兜几何形状。shadowBlur需要ctx.shadowColor = '#ffffff'配合。
