# STORY-00362: 防息屏 — 游戏中保持屏幕常亮

**Epic**: Core UX
**Sprint**: Sprint 57-mini
**Sprint Goal**: 防息屏 + 道具商店UI与整体风格对齐
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the screen to stay on while I'm playing, so I don't lose progress when the screen auto-locks.

## Expected Result
游戏界面启动时屏幕不息屏，退出游戏时恢复正常息屏。

## Acceptance Criteria
- [ ] showGame() 调用时执行 wx.setKeepScreenOn({keepScreenOn: true})
- [ ] hideGame()/_cleanup() 时执行 wx.setKeepScreenOn({keepScreenOn: false})
- [ ] 其他页面（menu/levels/gallery/shop）不调用 setKeepScreenOn，不影响正常省电
- [ ] 截图：游戏界面运行截图（证明功能代码已插入）

## Dependencies
无

## Notes
wx.setKeepScreenOn 在微信小游戏中有效，DevTools中不影响测试。
