## Description
As a player, I want the opening animation to feel like a real stargazing experience: a pitch-black sky gradually filling with stars of different sizes, a natural (not rigid) meteor shower, then stars connecting one by one into a constellation, and finally the title fading in.

## Expected Result
The intro animation shows:
1. Background: rich starfield with varied star sizes (small/medium/large), all twinkling
2. Meteor shower: meteors fall at different angles, different speeds, staggered naturally (not all at once)
3. Constellation reveal: stars appear one by one with sparkle burst, lines draw from point A to point B (not just appear), NO constellation name shown
4. Title: "追星少女" fades in, centered

## Acceptance Criteria
- [x] Background stars have 3 clear size tiers: tiny (~0.6px), medium (~1.2px), large (~2px) — creating depth perception
- [x] Background stars have varied brightness (some dim, some bright), all twinkling at different phases
- [x] Meteors fall at varying angles (not all at same angle) — staggered appearance, each with unique angle variation
- [x] No two meteors appear at the exact same time (natural stagger)
- [x] Constellation lines animate from point A toward point B (growth animation), not instant pop-in
- [x] NO constellation name text shown anywhere in the intro
- [x] Title "追星少女" fades in cleanly in lower screen area
- [x] Screenshot at t=2s shows visible meteor streaks against dark sky with star background
- [x] Screenshot at t=6s shows partial constellation (some stars connected)
- [x] Screenshot at t=10s shows full constellation + title visible
