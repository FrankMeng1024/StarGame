**Epic**: 游戏视觉质量提升

**Sprint Goal**: 修复用户反馈的三个游戏界面问题  
**Points**: 2

## Description
As a player, I want the game visuals to be clean and responsive, so that the girl character looks polished, the net direction is always visible, and pose changes feel smooth.

## Expected Result
1. Girl character has no white/grey artifact lines on either side
2. Net/pole is visible during swing state showing current direction
3. Frame transitions are cross-faded (180ms) instead of instant snaps

## Acceptance Criteria
- [x] No white vertical lines on either side of girl sprite — girl.png background made transparent via flood-fill
- [x] Bamboo pole and net bag visible during swing state (alpha 0.55, showLen=28px)
- [x] Girl pose transitions use 180ms cross-fade between frames
- [x] No regression on other screens (menu, gallery, levels)

## Notes
- girl.png: flood-fill from 4 corners removed 129,520 white/grey background pixels, 0 eye-area character pixels affected
- Net swing: removed `if (_netLen < 5 && _netState === 'swing') return` early exit; bamboo always drawn with `swingAlpha`
- Animation: added `_girlPrevFrame`, `_girlTransT`, `_girlTransStart`, `_GIRL_TRANS_MS=180` for cross-fade
- Sprint 67-mini: single bundled story (3 small bug fixes in same feature area)
