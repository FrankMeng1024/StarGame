# STORY-00383: 道具商店底部弹窗购买流程完整化

**Epic**: 游戏体验完整性
**Sprint**: Sprint 71-mini
**Sprint Goal**: 道具商店体验完整化 — 底部弹窗购买流程可用 + 来源记忆导航
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the shop bottom sheet to show complete item info and a working buy button, so I can purchase items without frustration.

## Expected Result
- 点击任意道具行 → 底部弹窗从底部滑出，包含：道具名、描述、价格、当前金币、购买按钮、取消方式
- 弹窗高度适配横屏 H≈375px，所有内容在弹窗内完整显示，不被裁剪
- 点击"购买"按钮 → 金币足够时：扣金币、inventory+1、显示成功Toast、弹窗关闭
- 金币不足时：购买按钮置灰，点击显示"金币不足"toast，不静默失败
- 点击弹窗外区域（顶部暗色区域）可关闭弹窗
- hitTest坐标与视觉位置对齐（无DPR/scrollY偏差）

## Acceptance Criteria
- [ ] 点击道具行后，底部弹窗在1帧内开始滑出动画，最终停在 H - SHEET_H 位置
- [ ] 弹窗内可见：道具图标、名称、类型badge、描述文字、"🪙 X"价格、购买按钮
- [ ] 弹窗高度(SHEET_H)调整为适配landscape H≈375px — 内容不被底部裁剪（截图证明）
- [ ] 购买按钮hitTest：弹窗完全停止后点击购买按钮，Toast出现确认扣款成功（截图证明）
- [ ] 金币不足时：购买按钮显示灰色，点击显示"金币不足"toast（截图证明）
- [ ] 点击弹窗外（暗色遮罩区域）→ 弹窗关闭（截图证明弹窗消失）

## Dependencies
- 无
