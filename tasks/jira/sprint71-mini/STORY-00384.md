# STORY-00384: 导航来源记忆 — shop/gallery返回正确页面

**Epic**: 游戏体验完整性
**Sprint**: Sprint 71-mini
**Sprint Goal**: 道具商店体验完整化 — 底部弹窗购买流程可用 + 来源记忆导航
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, when I enter the shop or gallery from the level select screen, I want the back button to return me to the level select screen (not the main menu).

## Expected Result
- 从levels页进入shop → 点返回 → 回到levels页
- 从menu进入shop → 点返回 → 回到menu页
- 从levels进入gallery（如有入口）→ 点返回 → 回到levels页
- 从menu进入gallery → 点返回 → 回到menu页

## Acceptance Criteria
- [ ] game.js navigate()支持第二参数opts：`navigate('shop', { from: 'levels' })`
- [ ] showShop(navigate, opts)接收opts.from，存储到_shopFrom；返回按钮调用`_navigate(_shopFrom || 'menu')`
- [ ] showGallery(navigate, opts)接收opts.from，存储到_galleryFrom；返回按钮调用`_navigate(_galleryFrom || 'menu')`
- [ ] levels.js中navigate('shop')调用改为navigate('shop', { from: 'levels' })（截图证明从levels进shop后返回到levels）
- [ ] levels.js中navigate('gallery')调用（如有）改为navigate('gallery', { from: 'levels' })
- [ ] menu.js中navigate('shop')/navigate('gallery')调用保持from:'menu'或不传（默认menu）

## Dependencies
- 无

## Notes
修改点：
1. game.js: navigate(key, opts={})，将opts传给showShop/showGallery/showAchievement
2. shop.js: showShop(navigate, opts={}) — _shopFrom = opts.from || 'menu'
3. gallery.js: showGallery(navigate, opts={}) — _galleryFrom = opts.from || 'menu'
4. levels.js line 995: _navigate('shop') → 需改为能传from的方式
   但_navigate是navigate函数本身，levels调用_navigate('shop')，此时没有from。
   解决方案：levels.js改为 _navigate('shop', { from: 'levels' })
   因此navigate()签名改为navigate(key, opts)，并在switch中透传opts给show*函数。
