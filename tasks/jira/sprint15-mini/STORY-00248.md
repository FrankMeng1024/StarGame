# STORY-00248: 关卡难度指示条

**Epic**: 关卡体验  
**Sprint**: Sprint 15-mini  
**Points**: 2  
**Owner**: Frontend Dev  
**Status**: Done  

## Description
As a player, on the level selection screen, I want to see a visual difficulty indicator for each level, so I can pick an appropriate challenge.

## Expected Result
Each level card in levels.js shows 1-5 filled dot difficulty indicators (matching constellation difficulty from CONSTELLATIONS data). Easy levels show 1-2 dots, hard levels show 4-5 dots.

## Acceptance Criteria
- [ ] Each level card shows difficulty dots (e.g. 5 small circles, filled/empty based on difficulty)
- [ ] Difficulty value comes from CONSTELLATIONS[idx].difficulty (1-5 scale)
- [ ] Dots are visible at all card sizes (landscape 5-col grid and portrait layouts)
- [ ] Locked levels still show difficulty dots (player can plan ahead)
- [ ] Dots use star color (gold/amber) for filled, dim gray for empty

## Notes
CONSTELLATIONS data is imported in levels.js already. Check existing card drawing code to fit dots in the card layout without overflow.
