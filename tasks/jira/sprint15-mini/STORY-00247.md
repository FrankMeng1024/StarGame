# STORY-00247: wx.onHide 自动暂停游戏

**Epic**: 游戏体验  
**Sprint**: Sprint 15-mini  
**Points**: 1  
**Owner**: Frontend Dev  
**Status**: Done  

## Description
As a player, when I switch away from the game (receive a call, switch apps, lock screen), I want the game to automatically pause so I don't lose time.

## Expected Result
wx.onHide() callback is registered in game.js. When app goes to background, the game pauses (if running). wx.onShow() resumes (or keeps paused for user to resume manually).

## Acceptance Criteria
- [ ] wx.onHide() registered in game.js showGame() or at module level
- [ ] Game timer stops when wx.onHide fires while game is in playing state
- [ ] Game shows paused state UI when returning via wx.onShow (player must manually resume)
- [ ] No error if wx.onHide fires when game is not in playing state (e.g. on menu screen)

## Notes
Check if _gameState / _isPaused variables exist in game.js to use for pause logic.
