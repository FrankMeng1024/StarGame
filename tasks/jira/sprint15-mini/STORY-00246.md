# STORY-00246: 通关卡片展示星座照片

**Epic**: 视觉完整度  
**Sprint**: Sprint 15-mini  
**Points**: 2  
**Owner**: Frontend Dev  
**Status**: Done  

## Description
As a player, after completing a level, I want to see a photo of the constellation I just caught, so the victory screen feels meaningful and educational.

## Expected Result
Victory card in game.js shows the constellation's astrophotography image (the same photo used in gallery). Image loads from CDN. Shows above or alongside the lore text on the victory card.

## Acceptance Criteria
- [ ] Victory card displays constellation photo (drawImage on canvas) after level completion
- [ ] Photo is fetched via the same CDN URL pattern used in gallery.js
- [ ] If image fails to load, gracefully falls back (no crash, no broken UI)
- [ ] Photo fits within the victory card bounds (cropped/scaled to fit)
- [ ] Landscape card height stays within Math.min(460, H-20) constraint

## Notes
gallery.js already has the CDN URL pattern for photos. Reuse that. Pre-load the image before level completes to avoid flash.
