# STORY-00245: 游戏音效 — 抓星/碰垃圾/通关/时间延长

**Epic**: 感官完整度  
**Sprint**: Sprint 15-mini  
**Points**: 2  
**Owner**: Frontend Dev  
**Status**: Done  

## Description
As a player, I want to hear sound effects when catching stars, hitting debris, completing a level, and using time extension items, so the game feels responsive and rewarding.

## Expected Result
AudioAdapter.playSFX() is called at the right moments during gameplay. Since WeChat mini game has no Web Audio API, SFX are generated as tiny inline PCM WAV data URIs embedded directly in wx-adapter.js, avoiding any file dependency.

## Acceptance Criteria
- [ ] Star catch: short ascending tone plays when a star is caught (not muted)
- [ ] Debris hit: short low thud plays when net hits debris (not muted)
- [ ] Level complete: fanfare plays when all stars caught (not muted)
- [ ] Time extension: upward sweep plays when time_ext item activates (not muted)
- [ ] No sound when AudioAdapter.isMuted() === true
- [ ] SFX play without blocking gameplay (fire-and-forget, no await)
- [ ] No console errors from audio calls

## Notes
WeChat mini game does not support Web Audio API oscillators. Solution: generate tiny PCM WAV Base64 data URIs for each SFX and use AudioAdapter.playSFX() with those URIs. The WAV generation happens at import time (module scope), not at call time.
