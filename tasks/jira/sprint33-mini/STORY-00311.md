# STORY-00311: 游戏HUD对齐 — 计时器样式+星标位置与web一致

**Epic**: E-033 跨平台对标
**Sprint**: Sprint 33-mini
**Sprint Goal**: Web vs Mini cross-platform parity
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the in-game HUD layout on mini-game to match the web version's layout, so both platforms feel like the same game.

## Expected Result
Mini game HUD matches web: circular timer in top-center, star count (★ X/Y) in top-right, level name top-left. Pause icon present.

## Acceptance Criteria
- [ ] Timer displayed as circular progress indicator in top-center (matching web's blue ring style), OR at minimum with same visual weight/position as web
- [ ] Star count displayed in top-right as `★ X/Y` (currently top-left on mini)
- [ ] Level/constellation name displayed in top-left
- [ ] Pause/settings icon (⚙) visible in top-right area
- [ ] HUD elements don't overlap game content at 375px viewport width

## Dependencies
- None
