# STORY-00309: 商店网格布局 — mini版与web版2×N卡片对齐

**Epic**: E-033 跨平台对标
**Sprint**: Sprint 33-mini
**Sprint Goal**: Web vs Mini cross-platform parity
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the shop on mini-game to show items in a grid layout with the same rich card details as the web version, so the experience feels consistent.

## Expected Result
Mini shop shows 2-column grid cards matching web: icon (large, centered), name, description, 主动/被动 badge, duration badge, price, 购买 button.

## Acceptance Criteria
- [ ] Shop displays items in 2-column grid (not vertical list)
- [ ] Each card has: large centered icon, item name, description text
- [ ] Each card shows 主动/被动 badge (purple pill)
- [ ] Each card shows duration badge (e.g. 15秒, 即时, 30秒, 全局)
- [ ] Price (金币 amount) and 购买 button visible on each card
- [ ] Layout scrollable if items exceed viewport height
- [ ] All 8 items visible (matching web's 网兜加速/扩大/宇宙炸弹/时间延长/缩小垃圾/星图揭示/宇航员手套/双倍金币)
- [ ] No overflow or clipping on 375px wide viewport

## Dependencies
- None
