# STORY-00379: 修复网兜绳子起点位置 — 应在头部/手部不在腰间

**Epic**: E-007 游戏视觉质量
**Sprint**: Sprint 69-mini
**Sprint Goal**: 修复女孩精灵图残留灰色像素和网兜绳子起点位置
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the net's rope to start from the girl's hand/shoulder area, so that the throw looks natural and not like it originates from her waist.

## Root Cause
`_updateNetHead()` 和 `_drawNet()` 中，idle/swing 状态的绳子起点为 `ropeOriY = _poleY - 17`。

女孩精灵图渲染到 canvas 的坐标：
- `dstX = _poleX - 55`, `dstY = _poleY - 98`, `dstW = 110`, `dstH = 110`
- 缩放比 0.5（PNG 220px → canvas 110px）
- `_poleY - 17` 对应精灵图 y = `(-17 + 98) / 0.5 = 162px`，即从顶部 74% 处 = 腰/臀部位置

正确的手部位置（idle 帧，女孩右手持竹竿）约在精灵图 y ≈ 80-90px 处：
- canvas Y = `_poleY - 98 + 80 * 0.5 = _poleY - 58`
- 对应 ropeOriY ≈ `_poleY - 58`，ropeOriX ≈ `_poleX + 20`

## Fix
修改 `_updateNetHead()` 和 `_drawNet()` 中 idle/swing 状态的绳子起点：
- 旧：`ropeOriX = _poleX + 13, ropeOriY = _poleY - 17`
- 新：`ropeOriX = _poleX + 20, ropeOriY = _poleY - 58`

注：extend 状态（`_poleY - 78`）已经接近正确，无需修改。

- [x] AC2: 发射前（swing）和发射后（extend）绳子起点位置视觉上连贯，无跳变感
- [x] AC3: 碰撞检测（_netHeadX/Y）计算逻辑正确（ropeOri 传入物理坐标）
