# STORY-00378: 清除 girl.png 残留灰色像素（scroll bar / darker grey）

**Epic**: E-007 游戏视觉质量
**Sprint**: Sprint 69-mini
**Sprint Goal**: 修复女孩精灵图残留灰色像素和网兜绳子起点位置
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character to have a completely clean transparent background, so that no scroll bar or grey artifacts appear when she throws the net.

## Root Cause
Sprint 68 的三通道背景清除使用 `R>190` 作为背景检测阈值。但 girl.png 底部行存在 `RGB(139,139,139)` 纯中灰色像素（浏览器 scroll bar / chrome 渲染残留），alpha=255，R=139 低于 190 阈值，因此未被清除。

具体：
- **所有 4 帧**：底部（约最后10行）有大量 `RGB(139,139,139)` 纯灰像素（1,000-1,300个/帧）
- **Frame 3（catch帧）**：右侧列额外有 1,280 个 `RGB(139,139,139)` 灰色像素

## Fix Approach
扩展背景清除逻辑，增加一个"纯灰色"通道：
1. 检测条件：`abs(R-G) < 12 AND abs(G-B) < 12 AND R < 175 AND alpha > 10`（纯中灰，非皮肤色）
2. 全图扫描，满足条件的像素设 alpha=0
3. 验证：`RGB(139,139,139,255)` 像素数量归零

Note: 皮肤色是暖色（R > G+30），不满足 `abs(R-G) < 12` 条件，不会误删。

## Acceptance Criteria
- [x] AC1: 游戏中网兜发射后（throw帧），女孩角色周围无灰色条纹/scroll bar 可见
- [x] AC2: girl.png 中不存在满足 `abs(R-G)<12 AND abs(G-B)<12 AND R<175 AND alpha>10` 的像素
- [x] AC3: 角色像素（皮肤、衣服、头发）不受影响

## Notes
皮肤色样本：`RGBA(254,222,194)` — R-G=32，远超12，不触发灰色通道。
发射后可见的 scroll bar 具体来自底部行（所有帧）+ frame 3 右列。
