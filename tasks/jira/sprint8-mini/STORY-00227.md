# STORY-00227: game.js HUD 适配安全区

**Epic**: E-001 核心引擎
**Sprint**: Sprint 8-mini
**Sprint Goal**: 刘海屏安全区适配
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on a notch phone, I want the HUD (timer, coin count, level name, pause area) to be fully visible and not hidden behind the notch.

## Expected Result
HUD bar extends to cover the notch area visually (background), but all text and interactive elements are offset below the notch.

## Acceptance Criteria
- [ ] HUD background bar starts at y=0 and extends to `G.SAFE_TOP + 52` (covers the notch visually)
- [ ] All HUD text (level name, caught count, timer) is drawn at `y = G.SAFE_TOP + 26` (vertical center of visible HUD area)
- [ ] Bomb button (if active) appears at `y = G.SAFE_TOP + 58` (below HUD bar)
- [ ] `_poleY` (girl position) remains unchanged — girl is not in the HUD zone
- [ ] `_netMaxLen` = `H * 0.55` remains unchanged — net throw distance not affected
- [ ] `_initStars` and `_initDebris` use `skyY0 = G.SAFE_TOP + 60` so no star/debris spawns behind notch

## Dependencies
- Depends on: STORY-00226
