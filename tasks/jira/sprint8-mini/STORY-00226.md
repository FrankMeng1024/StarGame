# STORY-00226: 安全区全局常量 — globals.js 注入 SAFE_TOP/BOTTOM/LEFT/RIGHT

**Epic**: E-001 核心引擎
**Sprint**: Sprint 8-mini
**Sprint Goal**: 刘海屏安全区适配
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a developer, I want a single source of truth for safe area insets so that all screens can offset their UI elements away from notches and home indicators.

## Expected Result
`G.SAFE_TOP`, `G.SAFE_BOTTOM`, `G.SAFE_LEFT`, `G.SAFE_RIGHT` available in globals.js. All screens import these from G and use them instead of hardcoded 0.

## Acceptance Criteria
- [ ] `globals.js` exports `SAFE_TOP`, `SAFE_BOTTOM`, `SAFE_LEFT`, `SAFE_RIGHT` (initialized to 0)
- [ ] `initGlobals()` accepts a 5th arg `safeArea` object and sets these fields
- [ ] `app.js` calls `wx.getSystemInfoSync()`, reads `.safeArea`, and passes insets to `initGlobals()`
- [ ] On devices without `safeArea` (older wx SDK), gracefully falls back to 0 for all insets
- [ ] `G.SAFE_TOP` equals the top of the safe area (e.g. 59 on iPhone 14 Pro with notch)
- [ ] `G.SAFE_BOTTOM` equals `SCREEN_H - safeArea.bottom` (home indicator height from bottom)

## Dependencies
- Blocks: STORY-00227, STORY-00228, STORY-00229

## Notes
wx.getSystemInfoSync().safeArea returns {top, left, bottom, right, width, height} in px.
SAFE_TOP = safeArea.top (distance from screen top to safe area top — notch height)
SAFE_BOTTOM = SCREEN_H - safeArea.bottom (home indicator height)
SAFE_LEFT = safeArea.left (side notch, usually 0 in portrait)
SAFE_RIGHT = SCREEN_W - safeArea.right (usually 0 in portrait)
