# STORY-00228: menu.js 按钮/标题适配安全区

**Epic**: E-005 主界面
**Sprint**: Sprint 8-mini
**Sprint Goal**: 刘海屏安全区适配
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on a notch/home-indicator phone, I want the main menu title, subtitle, and buttons to sit fully within the safe area so nothing is clipped.

## Expected Result
Title positioned above safe bottom zone; buttons are above the home indicator. Constellation background fills full screen (no change).

## Acceptance Criteria
- [ ] Main menu buttons bottom edge does not extend below `H - G.SAFE_BOTTOM - 8` (above home indicator)
- [ ] `startY` for button layout recalculated as `H - G.SAFE_BOTTOM - 180` instead of `H - 180`
- [ ] Title (`drawTitle`) at `H * 0.72` — if this would place it within `SAFE_BOTTOM` zone, shift up by `G.SAFE_BOTTOM`; otherwise keep as-is
- [ ] Constellation background (`_buildConLayout`, `_drawConBg`) extends fully to y=0 and y=H — no clipping at top/bottom (background is decorative, not interactive)
- [ ] `cy` (constellation center) = `H * 0.32` remains unchanged (upper portion)

## Dependencies
- Depends on: STORY-00226

## Notes
Current: startY = H - 180. Bottom button at H - 180 + 2*(48+14) = H - 180 + 124 = H - 56.
On iPhone 14 Pro: SAFE_BOTTOM = 34px. So need H - 34 - 180 = H - 214 for startY.
Title at H * 0.72: on 844px = 608. Safe bottom starts at 844-34=810. Title is fine, no shift needed.
Only startY for buttons needs the SAFE_BOTTOM offset.
