# BUG-00101-STORY-00204: 选关屏幕截图中标题栏显示异常文字

**Priority**: Low
**Sprint**: Sprint 1-mini
**Opened by**: QA
**Status**: Closed

## Description
截图 smoke-02-levels.png 中标题栏区域显示"迎天下下"，疑为文字渲染问题。

## Root Cause
经调查：为截图工具（BitBlt screen DC）捕获了 DevTools Electron 窗口标题栏文字（"Mini Game ..."）
的部分字符叠入截图，并非 Canvas 渲染错误。Canvas 实际标题文字为 `选择关卡`（levels.js:119），
无渲染问题。

## Fix
无需修复。截图方式已知限制——截图包含了 OS 窗口 chrome 层，非游戏内容。

## Status
Closed — 非真实 bug，为截图工件。
