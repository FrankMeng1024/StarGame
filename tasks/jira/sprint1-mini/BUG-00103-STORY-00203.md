# BUG-00103-STORY-00203: 主菜单第3个按钮超出屏幕底部

**Priority**: Critical
**Sprint**: Sprint 1-mini
**Opened by**: UX
**Status**: Fixed

## Description
主菜单三个按钮（挑战关卡/星座展厅/道具商店）在 iPhone 12/13（H=844px）上第3个按钮（道具商店）
底部超出屏幕，用户无法看到/点击。

## Steps to Reproduce
1. 打开小游戏主菜单
2. 观察 iPhone 12/13 viewport 下方区域

## Expected
三个按钮全部在屏幕内可见可点击

## Actual
第3个按钮("道具商店")被裁剪在屏幕底部以外

## Root Cause
`startY = H * 0.84` (709px for H=844)，三个按钮总高 172px，底部到达 881px > 844px。

## Fix
`menu.js`: `startY = H - 180`（三个按钮固定从底部 180px 处开始，始终适配任何屏幕高度）
同时标题位置从 `H * 0.76` 上移至 `H * 0.72`。
Commit: 待下次 Strategy A 提交。
