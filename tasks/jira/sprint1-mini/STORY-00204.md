# STORY-00204: Canvas 选关屏幕 — 30 关网格 + 解锁状态

**Epic**: E-M02 UI 屏幕
**Sprint**: Sprint 1-mini
**Sprint Goal**: 小游戏骨架可运行，自动化测试工具链验证
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want to see the level select screen with 30 constellation levels, so that I can choose which level to play.

## Expected Result
从主菜单点击[挑战关卡]进入，Canvas 显示 30 个关卡卡片（6 列 × 5 行），第 1 关解锁，其余锁定。卡片显示星座名 + 锁定/解锁状态。

## Acceptance Criteria
- [ ] 30 个关卡卡片均渲染，6 列布局，无重叠无溢出
- [ ] 第 1 关卡片：显示"猎户座"，无锁图标，可 tap
- [ ] 第 2-30 关：锁定状态，灰色 + 锁图标
- [ ] 已完成关卡：显示星评（1-3 星），从 StorageAdapter 读取
- [ ] [返回] 按钮导航回主菜单
- [ ] 竖屏布局，卡片可滑动（超出屏幕时支持上下滑动）
- [ ] 开发者工具无 JS 错误

## Dependencies
- 依赖：STORY-00202（wx-adapter）、STORY-00203（主菜单导航）

## UX AC
- [ ] 关卡卡片最小 tap 区域 60×60px
- [ ] 锁定和解锁状态一眼可区分

## Notes
背景随场景变化（Sprint 2 实现），Sprint 1 用固定深蓝背景。
