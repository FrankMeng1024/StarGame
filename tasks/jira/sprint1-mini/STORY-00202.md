# STORY-00202: wx-adapter 平台适配层 — storage/network/audio 封装

**Epic**: E-M01 平台基础
**Sprint**: Sprint 1-mini
**Sprint Goal**: 小游戏骨架可运行，自动化测试工具链验证
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a developer, I want a wx-adapter module that wraps all wx-specific APIs behind a unified interface, so that game logic code doesn't need to know about the platform.

## Expected Result
`js/platform/wx-adapter.js` 实现完整，存储/网络/音频三层均可用，本地 setStorage/getStorage 读写在开发者工具中验证通过。

## Acceptance Criteria
- [ ] `StorageAdapter.getLocal()` / `setLocal()` 在开发者工具中读写成功
- [ ] `StorageAdapter.loadSave()` 返回默认存档（网络不可用时）
- [ ] `StorageAdapter.persistSave()` 本地写入成功（网络不可用时跳过云端，无报错）
- [ ] `AudioAdapter.playBGM()` 调用后 `wx.createInnerAudioContext` 不报错
- [ ] `request()` 网络失败时抛出 Error（不静默吞掉）
- [ ] 开发者工具控制台无 JS 错误

## Dependencies
- 无外部依赖
