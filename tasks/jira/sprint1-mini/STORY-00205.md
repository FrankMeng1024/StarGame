# STORY-00205: 后端骨架 — 健康检查 + login + save 接口本地运行

**Epic**: E-M03 后端
**Sprint**: Sprint 1-mini
**Sprint Goal**: 小游戏骨架可运行，自动化测试工具链验证
**Points**: 3
**Owner**: Backend Dev
**Status**: Done

## Description
As a developer, I want the backend server to start locally and pass a health check, so that we can verify the API structure before deploying.

## Expected Result
`cd backend && cp .env.example .env && npm install && node src/app.js` 启动成功，`GET http://localhost:3000/health` 返回 `{"ok":true}`。数据库表自动创建。

## Acceptance Criteria
- [ ] `npm install` 依赖安装成功（无报错）
- [ ] `.env` 配置 DB 连接后 `node src/app.js` 启动无报错
- [ ] `GET /health` 返回 200 `{"ok":true}`，响应 < 100ms
- [ ] `POST /api/login` 接收 `{code:"test"}` 时返回 4xx（code 无效，预期行为），不报 500
- [ ] MySQL saves 表自动创建（`SHOW TABLES` 可见）
- [ ] `.env.example` 包含所有必要环境变量（WX_APPID, WX_APPSECRET, JWT_SECRET, DB_*）

## Dependencies
- 需要本地 MySQL 运行（或 Docker MySQL）

N/A（后端 API，无 UI）
