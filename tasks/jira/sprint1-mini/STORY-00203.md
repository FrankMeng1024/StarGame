# STORY-00203: Canvas 主菜单屏幕 — 星空背景 + 标题 + 两个按钮

**Epic**: E-M02 UI 屏幕
**Sprint**: Sprint 1-mini
**Sprint Goal**: 小游戏骨架可运行，自动化测试工具链验证
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see the main menu when I open the mini game, so that I can start playing or browse the gallery.

## Expected Result
微信开发者工具打开 miniprogram/ 目录，模拟器显示：深蓝星空背景 + "追星少女" 金色标题 + [挑战关卡] [星座展厅] 两个按钮。点击按钮有视觉反馈（颜色变化）。

## Acceptance Criteria
- [ ] Canvas 正确初始化（`wx.createCanvas()`，全屏尺寸）
- [ ] 星空背景渲染：深蓝渐变（`--sky-deep: #0a0e27` → `#1a1f4e`）+ 随机星点
- [ ] 标题"追星少女"金色文字，字号 ≥ 36px，位置：屏幕上 40% 居中
- [ ] [挑战关卡] 按钮：渐变填充，圆角，居中，可 tap 响应
- [ ] [星座展厅] 按钮：同上，位于[挑战关卡]下方 70px
- [ ] 点击[挑战关卡]：打印 `navigate:levels`（Sprint 2 接真实跳转）
- [ ] 点击[星座展厅]：打印 `navigate:gallery`（Sprint 2 接真实跳转）
- [ ] 开发者工具模拟器无 JS 错误
- [ ] 屏幕适配：iPhone 14 Pro 390×844 + Android 1080×2400 均无溢出

## Dependencies
- 依赖：STORY-00202（wx-adapter）

## UX AC
- [ ] 首次打开 2 秒内看到主菜单（无白屏超过 500ms）
- [ ] 按钮点击区域 ≥ 44px 高度，易于 tap

## Notes
星空粒子动画（星星闪烁）是 Should Have，如果影响 Sprint 1 进度可在 Sprint 2 加。
Sprint 1 目标是主菜单可见可交互，不需要开场动画。
