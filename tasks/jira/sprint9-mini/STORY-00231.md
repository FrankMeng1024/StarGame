**Points**: 2

## Description
As a player, I want a mute button on the main menu so that I can toggle background music on/off and have my preference remembered across sessions.

## Expected Result
- A small mute/unmute icon button (🔇/🔊) in the top-right corner of the menu screen
- Toggling it saves to wx storage (MUTED_KEY) and immediately stops/starts BGM
- Mute state persists across app restarts

## Acceptance Criteria
- [ ] Mute button rendered at top-right of menu screen (within safe area: right edge - SAFE_RIGHT - 48, SAFE_TOP + 14)
- [ ] Button shows 🔊 when unmuted, 🔇 when muted
- [ ] Tap toggles state: if currently playing → stop + save muted=true; if muted → play + save muted=false
- [ ] On app restart, AudioAdapter.playBGM checks MUTED_KEY; if muted=true, does not autoplay
- [ ] Audio state confirmed via code review (not real device required)
