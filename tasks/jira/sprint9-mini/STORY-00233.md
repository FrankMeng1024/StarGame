# STORY-00233: 音乐跨页面连续播放

**Epic**: E-001
**Sprint**: Sprint 9-mini
**Sprint Goal**: 背景音乐 + 静音控制 + BUG修复 — 完成VU前最后清单
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want background music to continue playing as I navigate between screens, so that the experience feels seamless.

## Expected Result
- BGM plays continuously through menu → levels → item selection → game → result → back to menu
- BGM does NOT restart (reset currentTime) on each screen navigation
- BGM stops only when explicitly muted

## Acceptance Criteria
- [ ] AudioAdapter uses a single persistent _bgm instance; playBGM only creates new context if not already playing
- [ ] Navigating from menu → levels does not stop/restart BGM
- [ ] Navigating from game result screen back to menu does not restart BGM
- [ ] Game over / level complete does not stop BGM
- [ ] Only mute button tap stops BGM

## Dependencies
Depends on: STORY-00230

## Notes
Currently hideMenu() would call stopBGM(). The navigation model in game.js calls hide* on all screens before show*.
Fix: AudioAdapter.playBGM should be idempotent — if _bgm is already playing, do nothing.
AudioAdapter.stopBGM should only be called from muteToggle, not from screen hide functions.
Remove any stopBGM calls from individual screen hide* functions.
