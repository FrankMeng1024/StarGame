# STORY-00377: 修复网兜绘制位置 — 网兜口在竹竿顶端

**Epic**: E-007 游戏视觉质量
**Sprint**: Sprint 68-mini
**Sprint Goal**: 修复女孩精灵图背景残留和网兜位置偏移
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the net bag to be visually centered at the tip of the bamboo pole, so that I can clearly see where the catching zone is.

## Expected Result
网兜口（半圆弧的直径端）的中心点 = `(headX, headY)` = 竹竿顶端。网兜袋向抛出方向延伸（远离绳子起点方向）。视觉上网兜"套"在竹竿顶端。

## Root Cause
`_drawNet()` 中 `ctx.translate(headX, headY)` 后 `ctx.rotate(angle)` 后，网兜口的圆心确实在 (0,0)（即竹竿顶端）。但 `ctx.arc(0, 0, mouthR, Math.PI, 0, false)` 画的是上半圆（y<0方向），网兜袋向 +y（旋转坐标系的"下方"，即远离抛出方向）延伸。

当竹竿指向上方（angle≈0）时，旋转坐标系的 +y 方向就是屏幕向下，网兜袋朝下——这意味着袋子远端在竹竿顶端之下，与竹竿方向相反，造成"网兜不在顶端"的视觉错觉。

## Fix
将 `ctx.arc(0, 0, mouthR, Math.PI, 0, false)` 改为 `ctx.arc(0, 0, mouthR, 0, Math.PI, false)` 配合袋体方向翻转（bagD 改为负值，即向 -y），使网兜口在 headX/headY，袋子向 -y（即抛出方向，远离绳子起点）延伸。

具体：将所有 bagD 的 +y bezier 控制点改为 -bagD，让袋体朝上（旋转后 = 朝抛出方向）：

```js
// 旧: 袋子朝下 (y=+bagD)
ctx.arc(0, 0, mouthR, Math.PI, 0, false);
ctx.bezierCurveTo(mouthR*0.9, bagD*0.5, mouthR*0.4, bagD, 0, bagD);
ctx.bezierCurveTo(-mouthR*0.4, bagD, -mouthR*0.9, bagD*0.5, -mouthR, 0);

// 新: 袋子朝上 (y=-bagD) = 朝抛出方向
ctx.arc(0, 0, mouthR, 0, Math.PI, false);
ctx.bezierCurveTo(-mouthR*0.9, -bagD*0.5, -mouthR*0.4, -bagD, 0, -bagD);
ctx.bezierCurveTo(mouthR*0.4, -bagD, mouthR*0.9, -bagD*0.5, mouthR, 0);
```

同样需修改网格线绘制部分（bagD → -bagD）以保持一致。

## Notes
修改仅在 `_drawNet()` 的网兜袋绘制部分（bag fill + bag outline + net mesh lines）。竹竿和细绳绘制逻辑不变。
碰撞检测逻辑（_netHeadX/Y）不受影响——那是物理坐标，不依赖绘制坐标系。
