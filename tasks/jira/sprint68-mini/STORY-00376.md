# STORY-00376: 彻底清除女孩精灵图白色/灰色背景

**Epic**: E-007 游戏视觉质量
**Sprint**: Sprint 68-mini
**Sprint Goal**: 修复女孩精灵图背景残留和网兜位置偏移
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character sprite to have no visible background artifacts, so that she blends naturally into the dark starfield.

## Expected Result
`girl.png` 所有帧的白色/灰色背景像素全部透明。游戏中女孩左右两侧及上下方不出现任何白色、灰色或浅色条纹/bar。

## Root Cause
Sprint 67 的 BFS flood-fill 从4个角落扩散，但精灵图底部存在一条浅色分隔条（浏览器滚动条/padding区域），以及右侧列，这些区域与角落区域不连通，因此未被清除。实测：仍有 10,941 个浅色背景像素（R>190, G>190, B>190, A>10）残留。

## Acceptance Criteria
- [x] AC1: `girl.png` 中不存在 R>190 且 G>190 且 B>190 且 alpha>10 的像素（非角色像素）
- [x] AC2: 游戏截图中女孩角色左侧、右侧、上方、下方均无白色/灰色条纹
- [x] AC3: 角色像素（皮肤、衣服、头发颜色）不受影响

## Fix Approach
用更完整的背景检测替代 BFS flood-fill：
1. 识别背景色：取左上角像素颜色作为背景色基准（应为白色/浅灰）
2. 全图扫描：凡是与背景色相似（颜色距离 < 30）且 alpha > 0 的像素，全部设 alpha = 0
3. 验证：检测处理后图像，确认 R>190,G>190,B>190,A>10 的像素数为 0

## Notes
girl.png 尺寸: 880×220px，4帧（idle/blink/throw/catch）
