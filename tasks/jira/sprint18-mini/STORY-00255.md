# STORY-00255: 角色形象视觉升级

**Epic**: Mini 视觉优化
**Sprint**: Sprint 18-mini
**Sprint Goal**: 视觉体验全面提升
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character to look appealing and charming so that the game has personality.

## Expected Result
The girl character is visually attractive with expressive features, gradient colors, and clear proportions fitting a stargazer aesthetic.

## Acceptance Criteria
- [ ] Head: round with simple face (dot eyes, small curved smile), skin tone warm
- [ ] Hair: visible dark hair peeking from under hat (arc shape)
- [ ] Hat: purple/violet with brim, rounder top (not flat rectangle)
- [ ] Dress: gradient from purple to pink, curved hem, clearly feminine silhouette
- [ ] Arms: both visible — left at side, right holding net pole
- [ ] Legs: slightly more visible, with small feet/shoes hint
- [ ] Overall scale: slightly larger (GIRL_W ~60, GIRL_H ~80) for visibility on landscape screen
- [ ] Net pole attachment point unchanged (same relative offset from _poleX, _poleY)
- [ ] Character readable at full zoom-out on 667×375 canvas

## Dependencies
None
