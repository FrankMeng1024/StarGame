# STORY-00253: 关卡选择滚动修复

**Epic**: Mini 视觉优化
**Sprint**: Sprint 18-mini
**Sprint Goal**: 视觉体验全面提升
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to scroll through the level select grid smoothly so that I can access all 30 levels.

## Expected Result
Level select screen scrolls naturally when user drags finger up/down. All 6 rows of 5 levels are accessible.

## Acceptance Criteria
- [ ] Scrolling works — dragging finger up reveals more level cards below
- [ ] Scroll direction is natural: drag up → see lower rows
- [ ] No erratic jumps or large scroll steps (DPR compensation applied if needed)
- [ ] Last row (levels 26-30) is reachable by scrolling
- [ ] Tap on card works after scroll (correct scroll-offset coordinate adjustment)
- [ ] Back button always visible (fixed, not scrolled)

## Dependencies
None

## Notes
Root cause analysis: check if clientY uses physical pixels vs logical pixels in WeChat Mini Game. If canvas is 375px tall but clientY reports 750px (2× DPR), dy would be 2× too large causing jumpy scroll.
