## Description
As a player, I want all UI text and elements to be correctly sized and proportioned for the landscape mini game screen.

## Expected Result
All UI is readable, well-spaced, and visually polished at 667×375 resolution.

## Acceptance Criteria
- [ ] Button text minimum 14px, titles minimum 16px across all screens

- [ ] HUD timer and coin display: font size 18px minimum, clearly readable
- [ ] Victory/failure overlay: adequate padding (min 16px), larger result text
- [ ] Shop item rows: 60px height minimum, icon 24px, item name 14px
- [ ] Back buttons: minimum 44px tall (touch target) with readable label
- [ ] All card backgrounds have proper rounded corners (radius 10+)
- [ ] Spacing between elements: minimum 8px gap everywhere
