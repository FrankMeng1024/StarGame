# STORY-00254: 刘海屏安全区全面适配

**Epic**: Mini 视觉优化
**Sprint**: Sprint 18-mini
**Sprint Goal**: 视觉体验全面提升
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on a notch phone, I want all UI elements to be fully visible and not hidden behind the notch or home indicator.

## Expected Result
All buttons, text, and interactive elements are inset by safe area margins on all four sides across all screens.

## Acceptance Criteria
- [ ] G.SAFE_LEFT applied to all left-edge UI elements (buttons, text) in all 7 screens
- [ ] G.SAFE_RIGHT applied to all right-edge UI elements in all 7 screens
- [ ] G.SAFE_TOP already applied — verify still correct
- [ ] G.SAFE_BOTTOM already applied — verify still correct
- [ ] No UI element overlaps with notch area (left side in landscape on iPhone X+)
- [ ] Back buttons inset correctly from left edge

## Dependencies
None

## Notes
Affects: menu.js, levels.js, game.js, gallery.js, shop.js, achievement.js, intro.js. In landscape mode, notch is typically on the LEFT side. SAFE_LEFT can be 44px+ on iPhone X/11/12/13.
