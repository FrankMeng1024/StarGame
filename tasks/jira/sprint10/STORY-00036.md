# STORY-00036: 抓住星星后连线保持可见

**Epic**: E-010 新迭代改进
**Sprint**: Sprint 10
**Sprint Goal**: 核心游戏体验升级
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want constellation lines to remain visible after I catch stars, so I can see the constellation forming as I play.

## Expected Result
After a star is caught, it stays as a dim glowing dot at its original position. Constellation lines remain intact. The net carries a particle effect but not the physical star.

## Acceptance Criteria
- [ ] Caught stars remain drawn at their original x,y position (NOT moved/dragged by net)
- [ ] Caught stars rendered with reduced opacity (alpha ~0.35–0.5) and smaller glow vs uncaught
- [ ] Constellation line preview (if star_map active) shows all lines, including lines to already-caught stars
- [ ] If no star_map active, constellation lines are NOT shown during gameplay (no change to existing behavior)
- [ ] The net catch particle effect still fires on catch
- [ ] Net retracts normally; caughtObj still registers for _processCatch logic
- [ ] When all stars caught, onComplete fires as before

## Notes
Root change in engine.js:
1. In `_buildStars()`: add `originalX` and `originalY` to each star object
2. In `_processCatch()` for type=star: set `star.caught = true` but do NOT update position during retract
3. In retract update loop: only move debris objects when caught, not stars
4. In `_draw()` star rendering: draw caught stars at originalX/Y with reduced alpha/glow

The `caughtObj` reference is used only for _processCatch side effects — remove the position-dragging behavior for star type.

UX AC: Player can see the partial constellation forming as they catch stars — rewarding sense of progress.
