# STORY-00038: 道具系统重设计 — 被动/主动+赛前选择

**Epic**: E-010 新迭代改进
**Sprint**: Sprint 10
**Sprint Goal**: 核心游戏体验升级
**Points**: 8
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to choose up to 3 active items before a level starts and activate them with 1/2/3 keys during play, so item usage is strategic and satisfying.

## Expected Result
A pre-level item selection screen appears after choosing a level. Passive items apply automatically; up to 3 active items can be slotted. During play, 1/2/3 activates each slot with a visible countdown.

## Acceptance Criteria

### Classification
- [ ] 被动 items (auto-apply, no slot): double_coins (金币+100%), and any future %-based items
- [ ] 主动 items (manual, slotted): net_speed (⚡ 15s), star_magnet (🧲 30s), shrink_debris (🔬 30s), star_map (🗺️ 60s), glove (🧤 30s), space_bomb (💣 instant), time_ext (⏱️ instant +20s)

### Pre-level selection screen
- [ ] After clicking a level card, a modal/overlay appears: "选择道具 (最多3个)" before navigating to game screen
- [ ] Shows all 主动 items the player owns (qty > 0) as selectable cards
- [ ] Player can select 0–3 items; selected items highlighted with slot number (1/2/3)
- [ ] 被动 items shown separately as "自动生效" with a different visual treatment
- [ ] "开始关卡" button confirms selection and starts the game
- [ ] If player owns no 主动 items, the selection screen is skipped (go directly to game)

### In-game activation
- [ ] HUD shows 3 item slots (bottom-left or bottom area) with icon + key label (1/2/3)
- [ ] Pressing 1/2/3 activates the corresponding slot if the item has not been used and the item is available
- [ ] Each active item shows a countdown timer bar under the icon while active
- [ ] After duration expires, slot greys out (item consumed for this level)
- [ ] Instant items (space_bomb, time_ext) activate immediately on key press, no duration bar
- [ ] star_map: shows constellation line overlay on game canvas for its duration (60s)
- [ ] net_speed: boosts netSpeed for 15s, then reverts
- [ ] star_magnet: activates magnetic pull for 30s, then deactivates
- [ ] shrink_debris: shrinks debris for 30s (reset to normal after)
- [ ] glove: activates debris-no-penalty flag for 30s

### Shop updates
- [ ] Shop item descriptions updated to show 被动/主动 badge and duration

### State management
- [ ] Selected items stored in `state.selectedItems` (array of 3 or fewer item IDs) — not persisted to localStorage
- [ ] Item qty decremented only when activated (not on selection screen open)
- [ ] If player navigates away from selection screen, no items consumed

## Dependencies
- Depends on: STORY-00034 (none blocking, but rename should ship together)

## Notes
This is the largest Story in the Sprint. The pre-level selection screen can be implemented as a div overlay on `#screen-levels` or as a new screen section. Prefer overlay approach to avoid adding a new route. Active item state during gameplay needs a new object in engine: `this.activeSlots = [{id, endTime, active:false}, ...]`. Duration tracking: `Date.now() + duration_ms`. UX: slot buttons should visually respond to 1/2/3 key — brief scale animation on press.
