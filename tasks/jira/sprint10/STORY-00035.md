# STORY-00035: 降低网兜摆动速度

**Epic**: E-010 新迭代改进
**Sprint**: Sprint 10
**Sprint Goal**: 核心游戏体验升级
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the pendulum to swing slowly enough that I can time my throw strategically, so the game rewards skill rather than luck.

## Expected Result
The net swings at roughly 3–4 seconds per full cycle (Gold Miner reference). Player can visibly track the angle and decide when to fire.

## Acceptance Criteria
- [ ] `swingSpeed` updated so full swing cycle takes 3.5s (±0.5s tolerance)
- [ ] `swingMax` unchanged at ±60° — only speed changes
- [ ] Player can observe 2–3 full swings before the timer expires for level 1 (90s)
- [ ] Net extend/retract speed unchanged — only pendulum swing speed changes
- [ ] Visual confirmation: on game screen, pendulum visibly moves more slowly than previous version
- [ ] Zero console errors

## Notes
Current: `swingSpeed = (Math.PI * 2) / (1.5 * 60)` = full cycle in 1.5s at 60fps
Target: `swingSpeed = (Math.PI * 2) / (3.5 * 60)` = full cycle in 3.5s at 60fps
Change is in engine.js constructor.
