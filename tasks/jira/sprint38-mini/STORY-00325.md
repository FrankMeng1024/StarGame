# STORY-00325: 游戏计时器改为圆形倒计时环

**Epic**: Visual Parity
**Sprint**: Sprint 38-mini
**Sprint Goal**: 核心视觉差距修复
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a circular countdown ring around the timer so that I get a visual sense of urgency as time runs out, matching the web version.

## Expected Result
Game HUD center-top shows a circular arc ring (blue → red when urgent) with the countdown number in the center, instead of just plain text.

## Acceptance Criteria
- [ ] Circular ring drawn at W/2, G.SAFE_TOP+22, radius 18px
- [ ] Background ring: rgba(255,255,255,0.2), lineWidth=4, full circle
- [ ] Progress arc: from -π/2 clockwise, ratio=timeLeft/levelInitTime, color=#4fc3f7 (blue), lineWidth=4
- [ ] When timeLeft≤10s: arc color changes to #ff5252 (red)
- [ ] Timer number displayed in circle center: bold 14px, white, textAlign center
- [ ] When timeLeft≤10s: ring pulses (radius oscillates 17-19px at 2Hz) in addition to text pulse
- [ ] No overlap with level name (left) or star count (right)
- [ ] Text "M:SS" removed from center position — only the number inside ring

## Dependencies
None

## Notes
Current: `_drawHUD` draws plain text at W/2, ST+26. Replace with ring+number.
`_levelInitTime` already stored for cap — use it as denominator for ratio.
