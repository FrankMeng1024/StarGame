## Description
As a player, I want level select cards to show the constellation emoji icon, a difficulty color bar, and my best time, matching the web version's richer card design.

## Expected Result
Unlocked level cards show: emoji icon (top area) + level number (smaller) + constellation name + difficulty color bar (bottom) + best time. Visual density matches web version.

## Acceptance Criteria
- [ ] Constellation emoji icon displayed on unlocked cards: c.icon field, font size min(16, w*0.22), centered top 25% of card
- [ ] If emoji renders as tofu/blank (test on DevTools): fallback to first 2 chars of c.nameZh in purple
- [ ] Level number font reduced from w*0.28 (or current size) to w*0.22 — less dominant
- [ ] Difficulty color bar: 4px high strip at card bottom, color by c.difficulty: 1-2=#4caf50 (green), 3=#ffc107 (yellow), 4=#ff9800 (orange), 5=#f44336 (red), full card width with bottom-radius matching card
- [ ] Best time shown below star rating: "⏱ Xs" format, 8px font, rgba(255,255,255,0.65), only when state.getScore(idx).time > 0
- [ ] Card layout still fits within existing CARD_W/CARD_H — no overflow
