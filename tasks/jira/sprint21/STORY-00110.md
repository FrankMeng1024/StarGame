# STORY-00110: 关卡精灵图立即渲染 — 消除入场空白闪烁

**Epic**: E-011 性能优化
**Sprint**: Sprint 21
**Sprint Goal**: 3项用户反馈修复
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see the game canvas render immediately when a level starts, without a blank canvas flash.

## Expected Result
Character and net sprites are visible as soon as the game canvas appears.

## Acceptance Criteria
- [ ] Sprite assets declared in <link rel="preload"> in index.html — browser loads before JS runs
- [ ] game.js uses img.decode() to ensure bitmap is ready before engine starts (not just img.complete)
- [ ] If sprites already cached (complete=true), decode() is called synchronously — no timeout race needed
- [ ] No blank canvas visible on level entry

## Notes
Replaced Promise.race([preload, 50ms timeout]) with Promise.all using img.decode() which resolves instantly when cached. Added HTML preload link tags for all 6 sprite SVGs. CR-069.
