# STORY-00108: 网兜绳起点对齐角色手部

**Epic**: E-010 游戏体验修复

**Sprint Goal**: 3项用户反馈修复

## Description
As a player, I want the net rope to visually originate from the character's hand, so the animation looks physically connected.

## Expected Result
The rope/pole base aligns with the character sprite's right hand in all states (idle, throw, catch).

## Acceptance Criteria
- [ ] Idle state: rope base at character's right hand position matching sprite (SVG cx=68,cy=81 → canvas cx+13, cy-17)
- [ ] Throw state: rope base at raised right hand matching sprite (SVG cx=82,cy=20 → canvas cx+27, cy-78) and moves with swing angle
- [ ] Catch state: rope base at catch-pose hand matching sprite (SVG cx=82,cy=34 → canvas cx+27, cy-64)
- [ ] No visible gap between character sprite hand and rope start point

## Notes
Fixed _updateHandPos() to use exact SVG-derived hand coordinates instead of procedural body geometry estimates. Updated initial _handX/_handY defaults to match idle position. CR-067.
