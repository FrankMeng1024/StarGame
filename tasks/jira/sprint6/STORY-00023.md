# STORY-00023: Level select background adapts to current scene

**Epic**: E-002 (Level System)
**Sprint**: Sprint 6
**Sprint Goal**: 场景完整度 (Scene Completeness)
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player returning to the level select screen after completing levels, I want the background to reflect my current progress — the sky should match the scene of my highest unlocked level — so the game world feels continuous.

## Expected Result
The level-select screen (`#screen-levels`) background gradient updates to match the current scene palette whenever the screen is shown. Scene is determined by `Math.floor(state.maxUnlockedIdx() / 5)`.

## Acceptance Criteria
- [ ] `initLevels()` or `navigate('levels')` sets CSS custom properties (or inline style) on `#screen-levels` based on current scene
- [ ] The level select background visually matches the game canvas background for the same scene — same color family
- [ ] Fresh player (only level 1 unlocked) sees Scene 0 palette — deep blue-violet
- [ ] After unlocking level 6, returning to level select shows Scene 1 palette — cold blue-white
- [ ] Background updates on every visit to the levels screen (not just on first load)
- [ ] Zero console errors

## Dependencies
- Depends on: STORY-00022 (scene palette definitions must exist first)

## Notes
Approach: export `SCENE_PALETTES` from a shared `js/data/scenes.js` module. `initLevels` reads it; `engine.js` reads it. No duplication.
