# STORY-00024: Scene tinting on complete/fail/menu screens

**Epic**: E-002 (Level System)
**Sprint**: Sprint 6
**Sprint Goal**: 场景完整度 (Scene Completeness)
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the complete and fail screens to carry a hint of the scene color I just played, so the world feels immersive and consistent during the level result flow.

## Expected Result
When `showComplete()` or `showFail()` is called, the `#screen-complete` background gains a subtle tint matching the current level's scene palette (low-opacity overlay, not full color replacement — the dark base is preserved).

## Acceptance Criteria
- [ ] `#screen-complete` has a visible (but subtle) scene-tinted background when shown — not pure black
- [ ] The scene tint matches the palette of the last played level's scene group
- [ ] The main menu screen (`#screen-menu`) background also uses Scene 0 palette tones (it is always the starting scene)
- [ ] The tint does not reduce text legibility — star ratings, stats, and lore text remain clearly readable
- [ ] Zero console errors

## Dependencies
- Depends on: STORY-00022 (scene palette definitions)

## Notes
Approach: `showComplete()`/`showFail()` call a shared `applySceneTint(screenEl, sceneIdx)` helper that sets the element's background to a semi-transparent scene-color overlay over the existing dark base. Use `background: linear-gradient(...)` on the element's style. Do not modify main.css — apply inline style only.
