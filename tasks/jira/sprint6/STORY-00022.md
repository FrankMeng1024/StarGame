# STORY-00022: Scene-based game background themes

**Epic**: E-002 (Level System)
**Sprint**: Sprint 6
**Sprint Goal**: 场景完整度 (Scene Completeness)
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want each group of 5 levels to have a visually distinct sky background, so that progressing through the game feels like a journey through different New Zealand night-sky locations.

## Expected Result
The game canvas background changes based on scene group (floor(levelIdx / 5)):
- Scene 0 (levels 1-5): 特卡波湖牧羊人小屋 — deep blue-violet classic starry night
- Scene 1 (levels 6-10): 库克山山顶雪景 — cold blue-white ice sky
- Scene 2 (levels 11-15): 特卡波湖夏夜全景 — warm blue-indigo summer night
- Scene 3 (levels 16-20): 库克山山谷营地 — amber-tinged valley night
- Scene 4 (levels 21-25): 特卡波湖冬夜极光 — aurora green-teal winter sky
- Scene 5 (levels 26-30): 库克山破晓前最深夜空 — near-black ultra-deep pre-dawn

## Acceptance Criteria
- [ ] `_drawBackground()` in `js/game/engine.js` reads `Math.floor(this.levelIdx / 5)` to select scene palette
- [ ] 6 distinct gradient palettes defined — each clearly visually different from the others
- [ ] Scene 4 (aurora) includes faint aurora shimmer bands across the upper sky
- [ ] Background particle star density/color also varies by scene (e.g. fewer stars in pre-dawn scene)
- [ ] Playing level 1 (idx=0) shows Scene 0 palette; level 6 (idx=5) shows Scene 1 palette — verified by screenshot
- [ ] Zero console errors after background renders

## Dependencies
- None

## Notes
Implementation: define a `SCENE_PALETTES` array of 6 objects each with `{ sky0, sky1, sky2, starColor, starAlpha }`. Select by `Math.floor(levelIdx / 5)`. Aurora shimmer: 2-3 horizontal gradient bands with sin-wave animated alpha.
