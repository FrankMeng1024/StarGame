# STORY-00014: 被动道具 I — net_speed, shrink_debris, glove

**Epic**: E-003
**Sprint**: Sprint 4
**Sprint Goal**: 道具生效
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, when I start a level with net_speed, shrink_debris, or glove in my inventory, those items should automatically apply their effects for the duration of the level and consume one charge.

## Expected Result
- net_speed: net extends/retracts 50% faster
- shrink_debris: all debris rendered at 50% normal size (radius halved)
- glove: catching debris does NOT deduct 1s from timeLeft

## Acceptance Criteria
- [ ] At level start, engine reads `state.getItemQty(itemId)` for each passive item
- [ ] If qty > 0: `state.useItem(itemId)` called once, effect applied for level duration
- [ ] net_speed: `this.netSpeed` multiplied by 1.5 when item active
- [ ] shrink_debris: debris radius multiplied by 0.5 when item active (affects both rendering and collision)
- [ ] glove: `_processCatch` debris branch skips `timeLeft -= 1` when glove active
- [ ] Items consumed on use (qty decrements in localStorage)
- [ ] No effect if qty = 0 (item not owned)

## Dependencies
- None

## Notes
Items are read at engine constructor time. Engine needs an `this.activeItems = Set` property populated at init.
