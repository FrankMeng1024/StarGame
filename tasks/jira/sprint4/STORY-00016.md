# STORY-00016: 主动道具 — space_bomb + time_ext

**Epic**: E-003
**Sprint**: Sprint 4
**Sprint Goal**: 道具生效
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, when I have space_bomb or time_ext in my inventory during a level, I can activate them manually via HUD buttons.

## Expected Result
- space_bomb button visible in HUD when owned; on click: all uncaught debris removed from level, particle burst at each debris position
- time_ext button visible in HUD when owned; on click: timeLeft += 20, one charge consumed

## Acceptance Criteria
- [ ] HUD shows active-item buttons only when `state.getItemQty(itemId) > 0` at level start
- [ ] space_bomb button: on click, `this.debris` filtered to remove all uncaught debris; `state.useItem('space_bomb')` called; particle burst at each cleared debris position
- [ ] time_ext button: on click, `this.timeLeft += 20`; `state.useItem('time_ext')` called; button hidden after use (qty becomes 0)
- [ ] Buttons are pointer-events enabled (unlike the rest of the HUD overlay)
- [ ] Active item buttons styled: `.hud-item-btn` in HUD area, clearly visible against game canvas
- [ ] Buttons update/hide when qty reaches 0

## Dependencies
- STORY-00014 (activeItems pattern for HUD initialization)

## Notes
Active items are NOT consumed at level start — they are consumed on manual activation.
HUD overlay is currently `pointer-events: none` — active item buttons need `pointer-events: auto` on the button elements specifically.
