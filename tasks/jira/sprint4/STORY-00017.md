# STORY-00017: 双倍金币 + 道具应用状态提示

**Epic**: E-003
**Sprint**: Sprint 4
**Sprint Goal**: 道具生效
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, when I have double_coins in my inventory, my coin reward at level complete should be doubled. Also, I want to see which passive items are active at the start of a level.

## Expected Result
- double_coins: coins earned at level complete are multiplied by 2 if item was active
- Level start: brief toast or HUD indicator shows which items are active this run (e.g. "⚡ 网兜加速 已激活")

## Acceptance Criteria
- [ ] double_coins: if `activeItems.has('double_coins')`, coins formula becomes `Math.floor(timeLeft) * 10 * 2`
- [ ] double_coins consumed at level start (`state.useItem`)
- [ ] Level complete screen shows doubled coin count correctly
- [ ] Active items toast: at level start, if any passive items active, show a brief list overlay (3s, then fade) listing item names
- [ ] Toast does not interfere with hint system or gameplay input
- [ ] Toast element has class `.active-items-toast`, auto-removes after 3s

## Dependencies
- STORY-00014 (activeItems Set)

## Notes
double_coins multiplier must be communicated from engine to _handleComplete in game.js.
Engine can expose `this.doubleCoins` boolean, or game.js can check `activeItems` before calculating.
Simplest: engine sets `this.coinMultiplier = activeItems.has('double_coins') ? 2 : 1`; game.js uses `Math.floor(timeLeft) * 10 * coinMultiplier`.
