# STORY-00015: 被动道具 II — star_magnet + star_map overlay

**Epic**: E-003
**Sprint**: Sprint 4
**Sprint Goal**: 道具生效
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, when I start a level with star_magnet or star_map in my inventory, those items should automatically apply their effects.

## Expected Result
- star_magnet: uncaught stars within 50px of net tip move toward the net tip each frame
- star_map: semi-transparent constellation line overlay drawn on canvas during gameplay

## Acceptance Criteria
- [ ] star_magnet: in `_update`, if `activeItems.has('star_magnet')`, each uncaught star within 50px of net tip position moves toward tip by 1.5px/frame
- [ ] star_magnet: stars do not teleport — movement is gradual, capped at 1.5px per frame
- [ ] star_map: if `activeItems.has('star_map')`, `_draw` renders constellation lines (from `level.lines`) as semi-transparent gold lines (alpha 0.25) beneath stars
- [ ] Both items consumed at level start (`state.useItem()`)
- [ ] No effect if qty = 0

## Dependencies
- STORY-00014 (activeItems Set pattern)

## Notes
Net tip position: `charX + sin(swingAngle) * poleLen * netPos * (max extend ratio)` — check engine._getNetTip() or compute inline.
Constellation lines array is `level.lines` (array of [starIdxA, starIdxB] pairs).
