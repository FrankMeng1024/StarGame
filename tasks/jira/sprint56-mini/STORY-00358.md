# STORY-00358: 全局Header统一 — drawHeaderBar函数+三屏对齐

**Epic**: Visual Polish
**Sprint**: Sprint 56-mini
**Sprint Goal**: 全局视觉风格统一升级
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want all secondary screens (shop, levels, gallery) to have a consistent header bar with unified back button and title style, so the game feels cohesive and premium.

## Expected Result
shop.js、levels.js、gallery.js 顶部header外观完全一致：半透明深色底条、统一尺寸返回按钮、Ma Shan Zheng标题居中。

## Acceptance Criteria
- [ ] `canvas-utils.js` 新增 `drawHeaderBar(ctx, W, H, title, opts)` 函数，返回backRect
- [ ] header条：高度 = SAFE_TOP + 48px，背景 `rgba(5,3,18,0.72)`，底部1px分割线 `rgba(160,100,255,0.25)`
- [ ] 返回按钮：x=SAFE_LEFT+10, w=72, h=32, 圆角10，`rgba(30,16,80,0.85)` 填充，`rgba(120,80,220,0.5)` 边框，`#f0e0ff` "← 返回" 12px sans-serif
- [ ] 标题：居中，Ma Shan Zheng(已加载)/serif fallback，22px，`#e8d5ff`，shadowBlur=8 `rgba(160,120,255,0.5)`
- [ ] shop.js 改用 `drawHeaderBar()`，删除手写header代码
- [ ] levels.js 改用 `drawHeaderBar()`，删除手写header代码
- [ ] gallery.js 改用 `drawHeaderBar()`，删除手写header代码（主列表视图）
- [ ] 三屏截图比较：header外观视觉一致
