# STORY-00359: 道具商店视觉升级 — 单列宽卡+大图标+深空背景

**Epic**: Visual Polish
**Sprint**: Sprint 56-mini
**Sprint Goal**: 全局视觉风格统一升级
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the item shop to feel premium and spacious like the gallery and levels screens, not cramped and plain.

## Expected Result
道具商店改为单列大卡片布局，每个道具有大图标、两行描述、右侧独立价格+购买按钮，背景有星云辉光，整体与图鉴/关卡视觉档次一致。

## Acceptance Criteria
- [ ] 布局改为单列（COLS=1），CARD_H = clamp(110, H*0.18, 130)
- [ ] 卡片左侧图标区：宽=CARD_H，图标r=CARD_H*0.28，发光圆底座+canvas图案（复用现有_drawItemIcon逻辑，等比放大）
- [ ] 卡片背景：深紫-蓝渐变 `rgba(10,6,36,0.92)` → `rgba(22,14,58,0.88)`，顶部1px白色高光 `rgba(255,255,255,0.07)`，无strokeStyle描边
- [ ] 卡片间距 CARD_GAP=10，无描边分隔
- [ ] 描述文字：12px，`rgba(255,255,255,0.65)`，允许两行（超出截断+…）
- [ ] 价格标签：右侧金色 `🪙 N` bold 14px，独立显示
- [ ] 购买按钮：w=80px，右对齐，`#4422aa`→`#7744cc`，圆角8
- [ ] 背景添加3个星云椭圆（复用gallery的_drawNebulae逻辑，位置偏右避开卡片区）
- [ ] 背景星场：initBgStars使用sin-hash seed，100颗
- [ ] 使用STORY-00358实现的 `drawHeaderBar()` 渲染header，右侧显示 `🪙 coins`
- [ ] 截图：商店整屏，可清晰看到图标、描述、价格、按钮
