# STORY-00317: 封面按钮布局优化 — 消除拥挤感，增加呼吸空间

**Epic**: E-033 跨平台对标
**Sprint**: Sprint 35-mini
**Sprint Goal**: 开局动画视觉修复 + 封面布局优化 + 星座图鉴列表&详情重设计
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the main menu buttons to feel spacious and well-organized, not cramped or overlapping with empty areas elsewhere.

## Expected Result
Main menu (landscape): buttons are taller, better spaced, start lower (away from title), constellation info panel does not overlap button column.

## Acceptance Criteria
- [ ] Landscape模式：BH = max(34, min(40, (H - safe - 80) / 3))（更高按钮）
- [ ] Landscape模式：GAP从当前(8px)改为14px
- [ ] 按钮起始Y = H * 0.38（远离标题，避免拥挤）
- [ ] 星座信息面板与按钮列水平不重叠（面板在星座canvas区域内，按钮在右列）
- [ ] Portrait模式：BH = max(44, min(52, ...))，GAP = 16
- [ ] 截图验证：menu截图显示按钮有明显间距，不拥挤
- [ ] 截图亮度 > 10
