# STORY-00274: 胜利连线动画减速 + 停留闪烁

**Epic**: E-003 Visual Polish
**Sprint**: Sprint 22-mini
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the constellation line-drawing animation to feel satisfying — slow connection, a brief linger with stars twinkling, before the result card appears.

## Expected Result
Line drawing speed slowed to 0.35s per line (was 0.12s). After all lines drawn, a 1.5s "linger" phase where all stars pulse/flash before auto-advancing to result card.

## Acceptance Criteria
- [ ] `totalDuration = Math.max(totalLines * 0.35, 1.5)` — slowed from 0.12
- [ ] After `_lineDrawProgress >= totalLines`: enter new `_phase = 'linger'` (not immediately 'result')
- [ ] During linger phase (1.5s): all constellation stars draw with pulsing alpha (sin wave, period ~0.6s)
- [ ] After linger timer expires: advance to `_phase = 'result'`
- [ ] Tapping during linger skips to result (same as current celebrate/linedraw skip behavior)
- [ ] `_lingerTimer` variable added, reset to 1.5 on linger phase entry
