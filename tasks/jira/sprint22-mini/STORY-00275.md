# STORY-00275: 首页按钮透明化 — ghost风格

**Epic**: E-003 Visual Polish
**Sprint**: Sprint 22-mini
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want the home screen buttons to feel light and non-crowded by using semi-transparent ghost styling, so the starry background breathes through.

## Expected Result
`_drawMenuButton` updated to use transparent fill with border-only ghost style. Background shows through buttons. Primary button has brighter border, secondary has soft border. Text remains readable.

## Acceptance Criteria
- [ ] Primary button fill: `rgba(160,0,220,0.28)` (semi-transparent purple, not solid gradient)
- [ ] Secondary button fill: `rgba(80,0,160,0.20)` (more transparent)
- [ ] Primary border: `rgba(200,80,255,0.80)` gold-purple line w=1.8
- [ ] Secondary border: `rgba(160,100,255,0.55)` soft purple line w=1.2
- [ ] Primary text: `#ffe566` (gold) — unchanged
- [ ] Secondary text: `#f0e0ff` — unchanged
- [ ] Glass highlight: reduced to `rgba(255,255,255,0.10)` (was 0.18) — subtle
- [ ] Shadow: reduced blur (primary 12, secondary 8 — was 18/12) to feel lighter
- [ ] Stars background visibly shows through buttons (verified by screenshot)
