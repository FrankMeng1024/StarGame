# STORY-00273: 星星尺寸缩小 + 最小间距防重叠

**Epic**: E-003 Visual Polish
**Sprint**: Sprint 22-mini
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want stars to be appropriately sized and never overlapping each other, so that the game looks clean and each star is individually catchable.

## Expected Result
Max star radius reduced from 10 to 8. Star placement uses minimum separation check to prevent two stars from appearing within 2 * maxRadius + 6px of each other.

## Acceptance Criteria
- [ ] `Math.max(3, Math.min(8, magToRadius(s.mag) * 1.4))` — max capped at 8 (was 10)
- [ ] Star placement checks minimum separation: if a new star is within `(r1 + r2 + 6)` of any existing star, re-position it (up to 10 retries, then skip)
- [ ] Separation check uses the same skyX0/skyX1/skyY0/skyY1 bounds
- [ ] Verified: no two stars visually overlapping in levels 0–4 (Orion, Ursa Major, Scorpius, Taurus, etc.)
