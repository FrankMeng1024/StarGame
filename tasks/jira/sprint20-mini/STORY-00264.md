# STORY-00264: 包体瘦身 — bgm.mp3压缩至<1MB

**Epic**: E-001
**Sprint**: Sprint 20-mini
**Sprint Goal**: 修复真机4个Blocker缺陷
**Points**: 2
**Owner**: Backend Dev
**Status**: Done

## Description
As a player, I want the game to load without a "source size exceed max limit 4MB" error.

## Expected Result
WeChat Mini Game package uploads and previews successfully. Package total < 4MB.

## Acceptance Criteria
- [ ] bgm.mp3 compressed to ≤ 900KB (from 2.9MB) — audio quality acceptable for BGM use
- [ ] Total miniprogram/ package size ≤ 3.8MB (verified with `du -sh miniprogram/`)
- [ ] BGM still plays correctly in game (wx.createInnerAudioContext src unchanged)
- [ ] No other audio files removed or degraded

## Root Cause
bgm.mp3 is 2.9MB. Total package is 4.5MB > 4MB WeChat limit (error code 80051).
Fix: re-encode bgm.mp3 at lower bitrate (64kbps CBR or equivalent) using ffmpeg.
