# STORY-00267: 少女角色重绘v3 — 比例正确，视觉精美

**Epic**: E-001
**Sprint**: Sprint 20-mini
**Sprint Goal**: 修复真机4个Blocker缺陷
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character to look visually appealing and correctly proportioned so the game feels polished.

## Expected Result
The girl character looks like a proper anime-style character on real device. Proportions correct. Not too large relative to game area.

## Acceptance Criteria
- [ ] Character total height ≤ 80px (down from 110px) — appropriate for 667px-tall landscape screen
- [ ] Character is drawn with CORRECT anime head:body ratio — head is roughly 1/4 of total height
- [ ] Face is clearly visible: eyes, eyebrows, smile (3 distinct features, not just dots)
- [ ] Dress has gradient fill (two-stop linear gradient, purple→pink)
- [ ] Hair is distinct and identifiable (dark color, not same as skin/dress)
- [ ] Both arms visible with throwing arm raised toward the net pole
- [ ] Character does not overlap with HUD elements (timer, score)
- [ ] Character anchor point (_poleX, _poleY) unchanged — net physics unaffected

## Design Notes
Sprint 18/19 increased GIRL_H to 110px. On real device this is too large.
The character must be redesigned to be:
1. Smaller (≤80px height so she doesn't dominate the bottom of the screen)
2. Better proportioned (the 110px version was "ugly and too big" per user feedback)
3. The drawing primitives must produce a visually appealing result — curves, not angular shapes

## UX Acceptance Criteria
- [ ] Character reads as a cute anime-style girl at first glance (not geometric shapes)
- [ ] Character is clearly visible against dark sky background
- [ ] Character does not obstruct star-catching play area

## Notes
Root cause: code-path QA cannot verify visual quality. User confirmed on real device that the character is "very ugly" with wrong proportions. Full redraw needed — this is a known limitation of code-review-only QA for visual features.
