# BUG-00268-STORY-00266: achievement.js touchStart/touchMove missing G.DPR

**Priority**: Critical
**Sprint**: Sprint 20-mini
**Opened by**: QA
**Status**: Verified

## Description
`_onTouchStart` and `_onTouchMove` in `achievement.js` used raw `t.clientY` without multiplying by `G.DPR`. Only `_onTouchEnd` applied the DPR correction. On DPR>1 devices, achievement screen scroll distance was incorrectly scaled (1/DPR times too slow).

## Steps to Reproduce
1. Open achievement screen on DPR=3 device (iPhone)
2. Try to scroll the constellation grid
3. Scroll moves 3× too slow or erratic

## Expected
Scroll responds correctly — same behavior as levels/shop/gallery screens.

## Actual
Scroll distance off by DPR factor.

## Root Cause
Copy-paste inconsistency — achievement.js used `e.touches[0]` (not `e.changedTouches[0]`) in start/move handlers, written before G.DPR pattern was established.

## Fix
Changed `achievement.js` lines 200 and 208-210:
- `_lastTouchY = t.clientY * G.DPR`
- `const rawY = t.clientY * G.DPR; const dy = _lastTouchY - rawY; _lastTouchY = rawY;`

**Fix verified by syntax check — node --check passed.**
