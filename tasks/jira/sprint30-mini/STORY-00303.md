**Points**: 3

## Description
As a player, when I complete a level, I want to see each star light up brightly as the constellation lines connect through them, matching the web version experience.

## Expected Result
通关后：先看到星座里的星星从暗→亮逐颗点亮（随连线绘制逐一reveal），然后连线从一颗亮星延伸到下一颗亮星。最终所有星星发光，全部连线完成。与HTML版本 `complete.js._runConstellationAnim()` 一致。

## Acceptance Criteria
- [ ] **动画逻辑**: 连线绘制时，连接到的星星同步亮起（globalAlpha从0.3→1.0，shadowBlur从r*1→r*3）
- [ ] 具体：`_drawAnimatedConLines`执行到第i条线时，lines[i]的两端星星(ai,bi)亮起
- [ ] **参照Web**: `complete.js:334-346` — `revealedStars.has(i)` 控制星星亮度，与连线进度同步
- [ ] mini版本中：`_drawStars`在linedraw阶段需要区分"已reveal"和"未reveal"的星星
- [ ] 已reveal星星：alpha=0.95，shadowBlur=r*3，颜色完整
- [ ] 未reveal星星：alpha=0.35，shadowBlur=r*1，颜色dim
- [ ] linger阶段所有星星全亮，保持pulse效果（已有`_drawLingerFlash`）
- [ ] Playwright截图：linedraw阶段截图显示部分亮/部分暗的对比效果

## Notes
Web版`complete.js`动画：
- `revealedStars = new Set()` 追踪已连线的星星
- 当第i条线完成时：`revealedStars.add(lines[i][0]); revealedStars.add(lines[i][1])`
- 星星绘制时：`globalAlpha = revealed ? 1 : 0.3`

Mini版需要同样的机制。当前`_drawAnimatedConLines`只画线，不影响`_drawStars`。
修复方案：在game.js增加`_revealedStarSet`，在`_updateLineDrawProgress`中随进度add star indices，在`_drawStars`的linedraw/linger阶段用此Set控制亮度。
