## Description
As a player, I want the game to show the intro animation immediately after scanning the QR code, so that I don't see a black screen.

## Expected Result
扫码后1秒内出现开场动画（流星雨/星座），不出现任何黑屏帧。

## Acceptance Criteria
- [ ] 在微信开发者工具中点击预览→真机扫码，5秒内出现开场动画，无黑屏
- [ ] canvas.width/canvas.height 在 boot() 时不为 0（加 console.log 验证）
- [ ] `requestAnimationFrame(() => navigate('intro'))` 在canvas尺寸有效后才执行
- [ ] 若canvas尺寸为0时：fallback到wx.getSystemInfoSync()重新设置尺寸再navigate
- [ ] web版(localhost:8090) Playwright截图对比：intro首帧可见
