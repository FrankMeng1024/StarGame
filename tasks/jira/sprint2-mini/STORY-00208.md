# STORY-00208: 星星目标 — 按星座数据分布 + 抓取消除

**Epic**: E-M01 核心游戏
**Sprint**: Sprint 2-mini
**Sprint Goal**: 核心游戏完整可玩
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see the constellation's stars positioned according to real star chart coordinates, with visual cues for magnitude and spectral type, so that catching them feels meaningful and educational.

## Expected Result
Level N shows stars from CONSTELLATIONS[N].stars, positioned in the sky area (top 70% of screen), sized by magnitude, colored by type, slowly twinkling. Catching a star → gold particle burst → star disappears → caught counter increments.

## Acceptance Criteria
- [ ] Stars loaded from `CONSTELLATIONS[state.currentLevel].stars`
- [ ] Star position: normalized (s.x, s.y) mapped to sky area (x: [16, W-16], y: [60, H×0.62])
- [ ] Star radius: magToRadius(s.mag) × 1.4, clamped [3..14]px
- [ ] Star color: typeToColor(s.type) from constellations.js
- [ ] Twinkle animation: alpha oscillates using Math.sin(t×speed + phase)
- [ ] On catch: star removed from active array; gold particles (6 dots expanding outward, 400ms)
- [ ] Caught count displayed in HUD (see STORY-00210)
- [ ] Constellation lines drawn as thin gold lines between connected star positions (from CONSTELLATIONS[N].lines)
- [ ] No console errors

## UX AC
- [ ] Stars are visually distinct from background star field (larger, brighter, colored)
- [ ] Catching a star has satisfying visual feedback

## Dependencies
- Depends on: STORY-00207 (net collision system)

## Notes
magToRadius and typeToColor already exported from constellations.js — reuse directly.
Sky area = y:[60, H×0.62] avoids overlap with ground silhouette.
Constellation line opacity: 0.25 (subtle guide).
