# STORY-00207: 网兜机制 — 摆动 + 发射 + 收回 + 碰撞

**Epic**: E-M01 核心游戏
**Sprint**: Sprint 2-mini
**Sprint Goal**: 核心游戏完整可玩
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to swing a net that automatically oscillates left/right, and tap the screen to launch it upward at the current angle, catching the first object it hits, so that I can play the core game mechanic.

## Expected Result
Net hangs from girl's hands and swings ±80° at ~3.5s per full cycle. Tap → net extends along current angle → hits first star/debris → retracts → continues swinging.

## Acceptance Criteria
- [ ] Net pole hangs from girl character position (W/2, H×0.82)
- [ ] Net oscillates left-right: angle = Math.sin(t × swingSpeed) × 80° (swingSpeed ≈ TWO_PI/(3.5×60))
- [ ] Tap canvas → net begins extending along current angle at ~8px/frame
- [ ] Net extends max 55% of screen height; if no hit → retracts automatically
- [ ] On hit (collision circle ~20px radius around net head vs object center): captures object, immediately retracts
- [ ] Retract speed: same as extend speed
- [ ] Only one launch active at a time; tap during active launch = ignored
- [ ] Net is drawn as a simple line + small circle at head, from girl's hand to current net position
- [ ] No console errors during continuous play (5 launches)

## UX AC
- [ ] Swing speed feels deliberate (not frantic) — player can aim
- [ ] Tap feedback is immediate (net visibly starts moving on same frame)

## Dependencies
- Depends on: STORY-00206

## Notes
swingSpeed = Math.PI * 2 / (3.5 * 60) (matches HTML5 version CR-010)
Net head position: pole.x + Math.sin(angle)×length, pole.y - Math.cos(angle)×length
touchstart = fire; touchend not needed for firing (tap-to-shoot not hold)
