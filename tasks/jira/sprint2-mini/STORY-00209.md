# STORY-00209: 宇宙垃圾 — 4种类型 + 自转 + 时间惩罚

**Epic**: E-M01 核心游戏
**Sprint**: Sprint 2-mini
**Sprint Goal**: 核心游戏完整可玩
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see space debris scattered in the sky that I need to avoid catching, so that the game has challenge and tension.

## Expected Result
3–5 debris objects (count scales with level difficulty) float in the sky area. Each type has a distinct drawn shape. Catching debris → net retracts immediately → 1 second time penalty shown in HUD.

## Acceptance Criteria
- [ ] Debris count: 2 + Math.floor(CONSTELLATIONS[levelIdx].difficulty × 0.8), max 5
- [ ] Debris types: 'meteor', 'satellite', 'rocket', 'cloth' — distributed randomly across sky area
- [ ] Each type has a distinct Canvas drawing (no generic circles):
  - meteor: jagged polygon (5-7 sides, irregular) with orange glow
  - satellite: rectangle body + two thin rectangles as solar panels
  - rocket: elongated pentagon with nozzle circle
  - cloth: wavy bezier outline
- [ ] Debris rotates slowly (spin: 0.01–0.03 rad/frame)
- [ ] Debris radius for collision: 14–18px
- [ ] On catch: net retracts → 1.0s removed from timer → red flash on HUD timer for 0.5s
- [ ] Debris stays in place after being caught (does NOT disappear — can be caught again)
- [ ] No console errors

## UX AC
- [ ] Debris is visually distinguishable from stars (shape + color — not points of light)

## Dependencies
- Depends on: STORY-00207 (net collision)

## Notes
Debris positions: fixed at game-start, randomly distributed in sky area.
Debris does NOT move (simplification for Sprint 2 — moving debris in Sprint 3 if needed).
