# STORY-00210: HUD + 时间 + 胜负判定 + 金币结算

**Epic**: E-M01 核心游戏
**Sprint**: Sprint 2-mini
**Sprint Goal**: 核心游戏完整可玩
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a countdown timer, caught/total star count, and level name, so that I understand the game state, and have win/loss conditions that trigger the completion screen.

## Expected Result
HUD shows timer (red when ≤15s), caught/total count. Timer depletes in real time. Catch all stars → victory. Timer hits 0 → failure. Either → navigate('result') with result data.

## Acceptance Criteria
- [ ] Timer starts at: difficulty 1→90s, 2→80s, 3→70s, 4→60s, 5→50s (per PRD F-004)
- [ ] Timer decrements in real-time (using delta-time, not frame count)
- [ ] Timer display: "MM:SS" format, top-right of HUD bar
- [ ] Timer text turns red when ≤15s remaining
- [ ] HUD bar: semi-transparent strip at top (y=0 to 52px): level name center, timer right, caught/total left
- [ ] caught/total: "已抓: N / M" format
- [ ] Victory condition: caught === total stars → navigate('result', {victory:true, timeLeft, coins})
- [ ] Failure condition: timer ≤ 0 → navigate('result', {victory:false, timeLeft:0, coins:0})
- [ ] Coins on victory: Math.floor(timeLeft) × 10
- [ ] state.coins += coins earned (via state.addCoins)
- [ ] state.setScore(levelIdx, {stars: coinsToStars(coins), time: timeLeft}) called on victory
- [ ] No console errors during full play (launch net multiple times until level ends)

## UX AC
- [ ] Timer urgency at ≤15s is immediately noticeable without reading text
- [ ] HUD is legible against all 6 scene backgrounds

## Dependencies
- Depends on: STORY-00208 (caught count), STORY-00209 (time penalty)
