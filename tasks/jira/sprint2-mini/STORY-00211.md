# STORY-00211: 通关/失败屏幕 — 结算卡 + 星座故事 + 导航按钮

**Epic**: E-M01 核心游戏
**Sprint**: Sprint 2-mini
**Sprint Goal**: 核心游戏完整可玩
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a result screen after the level ends showing my score, earned coins, star rating, and a brief constellation story excerpt, so that the game feels complete and rewarding.

## Expected Result
After victory or failure, a full-screen result card appears. Victory: shows stars earned, coins, time, constellation name + 2-sentence lore excerpt, [下一关] [返回选关]. Failure: shows "再试一次" + encouragement text, [重试] [返回选关].

## Acceptance Criteria
- [ ] Result screen shows as overlay on game canvas (no new Canvas)
- [ ] Victory card shows: ★ rating (1–3 stars), coins earned (e.g. "+350金币"), time left (e.g. "剩余35秒"), constellation nameZh + lore first 80 chars + "…"
- [ ] Star rating: 3 stars if coins ≥ 300, 2 stars if ≥ 100, 1 star otherwise
- [ ] Victory card has "通关！" headline in gold, constellation icon
- [ ] Failure card shows: "时间到！" headline in red, "还差N颗星" (how many not caught), [重试] button
- [ ] [下一关] button: navigates to game with state.currentLevel = (levelIdx + 1) % 30, unlocks next level
- [ ] [返回选关] button: navigate('levels')
- [ ] [重试] button (failure): navigate('game') with same level
- [ ] Unlocks next level on victory: state.unlock(levelIdx + 1) (if levelIdx < 29)
- [ ] No console errors on result screen

## UX AC
- [ ] Result card is visually distinct from game background (clear overlay)
- [ ] Player can act immediately (buttons respond on first tap)
- [ ] Lore text readable (font size ≥ 13px, high contrast)

## Dependencies
- Depends on: STORY-00210 (victory/failure trigger + result data)
