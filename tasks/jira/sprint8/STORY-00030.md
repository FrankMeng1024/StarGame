## Description
As a player who unlocks a constellation, I want to see structured astronomical metadata (sky region, best viewing month, main stars) on the gallery detail page, so that the gallery delivers educational value as promised.

- [ ] Metadata is visible for unlocked constellations (Orion unlocked via fresh state + completing Level 1)
- [ ] Metadata section is styled consistently with the rest of the detail page (dark theme, gold accents)
- [ ] No JavaScript errors in browser console after navigating to gallery detail
