# STORY-00031: Mute Button Accessible from Main Menu

**Epic**: E-001 Core UX
**Sprint**: Sprint 8
**Sprint Goal**: VU closure — gallery metadata + menu mute button
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player who opens the game, I want to mute/unmute the background music from the main menu, so that I can control audio immediately without having to enter a level first.

## Expected Result
A mute button is visible and functional on the main menu screen. Clicking it toggles BGM on/off with visual feedback. The button works the same as the existing in-game mute button.

## Acceptance Criteria
- [ ] A mute/unmute button is visible on the main menu screen (not hidden, not zero-size)
- [ ] Clicking the button toggles BGM mute state and updates the button icon (🔊/🔇)
- [ ] Mute state persists when entering a level (button in-game reflects same state)
- [ ] Button is styled consistently with the menu's visual design (no layout breaks)
- [ ] No JavaScript errors in browser console after clicking the mute button on the menu

## Dependencies
- None

## Notes
VU complaint: "Mute button rendered at width=0 height=0 on menu screen — effectively invisible/non-functional from user perspective on main menu."
Root cause: #mute-btn is inside #screen-game HUD which is display:none on menu screen.
Implementation: add a mute button directly to #screen-menu HTML, wire click handler to audioManager.toggleMute() same as the existing in-game button.
