# STORY-00239: 胜利lore"完成✓"按钮 — 点击后退出结算卡

**Epic**: E-007
**Sprint**: Sprint 11-mini
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done
**Origin**: UX friction item — Sprint 10-mini review

## Description
On the victory result screen, after reading all lore pages, tapping "完成 ✓" is currently a no-op. A first-time user expects the button to dismiss the lore or navigate forward, but nothing happens — they must discover that the 重试/选关/next-level buttons below still work.

## Acceptance Criteria
- [ ] Tapping "完成 ✓" on the last lore page scrolls/shifts focus to show the result action buttons (重试, 选关, 下一关)
- [ ] OR: "完成 ✓" tap collapses the lore section in-place so buttons become visible
- [ ] No regression on lore pagination navigation (下一段 ›)

## Notes
Current code: touch handler calls `_lorePage++` when `_btnLoreNext` hit — on last page this goes out of bounds but nothing else happens. Fix: detect `_lorePage >= _lorePages.length - 1` before increment; if already last page, signal completion (e.g. set `_lorePages = []` to hide lore section, or scroll card offset).
