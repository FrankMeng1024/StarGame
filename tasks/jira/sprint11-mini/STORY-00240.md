# STORY-00240: 展厅星座照片轮播 — wx.downloadFile + 本地fallback

**Epic**: E-006
**Sprint**: Sprint 11-mini
**Points**: 4
**Owner**: Frontend Dev
**Status**: Done

## Description
Gallery detail view must show real constellation/astrophotography images per PRD F-007 ("图片轮播，5-10张真实图片"). Mini game package size limit (~2MB) prevents bundling photos locally. Solution: use `wx.downloadFile` to fetch images from a remote CDN on demand, with a Canvas-drawn fallback if download fails or is slow.

## Acceptance Criteria
- [ ] Gallery detail shows at least 1 real astrophotography image per constellation (horizontal swipe carousel or single image display)
- [ ] Images loaded via `wx.downloadFile` (wx.createImage with remote src, or download to temp file then draw)
- [ ] Loading state shown while image fetches (spinner/placeholder text "加载中...")
- [ ] If image fails to load (network error, timeout): graceful fallback — show constellation silhouette or "暂无图片" placeholder, no crash
- [ ] At least the top 5 most prominent constellations (猎户座, 大熊座, 天蝎座, 狮子座, 金牛座) have valid working image URLs
- [ ] No regression on lore text, metadata display, back/prev/next navigation

## Notes
WeChat mini game image loading: `wx.createImage()` returns an Image object that can be drawn on Canvas with `ctx.drawImage()`. For remote URLs, set `img.src = url` — WeChat will download it. Must add the CDN domain to `app.json` `downloadFile.domain` and `navigateTo` domain whitelist.

Use reliable public domain astronomy image CDN — NASA APOD CDN or Wikimedia Commons direct file URLs are good choices (already used in HTML5 branch). Pick 1 representative image per constellation to keep it manageable. Store URLs in `constellations.js` as a new `photo` field.

Simplest approach: single photo per constellation shown in detail view (not a multi-image carousel), with swipe/tap to expand. The PRD says "轮播" but 1 working photo beats 0 photos.

AC operationalization: "at least 1 real astrophotography image" is testable by code-path — verify `c.photo` URL field exists for ≥5 constellations and `_drawPhoto()` function exists and is called in detail view.
