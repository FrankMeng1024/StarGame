# STORY-00243: 黑屏修复 — boot()即时启动，auth后台异步

**Epic**: E-001 核心体验
**Sprint**: Sprint 14-mini
**Sprint Goal**: 黑屏修复+横屏适配 — 扫码即开，横屏可玩
**Points**: 3
**Owner**: Backend Dev / Frontend Dev
**Status**: Done

## Description
As a user scanning the WeChat DevTools preview QR code on a real device, I want to see the menu immediately instead of a black screen, so that the game is usable.

## Expected Result
After scanning QR code, main menu appears within 1 second. No black screen.

## Acceptance Criteria
- [ ] boot() calls navigate('menu') synchronously before any await
- [ ] StorageAdapter.loadSaveLocal() exists and returns local save synchronously
- [ ] auth + cloud sync happen in background after menu is visible
- [ ] If network fails, game still starts normally with local/default save data
- [ ] Menu appears with title, constellation, and 3 navigation buttons

## Notes
Root cause: original boot() awaited AuthManager.login() + StorageAdapter.loadSave() before calling navigate(). With 10s network timeout × 2 calls = up to 20s black screen on real devices.

Fix: Added loadSaveLocal() synchronous method, restructured boot() to navigate immediately.
