# STORY-00244: 横屏适配 — game.json landscape + menu双栏布局

**Epic**: E-001 核心体验
**Sprint**: Sprint 14-mini
**Sprint Goal**: 黑屏修复+横屏适配 — 扫码即开，横屏可玩
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on a real WeChat device, I want the game to render in landscape orientation with a proper layout, so that the gameplay experience matches the design intent.

## Expected Result
- Device forces landscape orientation (game.json deviceOrientation: landscape)
- Menu: constellation fills left half, title + 3 buttons in right half
- All other screens (levels, game, gallery, shop) render correctly in landscape

## Acceptance Criteria
- [ ] game.json has "deviceOrientation": "landscape"
- [ ] Menu landscape layout: constellation visible on left, title+buttons visible on right
- [ ] Menu buttons are all tappable (correct hitbox positions)
- [ ] Levels screen renders correctly (5-col grid, scrollable)
- [ ] Game screen renders correctly (net swings, stars visible)
- [ ] Gallery screen renders correctly (3-col grid)
- [ ] Shop screen renders correctly (scrollable list)
- [ ] No layout overflow or clipped UI in landscape on H≈390 screen

## Notes
game.json was set to "portrait" which caused wrong orientation on real devices.
menu.js _buildConLayout() and _loop() updated with isLandscape branch.
Other screens (game, levels, gallery, shop) are scroll-based and work proportionally.
