# STORY-00123: 标签页自动暂停 + 网兜状态机边界修复

**Epic**: E-009 情感体验打磨 + 稳定性
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家, I want the game to automatically pause when I switch tabs (Q2), and I want rapid clicking to never cause the net to glitch (Q3).

## Expected Result
(1) 切换标签页时游戏自动暂停，回来时需手动恢复。(2) 快速连续点击/按空格时网兜状态机不会进入不一致状态。

## Acceptance Criteria
**Q2 — 标签页自动暂停**:
- [ ] 在 `js/screens/game.js` 的游戏启动逻辑中，注册 `document.addEventListener('visibilitychange', ...)` 事件监听
- [ ] 当 `document.hidden === true` 时，若游戏正在进行（非已暂停、非完成/失败），自动触发暂停（调用与 pause 按钮相同的暂停逻辑）
- [ ] 当 `document.hidden === false` 时，不自动恢复（让玩家主动点"继续"），避免玩家措手不及
- [ ] 游戏结束时（complete/fail）移除该事件监听，避免内存泄漏

**Q3 — 状态机边界修复**:
- [ ] 在 `game/engine.js` 的输入处理函数（`_handleInput` 或 click/keydown 处理）中添加最小延伸时长保护：发射后100ms内的重复输入被忽略
- [ ] 添加状态守卫：`if (this._netState === 'extending' && performance.now() - this._extendStart < 100) return;`
- [ ] 现有的 `_netState` 变量在每次合法发射时记录 `this._extendStart = performance.now()`
- [ ] 手动验证：在游戏中以最快速度连续按空格10次，网兜动画始终保持正常收放周期

## Dependencies
- 无

## Notes
Q2：`visibilitychange` 监听器需在 `stopGame()` 时通过 `removeEventListener` 清理。Q3：`_extendStart` 初始化为 `0`，保证第一次点击不被误判。
