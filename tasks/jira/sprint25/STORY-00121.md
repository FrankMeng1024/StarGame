# STORY-00121: 星座故事分段翻页

**Epic**: E-009 情感体验打磨
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家 who just completed a level, I want to read the constellation lore in short paginated segments, so that I can absorb each part during the celebration rather than scrolling through a wall of text.

## Expected Result
关卡完成屏幕的 lore 文本分成2-4个段落（按中文句号/换行分割），每次显示一段，配翻页按钮和页码指示器。

## Acceptance Criteria
- [ ] lore 文本按 `。\n` 或连续两个换行符分割，每段最多120字，自动合并短句（<30字的段合并到下一段）
- [ ] 初始显示第1段，底部有 "第1/N段 · 下一段 ›" 按钮
- [ ] 最后一段时按钮文本变为 "完成 ✓"，点击触发现有的完成后CTA显示逻辑
- [ ] 段落切换有淡入动画（opacity 0→1，150ms）
- [ ] 页码指示器：小圆点（每段一个），当前段为金色，其余为半透明白
- [ ] lore 文本容器高度固定（min-height: 120px），切换段落时不引起布局跳动
- [ ] 若 lore 文本只有1段（<80字），直接显示完整文本，不显示翻页控件

## Dependencies
- 无

## Notes
修改文件：`js/screens/complete.js` 的 `showComplete()` 中的 lore 渲染部分。分段逻辑：`const segments = lore.split(/。\n|。(?=\n)|(?<=。)\s{2,}/).filter(s => s.trim().length > 0);`（处理换行分隔的自然段落）。
