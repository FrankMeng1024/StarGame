# STORY-00124: localStorage 静默降级

**Epic**: E-009 稳定性
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家 in a restricted browser environment (private mode, Safari), I want the game to continue running even if localStorage is unavailable, so that I never see an unexpected crash or error.

## Expected Result
`storage.js` 的所有读写操作在 localStorage 不可用时静默降级，游戏以内存状态继续运行。

## Acceptance Criteria
- [ ] `storage.js` 中新增模块级变量 `let _storageAvailable = true`
- [ ] 模块加载时执行一次可用性探测：`try { localStorage.setItem('_sc_test','1'); localStorage.removeItem('_sc_test'); } catch(e) { _storageAvailable = false; }`
- [ ] `saveGame()` 函数：若 `!_storageAvailable` 直接 return（不尝试写入）；现有 try-catch 保留
- [ ] `loadGame()` 函数：若 `!_storageAvailable` 直接 return null；现有 try-catch 保留
- [ ] `clearGame()` 函数：若 `!_storageAvailable` 直接 return
- [ ] 无 `console.error`、无 `alert`、无任何用户可见提示（静默降级）
- [ ] `console.warn` 在探测失败时输出一次 `'[StarCatcher] localStorage unavailable, running in memory-only mode'`（可接受）

## Dependencies
- 无

## Notes
现有 storage.js 已有 try-catch，此次添加前置的可用性标志位即可，改动极小（约10行）。
