# STORY-00122: 动态背景音乐加速

**Epic**: E-009 情感体验打磨
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家, I want the background music to subtly speed up when time is running out, so that the urgency I feel matches the audio atmosphere.

## Expected Result
游戏计时器 ≤15秒时，背景音乐逐渐加速至1.35倍；计时器 >15秒或游戏结束时恢复1.0倍速。

## Acceptance Criteria
- [ ] `audio.js` 新增导出函数 `setMusicTempo(factor: number)` — 将当前所有调度音符的时间间隔缩短至 `CHORD_DUR / factor`（通过修改 `CHORD_DUR` 临时变量或用局部 tempo factor 参数控制）
- [ ] 在 `game/engine.js` 的倒计时逻辑中：当 `timeLeft` 从 >15 变为 ≤15 时，调用 `setMusicTempo(1.35)`
- [ ] 当关卡完成或失败时，调用 `setMusicTempo(1.0)` 恢复正常速度
- [ ] 过渡平滑：tempo 变化不是突变，而是在下一个 chord 调度时生效（不需要 Web Audio 级别的 ramp，chord 边界切换即可）
- [ ] muted 状态下功能仍存在但无声（不影响 tempo 逻辑）
- [ ] 手动验证：在难度5关卡中，最后15秒音乐明显比开始时更紧凑快速

## Dependencies
- 无

## Notes
`audio.js` 中 `_musicTick()` 使用 `_musicNextTime += CHORD_DUR`，改为 `_musicNextTime += _currentChordDur` 即可，`_currentChordDur` 默认2.0，`setMusicTempo(f)` 设置为 `2.0 / f`。
