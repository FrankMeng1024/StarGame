# STORY-00119: 失败屏幕改善

**Epic**: E-009 情感体验打磨
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家 who failed a level, I want to see an encouraging message and a beautiful constellation silhouette, so that I feel motivated to retry rather than frustrated.

## Expected Result
失败屏幕下方展示：(1) 一条基于星座名称的个性化鼓励文案，(2) 增强后的星座全连线剪影（银色半透明），整体比现有实现更精致。

## Acceptance Criteria
- [ ] 失败文案为 `${con.nameZh}跑得太快了，再来一次！✨`（以星座中文名填入）
- [ ] 失败文案显示在 `.fail-encouragement-text` 元素中，取代现有硬编码文案
- [ ] `_drawFailConstellation()` 中的星座剪影加强：连线 strokeStyle 改为 `rgba(180,200,255,0.5)`，每颗星绘制小发光圆点（r=3，带径向渐变），整体效果比现有更精致
- [ ] 失败 canvas 尺寸适配：宽度最多 `min(400px, 90vw)`，在小屏不溢出
- [ ] 失败屏幕竖向布局：标题 → 鼓励文案 → 星座剪影 → 重试按钮，无大片空白

## Dependencies
- 无

## Notes
修改文件：`js/screens/complete.js` 的 `showFail()` 和 `_drawFailConstellation()`。文案逻辑：`const con = CONSTELLATIONS[state.currentLevel]; '${con.nameZh}跑得太快了，再来一次！✨'`
