# STORY-00120: 道具选择情境推荐

**Epic**: E-009 情感体验打磨
**Sprint**: Sprint 25
**Sprint Goal**: 打磨每一处玩家情绪节点
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家 choosing items before a level, I want a contextual recommendation banner, so that I know what to bring without having to guess.

## Expected Result
道具选择界面顶部显示一行推荐文案，根据关卡难度给出建议。

## Acceptance Criteria
- [ ] 在 item-select overlay 的物品网格上方新增 `.item-recommend-banner` 元素
- [ ] 文案规则：difficulty 1-2 → "🌟 初级关卡，轻装上阵！"; difficulty 3 → "⚡ 建议携带：网兜加速"; difficulty 4-5 → "⏱️ 建议携带：时间延长"
- [ ] 文案样式：小字（font-size 13px），浅紫色背景（rgba(124,92,191,0.2)），圆角，内边距8px，左右与物品网格对齐
- [ ] 当玩家没有推荐道具时，文案自动改为"💡 去商店购买更多道具"，不显示买不起的推荐
- [ ] 文案每次打开 item-select 时根据当前关卡实时计算（不缓存）

## Dependencies
- 无
