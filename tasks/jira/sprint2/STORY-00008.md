# STORY-00008: 游戏界面操作提示（首次引导）

**Epic**: E-001 核心游戏引擎
**Sprint**: Sprint 2
**Sprint Goal**: 完成进度循环 — 玩家能用金币购买道具、在展厅欣赏已解锁的星座
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a first-time player, I want a brief visual hint telling me how to fire the net, so that I can start playing without having to guess the controls.

## Expected Result
When the game screen first loads, a subtle animated hint appears over the canvas (e.g. "点击发射网兜" with a tap/click icon). The hint auto-dismisses after the first click or after 5 seconds, whichever comes first. It does not reappear once dismissed.

## Acceptance Criteria
- [ ] On first load of any game level, a hint overlay appears on canvas showing "点击 / 空格 发射网兜" (or equivalent clear instruction)
- [ ] Hint dismisses immediately on first click/tap
- [ ] Hint auto-dismisses after 5 seconds if no interaction
- [ ] Hint does NOT appear on subsequent game loads in the same session (sessionStorage flag, cleared each new game start is acceptable)
- [ ] Hint does NOT block gameplay — the underlying game continues running during hint display
- [ ] UX: hint text is legible against the dark game background (white or gold text with shadow)
- [ ] UX: hint is positioned in lower portion of screen (above HUD area) to avoid covering star targets
- [ ] UX: hint animation is subtle (gentle pulse or fade-in) — not distracting

## Dependencies
- Depends on: STORY-00003 (game screen exists)
- Blocks: none

## Notes
Addresses Sprint 1 UX Medium friction item: "No in-game tutorial/control hint — first-time player must discover click-to-fire by experimentation."
Keep implementation simple: a single div overlay positioned over the canvas, CSS animation, removed on click or timeout.
