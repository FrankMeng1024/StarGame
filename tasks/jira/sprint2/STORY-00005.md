# STORY-00005: 道具商店界面

**Epic**: E-003 道具系统
**Sprint**: Sprint 2
**Sprint Goal**: 完成进度循环 — 玩家能用金币购买道具、在展厅欣赏已解锁的星座
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to spend my earned coins in an item shop after completing a level, so that I can buy power-ups that help me in future levels.

## Expected Result
After completing a level, clicking "去商店" navigates to the shop screen. The shop lists all 8 items with name, effect description, and price. Current coin balance is displayed. Purchasing an item deducts coins from balance and adds the item to inventory. If player has insufficient coins, the buy button is disabled. Player can return to the level select screen.

## Acceptance Criteria
- [ ] Shop screen accessible via "去商店" button on the complete screen
- [ ] Shop screen accessible via main menu (add "商店" entry or via existing nav)
- [ ] All 8 items listed with: name, effect description, price in coins
- [ ] Current coin balance displayed prominently at top of shop
- [ ] Buy button for each item: enabled when coins ≥ price, disabled (greyed) when insufficient
- [ ] Purchasing item: coins deducted immediately, item count in inventory incremented, localStorage updated
- [ ] Cannot purchase same consumable if already owned (持续型 items); consumables can stack
- [ ] "返回" button navigates to level select screen
- [ ] Coin balance and inventory state persist after page refresh (localStorage)
- [ ] UX: coin balance update is animated (brief number flash or decrement animation)
- [ ] UX: disabled buy button has visual affordance (opacity or "金币不足" label)
- [ ] UX: purchase confirmation — brief visual feedback (item briefly highlights or checkmark appears)
- [ ] All viewports ≥ 1280×720 render without overflow or horizontal scroll

## Dependencies
- Depends on: STORY-00001 (navigate router), STORY-00004 (coins awarded on complete)
- Blocks: none
