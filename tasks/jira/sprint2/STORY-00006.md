# STORY-00006: 星座展厅（展示 + 详情）

**Epic**: E-006 星座展厅
**Sprint**: Sprint 2
**Sprint Goal**: 完成进度循环 — 玩家能用金币购买道具、在展厅欣赏已解锁的星座
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to visit a constellation gallery where I can review the constellations I've unlocked, so that I can appreciate the educational content I've earned through gameplay.

## Expected Result
Clicking "星座展厅" on the main menu navigates to the gallery screen. 30 constellation cards are shown in a 6×5 grid. Locked constellations show a silhouette/outline with "未探索" label. Unlocked constellations show the constellation name, icon, and a colored card. Clicking an unlocked constellation opens a detail view with the constellation's lore text and basic info. A back button returns to the gallery grid.

## Acceptance Criteria
- [ ] Gallery screen reachable from main menu "星座展厅" button
- [ ] 30 constellation cards in 6×5 grid (matches level select layout)
- [ ] Locked cards: grey/silhouette style, show "未探索" label, NOT clickable
- [ ] Unlocked cards: colored display with constellation icon + name (中/英), clickable
- [ ] On fresh state (localStorage empty), only Level 1 (猎户座) is shown as unlocked (since Level 1 is default-unlocked in unlockedLevels)
- [ ] After completing Level 1, gallery shows 猎户座 as unlocked
- [ ] Detail view: constellation name (中文 + English), icon, lore text (from constellations.js)
- [ ] Detail view: back button returns to gallery grid without full page reload
- [ ] Gallery "返回" button (from grid) navigates to main menu via navigate() router (NOT inline onclick)
- [ ] UX: locked cards have visible silhouette/constellation-name hint to build anticipation (addresses Sprint 1 Low friction item)
- [ ] UX: detail view lore text is readable (adequate font size, line-height, max-width)
- [ ] UX: first-time user with no unlocked constellations sees helpful empty-state message
- [ ] All viewports ≥ 1280×720 render without overflow
