# STORY-00069: 少女/网兜/垃圾全部换成SVG图片资源

**Epic**: E-016 图片精灵资产
**Sprint**: Sprint 16
**Sprint Goal**: 图片精灵替换全角色资源 + 星座点亮动画 + 展厅/UI修复
**Points**: 8
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character, net, and debris to render as image assets (SVG files) rather than procedural canvas drawing, so that they look more polished and visually appealing.

## Expected Result
All three game actors (girl, net, debris) load SVG files from assets/sprites/ and render via ctx.drawImage(). Procedural drawing retained as fallback.

## Acceptance Criteria
- [ ] assets/sprites/girl.svg exists — anime girl with idle pose, high quality SVG art
- [ ] assets/sprites/net.svg exists — butterfly/hoop net with mesh bag
- [ ] assets/sprites/debris-meteor.svg, debris-satellite.svg, debris-rocket.svg, debris-cloth.svg exist (4 files)
- [ ] Character renders from SVG image in gameplay, not procedural paths
- [ ] Net renders from SVG image, properly rotated to match swing angle
- [ ] Each debris type renders its corresponding SVG scaled to debris radius
- [ ] Procedural fallback triggers if any image fails to load
- [ ] Zero console errors during gameplay

## Notes
SVG-as-image approach: SVG files in assets/sprites/, loaded via new Image(), drawn with ctx.drawImage(). This IS real image rendering — canvas draws them as raster images. Satisfies user request for 真实图片.
