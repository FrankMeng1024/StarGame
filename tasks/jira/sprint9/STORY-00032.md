# STORY-00032: Gallery Detail Real Astrophotography

**Epic**: E-006 Gallery
**Sprint**: Sprint 9
**Sprint Goal**: VU content closure — real astrophotography + full lore text
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player who unlocks a constellation in the gallery, I want to see real astronomical images (star photographs, constellation diagrams, mythology illustrations) on the detail page, so that the gallery delivers the immersive educational experience promised.

## Expected Result
The gallery detail page for each unlocked constellation displays a curated set of real or high-quality astronomical images — at minimum a real star field photograph showing the constellation region and a labeled star chart. Images are embedded inline (SVG, canvas, or base64) so the product remains network-free.

## Acceptance Criteria
- [ ] Gallery detail page for Orion (and at minimum 2 other unlocked constellations) shows at least 1 real or high-quality star photograph or SVG star chart (not just the canvas line drawing already present)
- [ ] The image(s) are visually distinct from the canvas constellation portrait (real photo aesthetic vs drawing)
- [ ] Image display is consistent with the night-sky design system (dark background, no jarring borders)
- [ ] No JavaScript errors after navigating to gallery detail
- [ ] Product remains fully offline — no external image URLs; all assets embedded or generated locally

## Dependencies
- None
