# STORY-00212: 通关屏幕 — 星座介绍卡 + 下一关/重玩/选关导航

**Epic**: E-001 核心游戏可玩
**Sprint**: Sprint 3-mini
**Sprint Goal**: 游戏体验闭环 — 通关屏幕完整、新手可上手、物理帧率无关、危险视觉语言清晰
**Points**: 5
**Owner**: Frontend Dev

## Description
As a player, I want to see a victory screen when I catch all stars, so that I feel rewarded and can continue to the next level.

## Expected Result
After catching all 7 stars, the game transitions to a Canvas-drawn victory screen showing: congratulations message, coins earned, brief constellation fact (from CONSTELLATIONS data), and three navigation buttons (下一关 / 重玩 / 返回选关).

## Acceptance Criteria
- [ ] `_triggerResult(true)` in game.js navigates to a new 'complete' screen (not back to levels)
- [ ] Victory screen renders on Canvas: star/celebration graphic, "恭喜通关！" heading, coins earned count
- [ ] Constellation name and nameZh displayed (e.g. "猎户座 / Orion")
- [ ] At least one constellation fact shown (from `CONSTELLATIONS[idx].description` or similar field)
- [ ] Three buttons: "下一关" (next level, unlocked), "重玩" (same level), "返回选关" (level select)
- [ ] "下一关" calls `state.unlock(idx+1)` and navigates to levels
- [ ] On level 30 (idx=29), "下一关" is hidden or replaced with "全部通关！"
- [ ] Navigation from victory → levels → game → victory works without console errors
- [ ] Victory screen screenshot saved as evidence (STORY-00212-01-victory.png)
