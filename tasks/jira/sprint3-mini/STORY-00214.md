# STORY-00214: 帧率无关物理 — 摆动 + 网兜速度改为 dt×speed

**Epic**: E-001 核心游戏可玩
**Sprint**: Sprint 3-mini
**Sprint Goal**: 游戏体验闭环 — 通关屏幕完整、新手可上手、物理帧率无关、危险视觉语言清晰
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on any device, I want the net swing speed to feel the same regardless of device frame rate, so that the game is fair on 30fps Android phones.

## Expected Result
`_swingT` and `_netLen` update using delta-time (ms per frame) instead of fixed increments per frame. At 60fps and 30fps, the net completes a full swing in the same real-world seconds.

## Acceptance Criteria
- [ ] `_swingT` update uses `dt` parameter: `_swingT += SWING_SPEED * (dt / 16.67)` or equivalent time-based formula
- [ ] `_netLen` update uses `dt` parameter: `_netLen += NET_SPEED * (dt / 16.67)` or equivalent
- [ ] SWING_SPEED and NET_SPEED constants remain unchanged in meaning (calibrated for 60fps reference)
- [ ] At 60fps (dt≈16.67ms) swing behavior is visually identical to before this change
- [ ] No regression: gameplay still functions (net fires, catches stars, returns)
- [ ] No console errors after change
