# STORY-00216: 垃圾危险视觉语言 — 红色光晕/警告色区分危险目标

**Epic**: E-001 核心游戏可玩
**Sprint**: Sprint 3-mini
**Sprint Goal**: 游戏体验闭环 — 通关屏幕完整、新手可上手、物理帧率无关、危险视觉语言清晰
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want debris objects to look visually dangerous, so that I know to avoid them without needing prior game knowledge.

## Expected Result
Debris objects (brown triangle, blue satellite) have a distinct visual language that signals "danger/avoid": red tint, pulsing red glow, warning outline, or hostile color scheme. Stars continue to glow gold (positive). The visual contrast makes the two categories instantly distinguishable.

## Acceptance Criteria
- [ ] Each debris type has a red or orange visual element (glow, outline, or tint) not present on star objects
- [ ] Stars remain visually positive (gold glow, warm color) — no change to star drawing
- [ ] Debris and star objects are visually distinguishable without text labels
- [ ] No performance regression (debris drawing runs within game loop without jank)
- [ ] No console errors after change
- [ ] Evidence screenshot of game canvas showing both stars and debris with new visual treatment (STORY-00216-01-debris.png)
