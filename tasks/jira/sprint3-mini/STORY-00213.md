# STORY-00213: 新手引导提示 — "点击屏幕发射网兜！" 首次入场 hint

**Epic**: E-001 核心游戏可玩
**Sprint**: Sprint 3-mini
**Sprint Goal**: 游戏体验闭环 — 通关屏幕完整、新手可上手、物理帧率无关、危险视觉语言清晰
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a first-time player, I want to see a hint explaining how to play, so that I know to tap the screen to launch the net.

## Expected Result
On first game entry, a pulsing text hint "点击屏幕发射网兜！" appears on the game canvas for 3 seconds, then fades out. On subsequent entries to the same level, the hint does not appear.

## Acceptance Criteria
- [ ] On first game load, hint text "点击屏幕发射网兜！" is visible on canvas for 3 seconds
- [ ] Hint is rendered in a readable font (e.g. white text with dark shadow or semi-transparent pill background)
- [ ] Hint fades out or disappears after 3 seconds
- [ ] After hint is shown once (per session or via wx.setStorageSync), it does NOT appear again on re-entry to the same level
- [ ] Hint does NOT block gameplay — player can tap through it to fire the net during hint display
- [ ] No console errors on game entry with or without hint
- [ ] Evidence screenshot showing hint text visible (STORY-00213-01-hint.png)

## Dependencies
- Depends on: STORY-00207 (game scene — Done)

## Notes
UX Sprint 2-mini Critical finding: "No tutorial or onboarding — a first-time user is dropped into gameplay with zero explanation of the tap-to-launch-net mechanic."
Simple text overlay is sufficient; no tutorial sequence needed.
