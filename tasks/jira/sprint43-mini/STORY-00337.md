# STORY-00337: 背景星空去规律化 — 消除对角线星串伪影

**Epic**: Visual Polish
**Sprint**: Sprint 43-mini
**Sprint Goal**: 修复背景星空排列规律 — 用哈希散列替换线性同余，消除对角线星串视觉伪影
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the background starfield to look like a real night sky — stars scattered randomly with natural variation, not aligned in visible diagonal streaks.

## Root Cause
Current coordinate generation uses linear congruential sequences:
- `x = (i * 137 + 41) % (W + 1)` — step 137 in x
- `y = (i * 97 + 23) % (H + 1)` — step 97 in y

With W≈960, H≈540, the ratio 137/97 ≈ 1.41 is close to √2, causing diagonal alignment every few stars. The result: a visible diagonal streak of evenly-spaced white dots.

## Expected Result
Stars are visually scattered with no perceptible pattern. Natural variation in size (0.4–2.6px) and brightness (0.10–0.78). No diagonal lines, no grid, no clustering.

## Acceptance Criteria
- [ ] Star coordinates use a non-linear hash function (e.g. sin-based or multiply-shift) instead of `i * constant % dimension`
- [ ] Each tier (tiny/medium/large) uses different seed offsets so they don't overlap in pattern
- [ ] Screenshot at t=2s shows no visible diagonal streak or grid of stars
- [ ] Star size and brightness variation remains (different tiers still have different radii/alphas)
- [ ] Total star count unchanged (105 tiny + 45 medium + 18 large = 168)

## Notes
Fix pattern — replace `(i * N + offset) % dim` with a hash scatter:
```js
function _hash(n) { return (Math.sin(n * 127.1 + 311.7) * 43758.5453) % 1; }
// x = Math.abs(_hash(i)) * W
// y = Math.abs(_hash(i + 1000)) * H
```
Each tier uses a different seed offset (tiny: +0/+1000, medium: +2000/+3000, large: +4000/+5000)
to ensure no two tiers share position patterns.
