# STORY-00241: 展厅多图轮播 — 每星座3张图片 + 左右翻页

**Epic**: E-006
**Sprint**: Sprint 12-mini
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player who has unlocked a constellation, I want to browse multiple real astrophotography images of that constellation in the gallery detail view, so that I experience the visual richness promised by the product (PRD F-007: 5-10 real photos + carousel).

## Expected Result
Gallery detail view shows a photo carousel with 3 real astrophotography images per constellation, with visible left/right navigation buttons. User can tap ‹ / › to cycle through photos.

## Acceptance Criteria
- [ ] Each constellation has at least 3 distinct `photos` array entries in constellations.js (not just a single `photo` field) — top 10 constellations mandatory, all 30 preferred
- [ ] Gallery detail view shows a photo carousel (single image visible at a time, with ‹ and › tap targets for navigation)
- [ ] Photo index indicator visible (e.g., "1/3" or dot indicators)
- [ ] Each photo loads asynchronously via wx.createImage() with loading/error fallback states
- [ ] Previous single-photo implementation replaced or upgraded to carousel
- [ ] No regression on lore text, metadata, or prev/next constellation navigation
- [ ] UX AC: carousel navigation is discoverable — ‹ and › indicators visible without prior knowledge

## Dependencies
- Depends on: STORY-00240 (photo infrastructure in gallery.js and constellations.js — Done)

## Notes
Approach:
- Extend constellations.js: add `photos: [url1, url2, url3]` array to each constellation. Can reuse existing `photo` as photos[0]. Add 2 more images per constellation (Wikimedia CDN for nebulae/star clusters/mythology art).
- gallery.js: track `_photoCarouselIdx` (current carousel position 0..N-1). Add `_prevPhoto()` / `_nextPhoto()` touch handlers. Draw ‹ and › canvas tap targets around photo area.
- Existing `_loadPhoto()` becomes `_loadPhotoAtIdx(idx, carouselPos)`. State tracks which carousel position is loaded.
- AC operationalization: code-path — verify `c.photos` array length ≥3 for top 10 constellations; verify carousel touch targets exist in `_drawDetail()`; verify photo state resets on constellation navigation.
