# STORY-00095: Net attached to character's hand

**Epic**: E-005 Gameplay Polish
**Sprint**: Sprint 19
**Sprint Goal**: Polish and fix 7 user-reported issues
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the net to visually originate from the character's hand so that the animation looks natural and connected.

## Expected Result
The pole base matches the character's hand/arm position in all states: idle, throw, catch.

## Acceptance Criteria
- [ ] Net pole base originates from character's hand position (not body center)
- [ ] Hand position updates each frame before net is drawn
- [ ] Works correctly in idle, extend (throw), and retract (catch) states
- [ ] No visual gap between hand and pole base

## Notes
Added `_updateHandPos()` method called in `_draw()` before `_drawNet()`. `_poleTop()` now uses `this._handX/Y` instead of `charX/Y`. Three hand states: idle (gentle bob), throw (arm extended at swing angle), catch (raised position).
