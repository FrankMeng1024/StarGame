# STORY-00098: Item-select back button and backdrop dismiss

**Epic**: E-004 Item System
**Sprint**: Sprint 19
**Sprint Goal**: Polish and fix 7 user-reported issues
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to dismiss the item-select overlay by clicking a back button or the backdrop, so I can return to the levels screen without starting the level.

## Expected Result
Item-select overlay has a visible "← 返回" button that dismisses the overlay and returns to levels screen. Clicking the backdrop also dismisses.

## Acceptance Criteria
- [ ] "← 返回" back button visible in item-select header
- [ ] Clicking back button dismisses overlay and returns to levels screen
- [ ] Items re-evaluated on each level entry (depleted items not shown)

## Notes
Added `.item-select-header` with back button. `showItemSelect(onConfirm, onBack)` now accepts an `onBack` callback. Clicking back calls `onBack()`. Both levels.js and main.js updated to pass `() => navigate('levels')` as the onBack callback. Backdrop click also triggers onBack.
