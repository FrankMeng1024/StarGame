# STORY-00101: Instant star appearance — sprite pre-cache on levels screen

**Epic**: E-005 Gameplay Polish
**Sprint**: Sprint 19
**Sprint Goal**: Polish and fix 7 user-reported issues
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see all stars immediately when entering the game so there is no blank-canvas flash or delayed star appearance.

## Expected Result
Stars appear instantly on game entry with no visible loading delay.

## Acceptance Criteria
- [ ] Sprites (girl.svg, net.svg) pre-warmed when levels screen loads
- [ ] Game entry preload timeout reduced (50ms, not 400ms)
- [ ] Stars visible within 1 second of game screen appearing

## Notes
Added sprite pre-warming IIFE in `levels.js` that creates Image objects for girl.svg and net.svg on levels screen load. This warms the browser cache before game starts. Also reduced `_preloadTimeout` in `game.js` from 400ms to 50ms since sprites are pre-warmed.
