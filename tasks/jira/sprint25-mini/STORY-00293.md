## Description
As a player, I want the girl character to look beautiful and polished, matching the quality of the web version's anime-style character art.

## Problem Analysis
Complaint #5: 女角色很丑. Current v4 character has r=20 head, full eye anatomy, dress ±32, hat star. Issues:
1. Hair color `#1a0a0a` (near-black) looks flat — should be deep purple/navy like web version
2. Hat is basic — needs more detail
3. Dress waist transition too abrupt
4. No hair highlights/shine
5. Face proportions: head r=20 but body is ±32 wide = head/body ratio OK, but the torso from y=-42 to y=4 (46px total) with head at y=-66 (r=20, top at y=-86) creates too much neck gap
6. The character blends with the dark background — needs stronger outline/rim light

Fixes:
1. Hair: `#553399` (deep purple) — already set but ensure it has shine streaks
2. Add purple hair bun/ornament at top (y=-84 area)
3. Dress: add a ribbon/bow at waist (y=-42 area)
4. Add rim light: thin bright stroke around head + shoulders
5. Improve hat: add a star cluster on the hat brim, and a hat band
6. Body proportions: move dress top to y=-46 (tighter to neck)

## Acceptance Criteria
- [ ] Character hair color = `#553399` (deep purple, not near-black)
