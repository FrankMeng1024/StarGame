## Description
As a player, I want to see the intro animation when I launch the game, so that I get the cinematic opening experience.

## Problem Analysis
Root cause 1 (动画没了/黑屏): `canvas-utils.js` has a singleton fade system (`_fadeAlpha`, `_fadeDir`). When `navigate('intro')` is called from game/menu via `fadeNavigate`, the fade-out sets `_fadeAlpha=1` and fires the callback. But `intro.js` does NOT import or call `tickFade`/`drawFadeOverlay` — so `_fadeAlpha` stays at 1 forever during the entire intro, showing only black. Fix: add `tickFade`/`drawFadeOverlay` to intro.js render loop.

Root cause 2 (比例不协调): In portrait (375×667), the constellation is centered at `cy = H*0.42 = 280`, and the title appears at `H/2 = 333`. The overall composition has the constellation bunched in the top-center and the title too close to it. Need:
- Constellation area: upper 30% of screen (cy = H*0.30)  
- Phase 3 title: lower area at H*0.65 (not H/2)
- Better visual breathing room

Root cause 3 (真机黑屏): Same as root cause 1. On real device, the navigate from boot → intro triggers `fadeNavigate`, which leaves `_fadeAlpha=1`. The intro renders completely invisible. Adding `tickFade`/`drawFadeOverlay` to intro.js fixes all three.
