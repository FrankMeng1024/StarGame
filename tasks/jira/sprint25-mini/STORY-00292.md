## Description
As a player, I want the gallery to be clearly named "星座图鉴" (not "星座展厅") in the main menu, and the gallery list cards to be smaller so more fit on screen.

## Problem Analysis
Complaint #4: "星座图鉴和星座展厅是同一个东西" — the menu button says "星座展厅" but the screen is effectively the constellation reference guide (图鉴). Rename to "星座图鉴".

Complaint #4.1: "星座展厅图标太大，不和谐" — gallery.js list uses COLS=3 with cards `CARD_H = CARD_W + 24`. At 375px wide with COLS=3: usableW ≈ 351, CARD_W = (351 - 16) / 3 ≈ 112px, CARD_H ≈ 136px. These are very large. Change to COLS=4 → CARD_W ≈ 84px, CARD_H ≈ 108px — more harmonious.
