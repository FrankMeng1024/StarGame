## Description
As a player, I want the stars to visibly twinkle and sparkle, giving the night sky a lively, magical feel.

## Problem Analysis
Complaint #6: 星星没有闪烁感. Current: `alpha = 0.50 + 0.50 * Math.abs(Math.sin(t * s.speed + s.phase))` with `speed: 0.4 + (i % 5) * 0.15`. At 60fps, t advances at 0.0167s/frame. At speed=0.4: sin completes one cycle in `2π/0.4 = 15.7s` — very slow, barely perceptible. At max speed=1.0 (0.4 + 4*0.15): one cycle in `2π/1.0 = 6.28s` — still too slow for "twinkling" feel.

Fix:
1. Increase speed range: `speed: 1.5 + (i % 5) * 0.6` → range 1.5-3.9, cycle time 1.6-4.2s — clearly visible twinkling
2. Increase alpha swing: `0.35 + 0.65 * Math.abs(Math.sin(...))` → deeper twinkling (was 0.50+0.50)
3. The 4-point sparkle cross arms: currently `sparkleLen = s.r * 3` and `alpha * 0.65`. Scale sparkle length with twinkling: `sparkleLen = s.r * (2.5 + 1.5 * Math.abs(Math.sin(t * s.speed * 1.3 + s.phase)))` — arms pulse longer when star is bright
4. Brightest moment: when alpha > 0.85, draw 2 additional diagonal arms (45° rotated) at half length — 8-point star effect at peak brightness

## Acceptance Criteria
- [ ] Star speed range: `1.5 + (i % 5) * 0.6` (was `0.4 + (i % 5) * 0.15`)
- [ ] Star alpha range: `0.35 + 0.65 * Math.abs(Math.sin(...))` (was `0.50 + 0.50`)

- [ ] At peak brightness (alpha > 0.85): additional diagonal arms drawn
