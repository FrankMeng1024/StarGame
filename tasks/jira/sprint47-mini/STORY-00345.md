# STORY-00345: 行星轨道选关界面 — 手机视觉优化版

**Epic**: Visual Polish
**Sprint**: Sprint 47-mini
**Sprint Goal**: 选关界面轨道重设计
**Points**: 5
**Owner**: Frontend Dev
**Status**: In Progress

## Description
As a mobile player, I want the level select screen to look like a beautiful orbital star system — with a glowing central sun, concentric elliptical orbits, and constellation nodes — so the experience feels immersive and thematic on my phone.

## Expected Result
- Vertical (portrait) layout with central sun + 5 concentric elliptical orbits
- 30 level nodes rotate slowly along their orbits
- Each node shows a mini constellation line drawing
- Unlocked nodes glow, locked nodes are dim with 🔒
- Level name + star rating displayed below each node
- Smooth scroll / pan to reveal all orbits
- Tapping a node opens the item selection overlay (existing behavior preserved)

## Acceptance Criteria
- [ ] Background: deep space #06091e + 160 twinkling stars (no pure black — prevents claustrophobia)
- [ ] Central sun visible with warm glow (not oversized — r≤28px, anti-megalophobia)
- [ ] 5 elliptical orbit rings drawn as faint dashed circles (opacity ~0.12)
- [ ] 30 nodes distributed 6 per ring, rotating at different speeds
- [ ] Node radius: ring 0 = 22px, ring 1 = 20px, ring 2 = 18px, ring 3 = 16px, ring 4 = 14px (diminishing depth)
- [ ] Mini constellation lines drawn inside each node (clipped to circle)
- [ ] Unlocked: blue-purple gradient fill + glow; locked: grey 0.3 alpha + 🔒
- [ ] Level name displayed below node (~10px font)
- [ ] Star rating (★/☆) displayed below name
- [ ] Vertical scroll to see all 5 orbit rings (totalH ≈ screen_h + outer ring overflow)
- [ ] Circular tap hit detection: Math.hypot(tx-cx, ty+scrollY-cy) <= r+10
- [ ] Back button and Shop button unchanged
- [ ] Item selection overlay (_drawItemOverlay) completely preserved
- [ ] No pure black (#000000) anywhere in background — minimum #06091e

## Dependencies
None
