# STORY-00091: 道具选择跨关卡数量刷新

**Epic**: E-018 用户反馈修复
**Sprint**: Sprint 18
**Sprint Goal**: 8项用户反馈修复
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the item-select screen to show current item quantities each time it opens, so items consumed in a previous level are correctly reflected.

## Expected Result
When entering item-select for level 2 after playing level 1, quantities reflect any items consumed during level 1.

## Acceptance Criteria
- [ ] Item quantities read from state.getItemQty() fresh each time showItemSelect() is called
- [ ] Previously selected items are NOT carried over to the next level's item-select
- [ ] If an item was consumed in level N, it shows reduced quantity in level N+1 selection
