# STORY-00090: 展馆左右切换导航

**Epic**: E-018 用户反馈修复
**Sprint**: Sprint 18
**Sprint Goal**: 8项用户反馈修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user viewing a constellation in the gallery detail, I want prev/next navigation buttons to switch between completed constellations without returning to the grid.

## Expected Result
Gallery detail shows left/right arrows that cycle through completed constellations. Wraps around at ends.

## Acceptance Criteria
- [ ] Prev (←) and Next (→) buttons visible in gallery detail header
- [ ] Clicking prev/next navigates to the previous/next completed constellation
- [ ] Navigation wraps: going past the last completed returns to first, and vice versa
- [ ] Only completed constellations (state.hasCompleted) are navigable
- [ ] Content fully refreshes (star chart, photos, portrait, meta, lore)
