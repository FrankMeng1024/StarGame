# STORY-00112: 关卡加载延迟消除 — 传入预加载精灵图对象

**Epic**: E-011 性能优化
**Sprint**: Sprint 22
**Sprint Goal**: 2项游戏体验修复
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the level to start instantly (< 1 second) when I press Play, with no blank canvas or loading flash.

## Expected Result
Character and net sprites appear on the canvas from the very first frame. No 2-5 second delay before the game becomes visible.

## Acceptance Criteria
- [ ] `GameEngine` constructor accepts an optional `sprites` parameter — a map of `{ src: HTMLImageElement }` — and assigns them directly instead of creating new Image() objects
- [ ] When sprites are provided and `img.complete === true`, `_charImgReady` and `_netImgReady` (and all debris image ready flags) are set to `true` immediately in the constructor (no async wait)
- [ ] `game.js` passes the preloaded sprites from `getSpriteReady()` (levels.js cache) into the `GameEngine` constructor
- [ ] All 6 sprites (girl, net, 4 debris types) are passed from preloaded cache — engine never creates new Image() objects when all sprites are provided
- [ ] On level entry, character and net are visible within 1 second of the Play button tap (measured in browser)
- [ ] Existing fallback: if `sprites` not provided, engine still creates its own Image() objects as before

## Root Cause
`GameEngine` constructor (lines 437-467 in engine.js) always creates new `Image()` instances. These trigger fresh network requests or cache-miss decodes even when `levels.js` has already preloaded and decoded the same files. The `getSpriteReady()` wait in `game.js` guards only the engine start — the engine itself still loads images asynchronously internally, causing the canvas to render blank for 2-5 seconds.

## Fix
1. Add `sprites` optional param to `GameEngine` constructor
2. If `sprites[src]?.complete`, assign directly and set `_charImgReady = true` etc.
3. In `game.js`, after `Promise.all([getSpriteReady(...), ...])`, build a `sprites` map and pass to `new GameEngine(..., { sprites })`
