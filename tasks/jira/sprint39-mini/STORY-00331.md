## Description
As a player, I want to see star name labels on the star chart in gallery detail, so that I can learn the names of the bright stars in each constellation.

## Expected Result
Bright stars (mag≤2.5) in the star chart have labeled pointers: a short dashed line + star name text near the star dot.

## Acceptance Criteria
- [ ] After drawing all stars, iterate constellation.stars and label those with mag≤2.5
- [ ] For each labeled star: draw a 6px dashed pointer line from the star outward (direction = angle of star position relative to chart center + 45°)
- [ ] At the end of the pointer: draw `s.name` text, font 9px, color rgba(255,255,255,0.75)
- [ ] Anti-overlap: if two label positions are within 20px of each other, offset the second one by y-10
- [ ] Maximum 5 labels per chart (take the 5 with lowest mag value — brightest stars)
- [ ] Labels render within the CHART_SIZE circle (clipped by existing ctx.clip())
- [ ] No console errors when a constellation has fewer than 5 bright stars

## Notes
CR-128 (mini). Implementation must work within the existing ctx.save()/ctx.clip() pattern in _drawDetail(). Dashed line: ctx.setLineDash([2,2]) before drawing, ctx.setLineDash([]) after.
