# BUG-00003: Carousel onerror uses innerHTML+= (fragile pattern)

**Priority**: Medium
**Sprint**: Backlog
**Opened by**: Arch (Sprint 13 Code Review)
**Status**: Open

## Description
Inline `onerror` attribute on carousel `<img>` tags uses `this.parentElement.innerHTML += '✦'`. No XSS risk today (static data source), but the `innerHTML+=` pattern destroys and recreates child nodes, is fragile if data source changes, and can cause event listener loss.

## Root Cause
Quick inline handler chosen for brevity; `innerHTML+=` is a known anti-pattern.

## Fix
Replace the inline `onerror` with a proper event handler that appends a text node or a dedicated `<span>` element: `const s = document.createElement('span'); s.textContent = '✦'; this.parentElement.appendChild(s);`
