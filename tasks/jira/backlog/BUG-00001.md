# BUG-00001: _handleInput missing pause guard

**Priority**: Medium
**Sprint**: Backlog
**Opened by**: Arch (Sprint 13 Code Review)
**Status**: Open

## Description
`_handleInput` (space/click net launch) does not check `this._paused` before acting. `_handleKeySlot` was patched with the pause guard in Sprint 13 but `_handleInput` was not. Pressing Space or clicking the canvas during pause overlay can mutate netState.

## Steps to Reproduce
1. Start a game
2. Click pause button
3. Press Space or click canvas while pause overlay is visible
4. Expected: no action; Actual: may fire net launch

## Root Cause
`_handleInput` guard was not added when `_handleKeySlot` guard was added.

## Fix
Add `if (this._paused) return;` at top of `_handleInput` in `js/engine.js`, mirroring the existing guard in `_handleKeySlot`.
