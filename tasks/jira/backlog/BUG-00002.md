# BUG-00002: _openStarChartModal keydown listener leak on double-call

**Priority**: Medium
**Sprint**: Backlog
**Opened by**: Arch (Sprint 13 Code Review)
**Status**: Open

## Description
`_openStarChartModal` replaces `document._scModalKeyHandler` without removing the previous listener if called twice in a row. In practice blocked by the overlay (can't open while open), but a programmatic double-call leaks a keydown listener.

## Steps to Reproduce
Programmatically call `_openStarChartModal()` twice in rapid succession (possible in theory via test injection).

## Root Cause
The function assigns `document._scModalKeyHandler = handler` and adds the listener, but does not remove the old listener first before reassigning.

## Fix
At start of `_openStarChartModal`, if `document._scModalKeyHandler` already exists, call `document.removeEventListener('keydown', document._scModalKeyHandler)` before adding the new one.
