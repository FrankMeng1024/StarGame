# STORY-00307: 道具选择界面重设计 — 更清晰更好看

**Epic**: Mini端视觉品质升级
**Sprint**: Sprint 32-mini
**Sprint Goal**: 视觉品质全面升级
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the item selection overlay before each level to look clean and easy to understand, not cluttered or ugly.

## Expected Result
道具选择overlay：每个道具有清晰的图标、名称、简短描述、价格；选中/未选中状态一目了然；整体布局对称、有间距感。

## Acceptance Criteria
- [ ] **卡片布局**: 每个道具占一整行，高度64px（当前60px基本合理，确认）
  - 图标(emoji)：24px，左边距12px，垂直居中
  - 名称：bold 14px，图标右边12px，上方
  - 数量：名称右边，"×N"格式
  - 描述：13px，名称下方
  - 按钮：右边，宽62px，高32px
- [ ] **选中状态对比**: 选中=绿色边框+绿色背景淡；未选中=紫色边框+暗色背景
- [ ] **标题区域**: "选择使用道具"标题 bold 18px，下方副标题 12px
- [ ] **底部按钮**: "跳过" 和 "确定出发 →" 两个按钮，足够大（高44px），填满卡片底部
- [ ] **滚动**: 超过3个道具时，中间区域可以滚动
- [ ] Playwright截图：道具选择overlay显示，对比HTML版的`js/screens/item-select.js`或`index.html`中的DOM
- [ ] 没有道具时：直接进入游戏，不显示overlay（已有此逻辑，验证）
