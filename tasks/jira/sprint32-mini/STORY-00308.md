# STORY-00308: 全流程Web对标验证与修复 — 全关卡全图片保证

**Epic**: Mini端视觉品质升级
**Sprint**: Sprint 32-mini
**Sprint Goal**: 视觉品质全面升级
**Points**: 3
**Owner**: Frontend Dev + QA
**Status**: Done

## Description
As a player, I want every screen of the mini game to match the HTML web version in layout, content, and visual quality.

## Expected Result
全流程逐屏对比web版，发现并修复所有不一致。QA必须用Playwright截图两个版本逐一比对，不能用代码推断代替视觉验证。

## Acceptance Criteria
- [ ] **逐屏对比检查单**（每项均需截图证据）：
  - [ ] 主菜单：按钮数量/位置/文字/背景星座 ≈ web版
  - [ ] 关卡选择：卡片布局/图标/锁/星级显示 ≈ web版
  - [ ] 游戏内：HUD（计时/金币/道具槽）≈ web版，角色位置/大小相近
  - [ ] 胜利界面：星评/金币/lore文字/图片/按钮 ≈ web版
  - [ ] 失败界面：鼓励语/重试/选关 ≈ web版
  - [ ] 展厅列表：卡片网格/图标/锁定样式 ≈ web版
  - [ ] 展厅详情：名称/英文名/星图/照片/介绍文字 ≈ web版
  - [ ] 道具商店：8个道具/价格/描述 ≈ web版
- [ ] **全关卡测试**: 关卡1、关卡5、关卡10、关卡30均可进入并正常游玩
- [ ] **全图片测试**: 展厅详情页至少3个不同星座的照片均能正常显示
- [ ] **导航回归**: 全流程无JS错误，所有返回按钮指向正确页面

## Notes
此Story是验收Story。前面STORY-00301~00307的修复完成后，此Story通过Playwright全流程截图对比确认所有修复生效。
QA subagent必须拿到web版(localhost:8090)和mini版(localhost:8090 or 微信DevTools)的并列截图进行比对。
