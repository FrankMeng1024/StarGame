# STORY-00306: 女角色全面重绘 — 对标Web版SVG形象

**Epic**: Mini端视觉品质升级
**Sprint**: Sprint 32-mini
**Sprint Goal**: 视觉品质全面升级
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character in the game to look beautiful and polished, matching the web version's quality standard.

## Expected Result
女角色外形品质接近Web版SVG角色：比例正确、五官精致、颜色丰富、有动感。用户不再感到"很丑"。

## Acceptance Criteria
- [ ] **头部比例**: 头部相对于身体的比例感觉自然（不过大也不过小）
  - 当前: head r=20, body height约130px → 头部占比约30%（合理）
  - 检查：眼睛位置在头部中线稍下，eyebrow更自然的弧度
- [ ] **五官精化**: 
  - 眼睛：虹膜颜色更丰富（加高光渐变）
  - 嘴巴：弧度更自然，加上嘴唇颜色
  - 脸型：添加下巴轮廓感
- [ ] **头发**: 当前黑色单色 → 添加深棕渐变 + 多层高光（不仅仅是arc）
- [ ] **裙子**: 添加更多层次感 — 蕾丝下摆纹理或裙褶线条
- [ ] **整体对比Web版**: 打开HTML版，Playwright截图web版菜单/游戏中的角色 → 对比mini版 → 找差距并修复
- [ ] Playwright截图：game.js截图显示新版角色，与web版角色截图并排评估
- [ ] 不破坏游戏功能：角色坐标系(_poleX, _poleY)不变，碰撞逻辑不变

## Notes
Web版角色在`js/game/engine.js`的`drawCharacter`或SVG图片资源中。先read web版角色绘制逻辑再实现mini版。

当前mini版`_drawGirl`的主要问题（用户反馈"很丑"）：
- Canvas 2D直接绘制的头发只有黑色填充，缺乏层次
- 眼睛虹膜是纯色圆形，缺乏高光渐变
- 裙子渐变颜色已有（紫→粉），但缺少裙摆细节
- 整体缺乏精致感

**此Story的核心策略**：先用Playwright截图web版，看到参照物，再修复mini版，再截图对比，确保真实看到效果。
