## Description
As a player on the complete screen, I want the "返回选关" button to have a visible background so it doesn't look broken or transparent.

## Expected Result
The "返回选关" / "返回关卡" button on the complete screen has a visible default background color, consistent with other secondary CTA buttons.

## Acceptance Criteria
- [ ] `.btn-back-levels` has a visible default background (not transparent) — use `rgba(255,255,255,0.08)` + border consistent with other ghost-style secondary buttons that were fixed in Sprint 15/16
- [ ] Button background visible without hover
- [ ] Button hover state still provides visual feedback (darker bg)
- [ ] Same fix applied consistently — `.btn-back-levels` in complete screen only (fail screen same button if present)
- [ ] Zero console errors

## Notes
`.btn-ghost` class currently has `background: transparent`. The fix adds a CSS override for `.btn-back-levels` with a subtle visible background, matching the pattern used for `#pause-exit-btn.btn-ghost` in Sprint 15 (background: rgba(255,255,255,0.08); border: 1px solid rgba(255,255,255,0.18)).
