## Description
As a player, I want a fair coin system that rewards first-clears and skill, with a starting balance to get me into the shop.

## Expected Result
Players start with 100 coins (one-time). Failing gives 0 coins. Succeeding gives time_remaining × 10 coins. Replaying an already-3★ cleared level gives half coins.

## Acceptance Criteria
- [ ] New game (no save) initializes with 100 coins in state — verified by checking coin display on main menu first load
- [ ] Existing saves: if `state.coins === 0` and no level scores exist → set to 100 (first-time initialization only; do NOT reset players who genuinely have 0 coins after spending)
- [ ] Fail flow: 0 coins awarded (no call to `state.addCoins`) — verified by checking coin balance before/after fail
- [ ] Success flow: `coins = Math.floor(timeLeft) * 10 * coinMultiplier` — same formula, unchanged
- [ ] 3★ repeat: if current level already has score with stars === 3, award only half: `Math.floor(coins / 2)` — verified by completing a 3★ level twice and checking coin increments
- [ ] coinMultiplier (double_coins item) still applies correctly on top of the half-coin reduction
- [ ] State persists across navigation and page reload

## Notes
Implementation in `js/screens/game.js` `_handleComplete()` and `_handleFail()` (fail already awards 0, just verify no addCoins call leaks).
Initialization: in `js/state.js` `load()` — after loading saved state, if `!saved` (null, first time), set `this.coins = 100`. For existing saves: in `load()`, after loading, if coins === 0 AND levelScores.size === 0 → set coins = 100 (truly fresh player).
Half-coin: in `_handleComplete()`, after calculating coins, check `state.getScore(idx)?.stars === 3` → if true, `coins = Math.floor(coins / 2)`.
