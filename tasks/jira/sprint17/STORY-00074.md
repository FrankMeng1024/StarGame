# STORY-00074: 星星尺寸缩小 + 上下限

**Epic**: E-017 游戏手感修复
**Sprint**: Sprint 17
**Sprint Goal**: 游戏手感全面修复
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want stars to look like distant stars in a sky, not oversized blobs, so that catching them feels like reaching into a vast starfield.

## Expected Result
All stars are rendered at 2/3 of their current size. A minimum and maximum radius cap prevents any star from being too tiny or too large. Ursa Major (Level 1, index 1) star sizes are the reference: its current proportions define the new min/max bounds.

## Acceptance Criteria
- [ ] All star radii multiplied by 2/3 (apply to baseR formula in engine.js `_initStars`)
- [ ] Hard minimum radius cap: `MIN_STAR_R = 3` (pixels)
- [ ] Hard maximum radius cap: `MAX_STAR_R = 18` (pixels)
- [ ] Stars still visually distinguish bright vs dim (larger mag difference → more noticeable radius difference)
- [ ] Collision hit radius unchanged relative to visual size (catchBonus scaling intact)
- [ ] No regression on constellation reveal animation or star catch particles
- [ ] Zero console errors

## Notes
Current formula: `baseR = Math.max(4, magToRadius(s.mag) * 1.2)`. New formula: `baseR = Math.min(MAX_STAR_R, Math.max(MIN_STAR_R, magToRadius(s.mag) * 1.2 * (2/3)))`. The 2/3 factor is the user's stated requirement. Min/max values derived from Ursa Major proportions (the user confirmed it "looks good").
