# STORY-00298: 主菜单新增星座信息面板（对标Web版）

**Epic**: E-028 Mini Web Parity
**Sprint**: Sprint 28-mini
**Sprint Goal**: 真实测试验收 + 修复Web差异
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player on the main menu, I want to see a constellation info panel like the web version — showing the current constellation's name, viewing season/tip, and notable stars. Currently the mini game menu shows no info panel.

## Web Version Info Panel Content
- Constellation name (大 format or 小 prefix)
- Viewing tip line (e.g. "7月（冬季最佳）最易观测")
- Notable stars list
- Location hint icon

## Acceptance Criteria  
- [ ] Info panel is visible on the main menu screen
- [ ] Panel shows constellation name matching the displayed constellation
- [ ] Panel shows at least: constellation name + viewing tip/season
- [ ] Panel is positioned at bottom or lower area of screen, not overlapping buttons
- [ ] Panel text is readable (sufficient font size, contrast against background)
- [ ] Panel updates when constellation changes (each menu visit shows new constellation)
- [ ] Panel uses semi-transparent or glass-style background consistent with mini visual style

## Dependencies
None

## Notes
Web version renders info panel as a bottom-anchored frosted glass strip. In mini (Canvas, landscape), place it in the lower-center of the canvas below the buttons or between star half and button half. Use the same constellation data already available (constellations array in menu.js or game-data.js). Adapt to landscape layout — may be a compact single-line or two-line card at bottom.
