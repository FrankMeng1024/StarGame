# STORY-00125: 封面单星座聚焦背景 + 观测提示面板

**Epic**: E-026 Cover Experience
**Sprint**: Sprint 26
**Sprint Goal**: 封面聚焦 — 最易见星座作为主背景 + 观测提示
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player opening the game, I want the cover (main menu) to show me the single constellation most visible from my current location tonight, large and beautiful, so I feel connected to the real sky outside — and I want to know what it is and how to spot it.

## Expected Result
- Menu background shows ONE large constellation (highest altitude for user's lat/lon + time) centered/filling ~50-60% of screen height
- An info card appears below/on the menu showing: constellation Chinese name + English name + brief viewing tip + current altitude
- The scattered multi-constellation layout (4-6 small constellations in fixed zones) is removed
- Bottom-right multi-constellation label removed
- Fallback: Lake Tekapo default if geolocation denied, panel shows "📍 默认：新西兰特卡波"

## Acceptance Criteria
- [ ] Menu background renders exactly ONE constellation (highest altitude) large and centered — not multiple scattered
- [ ] Constellation occupies at minimum 45% of screen height (measured from star bounding box top to bottom)
- [ ] Info panel visible below menu buttons with: Chinese name, English name, altitude in degrees, 1-2 sentence "如何找到它" tip
- [ ] "如何找到它" tip derived from constellation's region + bestViewMonth + mainStars fields (already in constellations.js)
- [ ] When geolocation denied: fallback to Lake Tekapo default, panel shows "📍 默认：新西兰特卡波"
- [ ] Zero console errors on menu load
- [ ] No overlap between info panel and menu buttons on 1280×720 viewport
- [ ] Stars twinkle with phase-offset animation (existing behavior preserved)
- [ ] Constellation lines rendered (existing behavior preserved)
