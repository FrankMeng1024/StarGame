## Description
As a player, I want to tap the star chart to view it full-screen so I can read the star labels clearly.

## Expected Result
Clicking the SVG star chart in gallery detail expands it to a full-screen modal with a close button.

## Acceptance Criteria
- [x] "点击放大查看" hint text visible below the star chart in gallery detail
- [x] Clicking the star chart opens a full-screen modal overlay
- [x] Modal: dark background, SVG fills 90vmin, all star labels legible at this size
- [x] Close button (✕) in top-right corner of modal
- [x] Clicking outside the modal closes it (backdrop click confirmed)
- [x] Pressing Escape closes the modal (confirmed)
- [x] Modal opens and closes without console errors
- [x] SVG in modal is the same data as the inline chart (svgStr passed directly)

## Dependencies
