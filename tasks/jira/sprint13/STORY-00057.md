## Description
As a player on the level select screen, I want to understand the difficulty of each level at a glance, so I can choose challenges appropriate to my skill.

## Expected Result
Difficulty is shown as a color-coded progress bar (not confusing star rows). Best score stars are shown separately with a clear label.

## Acceptance Criteria
- [x] Difficulty shown as horizontal progress bar: 20%/40%/60%/80%/100% fill for difficulty 1-5
- [x] Bar color: difficulty 1-2 = green, 3 = amber, 4-5 = red
- [x] "难度" label next to bar
- [x] Best-score stars shown separately as "最佳: ★★☆" in gold color
- [x] Both rows clearly labeled so user knows which is difficulty vs earned score
- [x] Zero console errors
- [x] Existing level unlock state (🔒) still visible and functional
