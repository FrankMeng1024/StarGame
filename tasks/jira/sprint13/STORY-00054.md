## Description
As a player, I want the girl character to look like a real anime-style character, so that the game feels visually appealing and the protagonist is relatable.

## Expected Result
The canvas-drawn girl character is visually attractive with anime proportions, detailed face, styled hair, gradient dress, and clear arm/net pose states.

## Acceptance Criteria
- [x] Character is ~120-140px tall, centered at bottom 15% of game canvas
- [x] Head: large relative to body (radius 18×20px, anime proportions), almond eyes with highlights and lashes, rosy cheeks, visible smile
- [x] Hair: twin tails (双马尾) with gold ribbon ties, fringe strands, star hair clip
- [x] Dress: deep navy → purple gradient skirt (layered with inner+outer layer), sailor collar, gold bow
- [x] Arm states: idle (arms at sides swaying), throw (arm raised with pole direction), catch (both arms wide V-shape)
- [x] Arm states visually distinct — sleeve + skin forearm segments
- [x] Golden pole/staff visible in hand
- [x] Character looks significantly more detailed than Sprint 11 version
- [x] Zero console errors with character animation active
