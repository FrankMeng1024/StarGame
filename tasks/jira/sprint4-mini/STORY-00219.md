## Description
As a player, I want the game background to change every 5 levels so that the game feels visually fresh as I progress.

## Expected Result
The game canvas background color changes based on the current level index. Levels 1-5 use Scene 0 palette, 6-10 use Scene 1, etc. (6 scenes total, each for 5 levels). js/data/scenes.js already defines SCENE_PALETTES[6].

## Acceptance Criteria
- [ ] Game screen background gradient uses SCENE_PALETTES[Math.floor(_levelIdx / 5)] sky0/sky1/sky2 colors
- [ ] Level 1 (idx 0) uses Scene 0 (深蓝 #050816 palette) — same as current default
- [ ] Level 6 (idx 5) uses Scene 1 — visually different background
- [ ] Level 16 (idx 15) uses Scene 3 — visually different
- [ ] Scene 4 (idx 15-19): aurora flag true — render aurora bands on background (teal-green gradient bands)
- [ ] Ground color uses scene.groundColor instead of hardcoded color
- [ ] No visual regression on levels 1-5 (same as before)
- [ ] No console errors
- [ ] Evidence screenshot of level 1 game screen (Scene 0) and level 6 game screen (Scene 1) — STORY-00219-01-scene0.png, STORY-00219-02-scene1.png (if navigation automation allows)
