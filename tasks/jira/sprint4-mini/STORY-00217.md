## Description
As a player, I want to browse the constellation gallery so that I can read about the constellations I've unlocked by completing levels.

## Expected Result
A Canvas-drawn gallery screen showing 30 constellation cards in a scrollable grid. Unlocked constellations are bright/interactive. Tapping an unlocked card shows a detail view with constellation name (ZH+EN), region, best view month, main stars, and lore text. Locked constellations show dimmed/greyed card. Navigation: back to menu.

## Acceptance Criteria
- [ ] Gallery screen accessible from main menu "星座展厅" button
- [ ] 30 constellation cards rendered in a scrollable grid (5 columns × 6 rows or similar)
- [ ] Unlocked cards (matching state.isUnlocked(idx)) show constellation nameZh + icon, bright appearance
- [ ] Locked cards show dimmed appearance + "?" or "🔒" label — no constellation name visible
- [ ] Tapping unlocked card navigates to detail view
- [ ] Detail view renders on Canvas: nameZh, nameEn, icon, region, bestViewMonth, mainStars, lore (full text)
- [ ] Detail view has "返回" button to go back to gallery list
- [ ] Gallery accessible with fresh save (only level 1 unlocked): level 1 card is interactive, others locked
- [ ] No console errors on gallery entry or detail navigation
- [ ] Evidence screenshot: gallery list (STORY-00217-01-gallery.png), detail view (STORY-00217-02-detail.png)
