## Description
As a player who has just completed a level, I want to access the shop and gallery from the victory screen so that I can spend my coins and see my unlocked constellation.

## Expected Result
Victory screen adds two secondary navigation buttons: "去商店" and "看展厅", shown below the 下一关/重玩/选关 row. Tapping navigates to the respective screen. Both screens have "返回" that goes to levels, not back to victory.

- [ ] Victory screen shows "看展厅" button (navigates to gallery, with newly unlocked constellation visible)
- [ ] Both buttons visually distinct from primary action buttons (smaller, secondary style)
- [ ] navigate('shop') routes to shop screen (not menu stub)
- [ ] navigate('gallery') routes to gallery screen (not menu stub)
- [ ] No console errors on navigation to shop or gallery from victory screen
- [ ] Evidence: victory screen screenshot showing both secondary buttons — STORY-00220-01-victory-nav.png (if automation reaches victory state)
