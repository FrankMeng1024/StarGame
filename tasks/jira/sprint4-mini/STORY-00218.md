# STORY-00218: 道具商店 — Canvas商店屏：金币购买6种道具

**Epic**: E-003 道具系统
**Sprint**: Sprint 4-mini
**Sprint Goal**: 内容完整度 — 星座展厅可浏览、商店可购买道具、关卡场景切换
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to spend my coins in a shop to buy items that help me in future levels.

## Expected Result
A Canvas-drawn shop screen showing available items with name, description, cost, and owned count. Player can tap "购买" to spend coins. Items are stored in state.inventory. Shop accessible from main menu and from victory screen.

## Acceptance Criteria
- [ ] Shop screen accessible from main menu (second button or added button)
- [ ] At least 6 items rendered as cards: each showing icon, name, effect description, coin cost, owned count
- [ ] "购买" button per item — tapping deducts coins from state and increments inventory count
- [ ] If coins < cost: "购买" button disabled or shows insufficient message
- [ ] Coin balance displayed at top of shop screen, updates on purchase
- [ ] state.addCoins(-cost) and state.addItem(id, 1) called on purchase
- [ ] Items: 网兜加速(speed), 网兜扩大(enlarge), 宇宙炸弹(bomb), 时间延长(time_ext), 缩小垃圾(shrink), 双倍金币(double_coins)
- [ ] "返回" button navigates back to menu
- [ ] No console errors on shop entry or purchase
- [ ] Evidence screenshot: shop screen showing items (STORY-00218-01-shop.png), after purchase (STORY-00218-02-purchase.png)
