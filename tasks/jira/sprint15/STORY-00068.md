## Description
As a player, I want the gallery and shop UI to be clean and consistent, so that locked content is clearly indicated and buttons have visible backgrounds.

## Expected Result
- Gallery: locked/unseen cards show only a grey placeholder, no icon or name
- Gallery detail: back button at bottom only (top shows name + constellation)
- Shop (main menu): item cards have visible default background (not just on hover)
- Pause overlay: exit button has visible background
- Level grid: 6-column layout fills evenly (last row partial fill is expected but grid shouldn't show empty ghost cells)
