# STORY-00066: 星星大小/亮度区别 (CR-047)

**Epic**: E-003 视觉精修
**Sprint**: Sprint 15
**Sprint Goal**: 视觉核心大升级：少女/网兜/星星重绘，游戏交互精修
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want uncaught stars to be noticeably bright and large, and caught stars to be dim and small, so that I can immediately tell which stars I still need to catch.

## Expected Result
- Uncaught stars: bright, full size, twinkling prominently
- Caught stars: dim (not invisible), small, at original position (shows constellation forming)
- All stars same semantic color (gold/white — don't confuse player with multi-color type system)
- Star sizes tuned: not too small to click, not too large after catching

## Acceptance Criteria
- [ ] 未抓到的星星：半径 r*1.8（放大18×基础尺寸），亮度高，twinkle效果明显
- [ ] 已抓到的星星：半径 r*0.5，globalAlpha 0.25，dim效果
- [ ] 碰撞检测半径对应调整（hitbox = 显示尺寸+10px buffer）
- [ ] 星星颜色：所有星星显示为金黄色/白色（`#fff8e0` 或 `#ffd700`），不再显示恒星光谱色（移除typeToColor的运用）
- [ ] 去除"星星颜色说明"toast（因为不再有多色stars了）
- [ ] 无console error

## UX AC
- [ ] 5秒内新玩家能区分"这个是还没抓的"和"这个已经抓了"
- [ ] 未抓的星星足够大，手指/鼠标能准确点击到

## Dependencies
- None

## Notes
Current _buildStars() uses magToRadius(s.mag) → typically 2-5px. Too small at 720p.
Fix: multiply by ~1.5 at build time, OR scale up in _drawStars().
Uncaught draw: increase to r*1.8 visual radius + glow r*3.5.
Caught draw: r*0.5, alpha 0.25.
Collision in _update (extend): currently `s.r + 8` — keep this or even slightly larger since visual r is now bigger.
Gold color: use '#fff8e0' for base, '#ffd700' for glow (warm white-gold).
Remove _showStarColorHint() call in screens/game.js since multi-color is gone.
