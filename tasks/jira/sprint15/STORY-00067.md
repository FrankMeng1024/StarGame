## Notes
Issue 15: engine.start() calls document.addEventListener('click', this._handleInput) synchronously. The click from level card bubbles up and fires _handleInput immediately. Fix: use setTimeout(..., 300) before adding the click listener, OR listen for 'pointerup' on canvas only (not document).

Issue 8: in _initPause, setPaused(false) sets pauseBtn.textContent = '⏸'. But pauseBtn.onclick = () => setPaused(overlay.classList.contains('hidden')). When overlay is hidden (game running), clicking pauseBtn calls setPaused(true) — correct. Problem may be in "resume via pauseBtn click when overlay visible" — overlay is NOT hidden, so setPaused(false) is called — text should become '⏸'. Need to verify the actual bug.

Issue 7: state.seenScenes is saved to localStorage via state.save(). Change to use sessionStorage directly in engine.js start() instead of state.seenScenes.

Issue 14: _isSlotActive('star_magnet') used in _update — replace with _isSlotActive('net_enlarge') and use it to scale mouthR in _drawNet().
