# STORY-00065: 网兜视觉重绘

**Epic**: E-003 视觉精修
**Sprint**: Sprint 15
**Sprint Goal**: 视觉核心大升级：少女/网兜/星星重绘，游戏交互精修
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the net to look like a real butterfly/star-catching net, so that the game mechanic is immediately understandable and visually appealing.

## Expected Result
The net looks like an actual mesh net bag with a visible hoop/ring and mesh pattern. The current version looks acceptable but needs refinement — larger mouth ring, more visible mesh lines, better color contrast.

## Acceptance Criteria
- [ ] 网兜口（hoop ring）明显可见，金色或银白色，lineWidth ≥ 3
- [ ] 网兜袋体有清晰的网格线（mesh lines），不少于6条
- [ ] 网兜颜色与背景天空有足够对比（不会消失在深色背景中）
- [ ] 延伸（extend）和收回（retract）时网兜形态正确
- [ ] 抓住物体时网兜有视觉变化（膨胀/颜色变化）
- [ ] 绳索（rope from pole to net）清晰可见
- [ ] 网兜速度降低：netSpeed 从 0.025 降到 0.014（约44%减速）
- [ ] 无console error

## UX AC
- [ ] 玩家能立即理解"这是一个网兜/捕网"
- [ ] 不会觉得网兜"直线飞出"而是有弧度感（绳索quadraticCurve已有，保持）

## Dependencies
- None

## Notes
Current _drawNet() already has decent structure: rope + bag fill + mesh lines + hoop ring.
Issues: mouthR = 18 is too small at 1280×720; mesh lines (4 levels) with 0.7 lineWidth are barely visible.
Fix: mouthR → 26, mesh lineWidth → 1.2, hoop lineWidth → 3.5, add 2 more mesh rings (6 total).
netSpeed in engine.js constructor: currently 0.025, reduce to 0.014.
