# STORY-00064: 少女角色重绘

**Epic**: E-003 视觉精修
**Sprint**: Sprint 15
**Sprint Goal**: 视觉核心大升级：少女/网兜/星星重绘，游戏交互精修
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the girl character to look beautiful and anime-quality, so that the game feels polished and delightful.

## Expected Result
The procedural canvas character is visually attractive — clear anime-style proportions, expressive face, elegant outfit. She should look like the protagonist of a quality casual game, not a stick figure.

## Acceptance Criteria
- [ ] 少女的头部比例更大（anime风格标准比例：头身比1:4~1:5）
- [ ] 面部特征清晰：大眼睛（anime style）、小鼻、微笑嘴
- [ ] 头发有立体感（光泽高光、多层次）
- [ ] 服装配色协调（现有紫色系保持）
- [ ] 站立姿态自然，动作帧（swing/extend/retract）各有不同
- [ ] 在 1280×720 分辨率下清晰可见，不模糊
- [ ] 无console error

## UX AC
- [ ] 第一眼看上去是"可爱少女"而非"卡通火柴人"
- [ ] 与星空背景颜色对比度足够，不会消失在背景中

## Dependencies
- None

## Notes
Root cause of ugliness: procedural draw uses very small pixel dimensions (~130px tall) with low-detail polygon shapes. 
Fix: increase size of character to ~160px tall, improve head proportions (HEAD_RY enlarged), add better eye details, improve hair.
Key dimensions in engine.js: charY = H*0.85, poleLen = H*0.18. Character is drawn with cy = charY (feet level).
The sprite-sheet path exists at this._charImgReady but is false — procedural fallback always used.
