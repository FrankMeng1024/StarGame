# STORY-00224: 补齐M7道具 — 磁力星引 + 宇航员手套

**Epic**: E-003 道具系统
**Sprint**: Sprint 6-mini
**Sprint Goal**: PRD完整度 — 补齐M7剩余两种道具
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want all 8 PRD items to be available in the shop so that I have the full strategic toolkit for difficult levels.

## Expected Result
Two new items added to shop.js and game.js:
- **磁力星引** (star_magnet, 🧲, 80金): Stars within 80px of net head drift toward it at 1.2px/frame (dt-normalized). Active for full level.
- **宇航员手套** (glove, 🧤, 70金): When debris is caught, no retraction slowdown — net retracts at full speed. Active for full level.

## Acceptance Criteria
- [ ] shop.js ITEMS array gains two new entries: { id:'star_magnet', icon:'🧲', nameZh:'磁力星引', desc:'本关星星主动靠近网兜', cost:80 } and { id:'glove', icon:'🧤', nameZh:'宇航员手套', desc:'抓到垃圾不减速', cost:70 }
- [ ] game.js: `_magnetActive` boolean flag, reset in `_cleanup()` and on showGame() entry
- [ ] game.js: When `_magnetActive`, stars not yet caught move toward net head by `1.2 * dt * 60` px per frame — capped so they don't overshoot
- [ ] game.js: `_gloveActive` boolean flag, reset in `_cleanup()` and on showGame() entry
- [ ] game.js: When debris is caught and `_gloveActive` is true, net retracts at normal speed (no slowdown multiplier applied)
- [ ] game.js: `showGame()` reads state.selectedItems and sets `_magnetActive` / `_gloveActive` from 'star_magnet' / 'glove' IDs (alongside existing item flags)
- [ ] Item selection overlay in levels.js shows the two new items when owned (tests automatically with ITEMS array from shop.js)
- [ ] No console errors

## Dependencies
- Depends on: STORY-00221 (item effect system in place — Done)

## Notes
Mini currently has 6 items; PRD M7 requires 8. This story adds the 2 missing ones.
Star magnet: apply force each _update() frame to uncaught stars' x,y positions toward (_netHeadX, _netHeadY).
Glove: mini currently doesn't have debris-slow mechanic — debris is caught and net retracts normally. So glove is a no-op unless we add the slow first. Decision: add a small 0.6× speed penalty on debris catch to make glove meaningful, then glove negates it.
