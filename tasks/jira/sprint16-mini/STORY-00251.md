## Description
As a player browsing the gallery, I want to see the constellation star chart with connecting lines and star glow, so that I can learn the actual shape of each constellation.

## Expected Result
In gallery detail view, below the constellation name, a star chart is drawn showing the constellation's stars (sized by magnitude, colored by type) with golden connecting lines and glow effects. This matches the web gallery's _drawStarChart() implementation.

## Acceptance Criteria
- [ ] Star chart drawn in gallery detail view, above photo carousel
- [ ] Stars sized by magnitude using magToRadius() (imported from constellations.js)
- [ ] Stars colored by stellar type using typeToColor() (import or inline)
- [ ] Constellation lines drawn between star pairs using con.lines data
- [ ] Lines have golden color (rgba(255,215,0,0.55)) with soft glow (shadowBlur)
- [ ] Stars have radial gradient glow effect
- [ ] Chart fits within detail card layout (does not overflow)
- [ ] No console errors

## Notes
Reference: js/screens/gallery.js _drawStarChart() function. mini constellations.js already has .stars, .lines, .mag, .type data — verify before coding.
