# STORY-00252: 游戏内道具计时HUD槽 — 触屏激活+倒计时

**Epic**: E-003
**Sprint**: Sprint 16-mini
**Sprint Goal**: 小游戏质量对齐Web版
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see my selected items as activatable slots during gameplay, so that I can choose WHEN to use timed items tactically instead of having all effects apply at once.

## Expected Result
During gameplay, up to 3 item slots are drawn at bottom-right HUD. Each slot shows: item icon, a tap zone (numbered 1/2/3). Tapping a slot activates the item — timed items (net_speed 15s, net_enlarge 15s, shrink_debris 30s, glove 30s) show a countdown bar that depletes. Instant items (time_ext, space_bomb) activate immediately. double_coins is passive (auto, shown differently). Items are consumed on activation, not at level start.

## Acceptance Criteria
- [ ] Up to 3 item slot boxes drawn in HUD during gameplay (bottom-right corner)
- [ ] Each slot shows item icon + slot number (1/2/3)
- [ ] Tapping a slot box activates the item
- [ ] Already-used slots are visually dimmed/expired
- [ ] Timed items show a countdown bar (width shrinks over duration)
- [ ] Item effects ONLY apply when slot is tapped (not at level start)
- [ ] double_coins passive item shown in HUD as "auto" — no tap required
- [ ] Items consumed via state.useItem() on activation
- [ ] No slot tap interference with net launch (tap zones must not overlap net launch area)
- [ ] Works in landscape orientation

## Notes

Item durations: net_speed=15s, net_enlarge=15s, space_bomb=instant, time_ext=instant, shrink_debris=30s, star_map=60s (if present), glove=30s.
Slot tap detection: add to _onTouchEnd, check tap coordinates against slot boxes. Slot boxes must be drawn in _drawHUD().
