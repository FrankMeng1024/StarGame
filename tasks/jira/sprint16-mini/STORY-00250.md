## Description
As a player, I want to see a cinematic intro animation when the game loads, so that the experience feels polished and immersive.

## Expected Result
On first launch (and every launch), a ~12s Canvas animation plays: Phase 1 meteor shower (0-3s), Phase 2 random constellation nodes + lines appear one-by-one (3-8s), Phase 3 title "追星少女" fades in (8-12s). Tap anywhere to skip. After completion, navigates to menu.

## Acceptance Criteria
- [ ] Intro plays automatically on game launch (before menu is shown)
- [ ] Phase 1: gold diagonal meteor streaks drawn on dark sky canvas (0-3s)
- [ ] Phase 2: constellation star nodes appear one-by-one with connecting lines (3-8s)
- [ ] Phase 3: "追星少女" title text fades in center screen (8-12s)
- [ ] Tap/touch anywhere skips intro immediately and proceeds to menu
- [ ] Canvas cleaned up after intro (no memory leak — destroy canvas/RAF)
- [ ] No console errors during or after intro
- [ ] Works in landscape orientation (W > H)
