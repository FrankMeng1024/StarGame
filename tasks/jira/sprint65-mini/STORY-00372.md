# STORY-00372: 游戏背景升级 — 草地层 + 背景星分层

**Epic**: 游戏视觉质量提升  
**Sprint**: Sprint 65-mini  
**Sprint Goal**: 游戏背景视觉升级：细草地面层 + 背景星星分层  
**Points**: 3  
**Owner**: Frontend Dev  
**Status**: Done  

## Description
As a player, I want the game background to feel more immersive, so that the star-catching experience feels like a real night sky with foreground detail.

## Expected Result
1. 5-8 bezier grass stems appear at the base of the screen near the pole, swaying slightly
2. Background stars are split into a far layer (50 stars, slow/dim) and near layer (20 stars, brighter, some with cross sparkles)
3. These elements don't interfere with gameplay or existing star rendering

## Acceptance Criteria
- [ ] Grass stems visible at bottom of game screen (near poleX), height ~H×0.04, dark `#050810`
- [ ] Grass stems sway with time (±2°, t×0.8 speed)
- [ ] Far background layer: ~50 stars, r=0.4-0.8px, low alpha (0.1-0.25), slow drift
- [ ] Near background layer: ~20 stars, r=1.2-2.0px, higher alpha (0.3-0.6), 5-8 with cross diffraction lines
- [ ] No regression: gameplay stars, girl, net all render correctly
- [ ] Screenshot evidence from game screen confirms visual improvement

## Notes
Sprint C from visual upgrade plan. Background elements are decorative overlays — they must not affect game logic.
