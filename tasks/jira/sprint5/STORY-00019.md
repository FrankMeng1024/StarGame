# STORY-00019: 背景音乐 — procedural ambient loop

**Epic**: E-001
**Sprint**: Sprint 5
**Sprint Goal**: 感官完整度 — 音效与反馈polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want soft ambient background music while playing, so that the game feels immersive and atmospheric.

## Expected Result
A simple procedural ambient music loop plays during gameplay, generated entirely via Web Audio API (no external files). Music pauses on menu screens and resumes on game entry.

## Acceptance Criteria
- [ ] Ambient loop plays when game screen is active (starts on first user interaction per Chrome policy)
- [ ] Loop uses soft sine-wave pads at low volume (≤0.15 master gain) — does not mask sound effects
- [ ] Music pauses/stops when navigating away from game screen
- [ ] Music respects the global mute toggle from STORY-00018
- [ ] No audio errors in console
- [ ] Loop is seamless (no audible click at loop point)

## Dependencies
- Depends on: STORY-00018 (AudioContext + mute system)

## Notes
Use a simple 8-bar chord progression (Am - F - C - G) with 4 sine oscillators per chord at low amplitude. Schedule notes via AudioContext.currentTime scheduling for tight looping.
