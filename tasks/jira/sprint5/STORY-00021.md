# STORY-00021: UX polish — time_ext flash + passive item HUD indicator

**Epic**: E-005
**Sprint**: Sprint 5
**Sprint Goal**: 感官完整度 — 音效与反馈polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want clear visual confirmation when I use time_ext, and a persistent reminder of which passive buffs are active during gameplay, so that I understand what my items are doing.

## Expected Result
Using time_ext shows a brief "+20秒" flash near the timer. A small icon row in the HUD corner persists for the duration of the level showing active passive items.

## Acceptance Criteria
- [ ] time_ext activation: "+20秒" text floats up near the HUD timer (similar to penalty-text pattern), fades out after 1.2s
- [ ] Passive item HUD row: small icons (emoji) displayed in a horizontal row in top-right HUD area; visible for the full level duration once items are activated
- [ ] Passive item row is not clickable (display only)
- [ ] Passive item row does not overlap star count or timer
- [ ] Row only shows if activeItems Set is non-empty
- [ ] No layout regression on 375px mobile viewport

## Dependencies
None

## Notes
time_ext flash: create a DOM element positioned near .hud-timer (absolute, same pattern as .penalty-text). Passive item row: create after engine.activeItems Set is populated, render emoji badges in .hud-top or a new .hud-passive-row div.
