## Description
As a player, I want to see my best performance (star rating + time remaining) on each level card, so that I'm motivated to replay levels and beat my record.

## Expected Result
Level select cards for completed levels display star rating (1-3 ★) and best time-remaining clearly. Level complete screen shows whether current run beats the previous best.

## Acceptance Criteria
- [ ] Level card shows star rating (e.g. ★★☆) for completed levels — already partially present; confirm renders correctly after unlock
- [ ] Level card shows best time remaining (e.g. "最佳: 45秒") below star rating
- [ ] Level complete screen shows "新纪录！" badge if current run beats previous best (more stars, or same stars + more time)
- [ ] "新纪录！" badge animates in (CSS keyframe, 0.3s scale-in)
- [ ] Best score persists across page reload (localStorage)
- [ ] No regression on existing star rating storage (state.setScore already stores best)

## Dependencies
None
