## Description
As a player, I want the mini game intro title to look identical to the Web version — using the Ma Shan Zheng calligraphy font, plain light-purple color, tight character spacing, and a "StarCatcher" subtitle below.

## Expected Result
Phase 3 of the intro animation shows:
- "追星少女" in Ma Shan Zheng calligraphy font, `#e8d5ff` color, `#b090ff` shadow (shadowBlur 18)
- No character spacing (紧排, same as Web)
- "StarCatcher" subtitle in smaller font below, `rgba(200,200,255,0.7)`
- Font loaded via `wx.loadFontFace()` at animation start; fallback to `serif` if load fails

## Acceptance Criteria
- [ ] `wx.loadFontFace()` called in `showIntro()` with Ma Shan Zheng CDN URL
- [ ] Phase 3 title uses `Ma Shan Zheng` (or fallback `serif`) — NOT `sans-serif`
- [ ] Title text is `'追星少女'` — no spaces between characters
- [ ] Title color: `#e8d5ff` solid fill (no gradient)
- [ ] Title shadow: `shadowColor=#b090ff`, `shadowBlur=18`
- [ ] Font size: `W * 0.045` (responsive, not fixed px)
- [ ] "StarCatcher" subtitle rendered below title in `Noto Sans SC` or fallback `sans-serif`, `rgba(200,200,255,0.7)`
- [ ] Screenshot at t=11s shows calligraphic title matching Web style

## Dependencies
None — isolated to intro.js Phase 3 title rendering + font loading
