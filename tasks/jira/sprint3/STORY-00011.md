# STORY-00011: Star rating (1-3 stars) on complete screen

**Epic**: E-007
**Sprint**: Sprint 3
**Sprint Goal**: 完善游戏完整度
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to earn 1-3 stars based on how quickly I complete a level, so that I have a reason to replay and improve.

## Expected Result
Complete screen shows 1, 2, or 3 filled stars. Level select cards update to show the best star rating achieved. State persists to localStorage.

## Acceptance Criteria
- [ ] Star rating calculated as: 3 stars = caught all + timeLeft > 50% of startTime; 2 stars = caught all + timeLeft > 20%; 1 star = caught all (any remaining time)
- [ ] Complete screen displays correct star count (e.g. "★★★", "★★☆", "★☆☆")
- [ ] Level select card updates to show best star rating for completed levels (not all 5 grey stars)
- [ ] `state.setScore` stores star rating; best rating persists on replay
- [ ] game.js passes correct star count to `state.setScore` (not hardcoded 3)
- [ ] All viewports: 1280×720 ✓

## Dependencies
- STORY-00010 (time limits must be correct before star thresholds make sense)

## Notes
Currently `game.js:119` has `state.setScore(idx, { stars: 3, time: timeLeft })` — hardcoded to 3. Must calculate based on timeLeft vs startTime. Level card currently renders `★`.repeat(score.stars) but score is never <3 with current code.
