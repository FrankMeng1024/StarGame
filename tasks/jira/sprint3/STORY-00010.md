# STORY-00010: Difficulty-based time limits

**Epic**: E-002
**Sprint**: Sprint 3
**Sprint Goal**: 完善游戏完整度
**Points**: 2
**Owner**: Frontend Dev

## Description
As a player, I want harder constellations to have less time, so that difficulty progression feels real and challenging.

## Expected Result
Level 1 (difficulty 1) starts with 90s. Level 3 (difficulty 2) starts with 80s. A difficulty-5 level starts with 50s. The HUD timer reflects the correct starting time. Fail screen elapsed time is calculated from the correct starting time.

## Acceptance Criteria
- [ ] Engine reads `CONSTELLATIONS[idx].difficulty` to set starting time: diff 1=90s, 2=80s, 3=70s, 4=60s, 5=50s
- [ ] HUD timer initialises to the correct time (e.g. "01:30" for diff 1, "00:50" for diff 5)
- [ ] `getStatus().timeLeft` returns the difficulty-appropriate starting value
- [ ] Fail screen elapsed = starting_time − timeLeft at fail (still accurate)
- [ ] Coin formula still uses remaining timeLeft (not affected by starting time)
- [ ] All viewports: 1280×720 ✓

## Dependencies
- None

## Notes
`LEVEL_TIME = 90` constant in engine.js:6 must become a per-level lookup. Formula: `TIME_BY_DIFFICULTY = {1:90, 2:80, 3:70, 4:60, 5:50}`.
