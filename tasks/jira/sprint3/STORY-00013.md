# STORY-00013: HUD last-10s warning + debris time-penalty visual feedback

**Epic**: E-001

**Sprint Goal**: 完善游戏完整度
**Points**: 2

## Description
As a player, I want a clear visual warning when time is running low, and visible feedback when I catch debris (time penalty), so I understand the game state without confusion.

## Expected Result
When ≤10s remain the timer pulses red. When debris is caught, a brief "-1s" or "-0.5s" red text flash appears near the character.

## Acceptance Criteria
- [ ] Timer element gets `.warning` class when timeLeft ≤ 10 (already wired in engine — verify CSS pulse animation is visible)
- [ ] Timer CSS `.warning` state: red color + pulse animation (not just color change)
- [ ] Debris catch triggers a brief floating text "-Xs" near character position (CSS animation, auto-removes)
- [ ] Penalty amount matches PRD (0.5s for small debris, 1s for large — or uniform 1s if simplified)
- [ ] Penalty text does not block gameplay or persist > 1.5s
- [ ] All viewports: 1280×720 ✓

## Dependencies
- None
