# STORY-00012: Shop UX improvements — ownership count + type legend

**Epic**: E-003
**Sprint**: Sprint 3
**Sprint Goal**: 完善游戏完整度
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see how many of each item I already own before buying, and understand what "持续型" vs "消耗型" means, so I can make informed purchasing decisions.

## Expected Result
Each shop card always shows owned quantity (even 0). A legend or tooltip explains the two item types. Pre-purchase clarity is achieved without needing to buy first.

## Acceptance Criteria
- [ ] Shop card shows "持有: ×N" for all items (N=0 if not owned, N>0 if owned) — not hidden when qty=0
- [ ] A type legend appears at the top of the shop grid: "持续型 = 本关全程生效 | 消耗型 = 手动激活，用完即止"
- [ ] Type badge on each card clearly distinguishes 持续型 (e.g. green) vs 消耗型 (e.g. orange)
- [ ] Visual distinction between 0-owned and N-owned states is clear
- [ ] All viewports: 1280×720 ✓

## Dependencies
- None (shop already exists)
