# STORY-00132: 开场动画每次F5播放，游戏内返回不播放 (CR-085)

**Epic**: E-027 Cover Polish
**Sprint**: Sprint 32
**Sprint Goal**: 关卡加载极速化
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
Remove localStorage gate from playIntro(). Intro plays on every fresh page load. In-app navigation back to menu never calls playIntro() (it calls resumeMenuSky() instead), so this is zero-risk.

## Expected Result
- F5/hard reload always shows the intro animation
- Navigating from game → menu (fail, complete, pause) shows menu directly without intro
- No localStorage key written or checked

## Acceptance Criteria
- [x] F5 triggers intro animation every time
- [x] Navigate back from game does not replay intro
- [x] No localStorage entries for intro
- [x] Zero console errors
