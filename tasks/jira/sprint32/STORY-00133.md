# STORY-00133: 关卡加载极速化 — decode Promise缓存复用 (CR-086)

**Epic**: E-027 Cover Polish
**Sprint**: Sprint 32
**Sprint Goal**: 关卡加载极速化
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
Level load time was 3+ seconds because getSpriteReady() called img.decode() on every invocation, re-rasterizing complex SVGs. Fix: store the decode Promise once in _decodeCache at prewarm time, return it directly on all subsequent calls.

## Root Cause
`getSpriteReady()` was calling `cached.decode()` every time it was invoked — even after the image was already decoded. `img.decode()` re-rasterizes the SVG each time, which takes 3+ seconds for girl.svg (440px wide, 4 animation frames with gradients).

## Fix
- `_prewarmAssets()` IIFE now creates `_decodeCache[src] = new Promise(...)` immediately on `onload`
- `getSpriteReady()` returns `_decodeCache[src]` directly (already-resolved Promise) on all subsequent calls
- No decode() call ever happens more than once per sprite

## Expected Result
- Any level loads and game canvas appears within 1 second of card click
- Timer starts immediately, character visible from frame 1
