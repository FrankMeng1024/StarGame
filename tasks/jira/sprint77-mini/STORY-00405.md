## Description
As a player, I want the result screen (success and fail) to look polished and professional, so that the end of each level feels rewarding and emotionally resonant.

## Expected Result
- Success screen: vibrant gold/purple gradient card, large star rating displayed prominently, constellation name shown, clear action buttons with good contrast
- Fail screen: atmospheric cold-blue card, encouraging text visible, constellation silhouette visible, buttons clearly distinguishable
- Both screens: buttons are 44px tall (large enough to tap comfortably), well-spaced, clearly labeled with contrasting text

## Acceptance Criteria
- [ ] Success card background: rich deep-purple/navy gradient (not washed out), semi-transparent (97% opacity)
- [ ] Success screen shows 1-3 stars prominently (size ≥ 24px each) in the top half of the card
- [ ] Constellation name displayed in 16px+ font, visible against card background
- [ ] Action buttons (下一关/重玩/选关 or 重试/选关) have height ≥ 44px and occupy full card width minus 24px padding
- [ ] Button text size ≥ 14px with white/light text on gradient background — legible contrast (≥ 3:1)
- [ ] Fail screen encouragement text readable (≥ 12px, contrast ≥ 3:1 against card background)
- [ ] No button is cut off or partially off-screen at 667×375 canvas
- [ ] UX AC: First-time user can identify success vs fail immediately from card visual style (gold vs cold-blue)
