# STORY-00408: 连击+5s时间奖励可见提示

**Epic**: E-009 游戏性核心
**Sprint**: Sprint 77-mini
**Sprint Goal**: 修复结算页按钮无响应 + 提升结算/商店UI质量 + 骨骼动画加肉
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see "+5s" appear when I get a 3+ combo, so that I understand why extra time was added to my countdown.

## Expected Result
When a x3+ combo is scored, a "+5s" indicator briefly appears near the timer HUD, helping players connect combo play to time reward.

## Acceptance Criteria
- [ ] When `_comboCount >= 3` and `+5s` bonus is applied, a "+5s" text briefly appears near the timer area (top-left HUD zone)
- [ ] "+5s" popup fades out over 1.5s (similar to combo popup fade)
- [ ] "+5s" text uses green/teal color (e.g. `#44ff88`) with slight glow — distinct from the gold combo popup
- [ ] Popup does not obscure the timer digit itself
- [ ] UX AC: Player who gets a 3+ combo sees both "x3 连击!!" AND "+5s" — both indicators visible simultaneously for at least 0.8s

## Dependencies
- None

## Notes
Current combo popup is at H*0.25. Place "+5s" at H*0.08, X = W*0.15 (near timer area, top-left).
New state variables needed: `_timeBonusPopup = null` (similar to `_comboPopup`).
In `_checkCollisions` where +5s is applied, also set `_timeBonusPopup = { alpha: 1.0 }`.
In render loop, draw `_timeBonusPopup` if `alpha > 0`, then fade `alpha -= dt * 60 / 90` (1.5s fade).
