## Description
As a player, I want the girl character to have a visible body (torso + head) with skeletal arms rather than a full sprite sheet, so that the arm movement feels natural and anatomically correct.

## Expected Result
The girl character renders using body_no_arms.png for the torso/head, with canvas-drawn skeletal arms (bones). This replaces the current full-body sprite sheet rendering.

## Implementation Plan (from approved plan rustling-swimming-sundae.md)

### Resource
`docs/demo/parts2/body_no_arms.png` → copy to `miniprogram/assets/sprites/body_no_arms.png`

### Coordinate System
- Canvas: W × H (dynamic, landscape)
- Pole base: `_poleX = W/2`, `_poleY = H * 0.87`
- Current girl render: `dstX = _poleX - 55`, `dstY = _poleY - 110 + 12`, `dstW = 110`, `dstH = 110`
- Sprite: 220×220 px → scale = 0.5 → 110×110 in-game
- Shoulder offsets (220px space): L_SHX=83, L_SHY=117 → scaled: (83*0.5, 117*0.5) = (41.5, 58.5) from dstX/dstY
- Left shoulder world: `dstX + 41.5`, `dstY + 58.5`
- Right shoulder world: `dstX + 133*0.5`, `dstY + 117*0.5` = `dstX + 66.5`, `dstY + 58.5`

### Arm Lengths (scaled to 0.5)
- Upper arm: 28*0.5 = 14px
- Forearm: 26*0.5 = 13px
- Hand radius: 6*0.5 = 3px
- Pole: 68*0.5 = 34px

### Bone Drawing
- Left arm: fixed "relaxed" pose — upper arm pointing down-left (~200°), forearm bent inward
- Right arm: follows `_netAngle` for swing/extend, maps to shoulder→elbow→hand→pole
  - swing: oscillating angle from `_skelSwingPhase`
  - extend/retract: right arm extends upward following pole angle

### Image Loading
```js
const _bodyNoArmsImg = (() => {
  const img = wx.createImage();
  img.src = 'assets/sprites/body_no_arms.png';
  return img;
})();
```

### `_drawGirl(ctx)` replacement
1. Draw body_no_arms.png at current frame (frame 0 for idle/swing/extend, frame 1 for blink — same blink logic)
2. Draw left arm (fixed relaxed pose)
3. Draw right arm (driven by `_netAngle` and `_netState`)
