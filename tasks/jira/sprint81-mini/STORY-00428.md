## Description
As a player who failed a level, I want to see useful statistics about my attempt so that I understand what went wrong and feel motivated to improve.

## Expected Result
The fail result card shows 3 stat lines: catch rate, time consumed, and a contextual improvement tip. This replaces the current minimal single-line display.

## Acceptance Criteria
- [ ] AC1: Fail card shows 3 stat lines: (1) "捕获进度: X/Y (NN%)" in `rgba(160,190,255,0.85)`, (2) "用时: Ns / 总计Ns" in `rgba(200,200,220,0.70)`, (3) contextual tip line. Each line 11px font, 14px vertical spacing.
- [ ] AC2: Contextual tip: catch rate ≥ 80% → "差一点就成功了！再试一次！" in `#a0ffa0` (light green); rate ≥ 50% → "注意瞄准再发射网兜" in `#ffd080` (amber); rate < 50% → "试试使用道具来帮助你" in `#a0e0ff` (cyan, promotes shop).
- [ ] AC3: The constellation encouragement line (e.g. "猎户座还在等你，再试一次！") is preserved above the stats block.
- [ ] AC4: Stats block is positioned between the encouragement line and the existing constellation silhouette/stardust area. If space is insufficient (< 50px total content height), the silhouette is hidden to show all stats.
- [ ] AC5: Time display shows integer seconds (`Math.floor`). Catch percentage is `Math.round(caught/total*100)`. If `_total === 0`, shows "捕获进度: 0/0 (—)" to avoid division-by-zero display.
