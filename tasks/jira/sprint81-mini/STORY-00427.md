# STORY-00427: 抓空惩罚 — 0.5s冷却+疲惫动画

**Epic**: E-008 游戏体验精化
**Sprint**: Sprint 81-mini
**Sprint Goal**: 提升游戏核心手感 — 星星捕获视觉升级、首通/重玩文案区分、下一关预告、抓空惩罚、失败统计
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want there to be a cost to launching the net carelessly, so that careful aiming feels rewarding and the game has meaningful skill differentiation beyond button-mashing.

## Expected Result
When the net extends to full length and retracts empty (no catch), a 0.5-second cooldown prevents re-launch. The character shows a subtle "tired" visual. Touch is ignored during cooldown. Timer continues.

## Acceptance Criteria
- [ ] AC1: When the net completes a full extend-then-retract cycle without catching any star or debris, a 0.5-second miss cooldown is applied. During cooldown, net hangs at pole and touch input is blocked (cannot launch).
- [ ] AC2: During cooldown, the girl's body alpha drops to 0.6 and a small "..." text appears above her head (alpha fading 0.8→0 over 0.5s). Text positioned at approximately girl head position - 20px Y.
- [ ] AC3: If the net catches a star OR debris during the extend/retract cycle, no cooldown is applied — existing behavior unchanged. Debuff tracks via a `_caughtThisShot` boolean, set true on any catch, reset on each launch.
- [ ] AC4: Game timer continues counting down during cooldown — missing has a real time cost.
- [ ] AC5: Cooldown is dt-scaled (not frame-counted). Net returns to normal swing state exactly 0.5 seconds after the empty return, regardless of frame rate.

## Dependencies
- None

## Notes
Add `_missCooldown = 0` and `_caughtThisShot = false`. Set `_caughtThisShot = true` in star catch code and debris catch code. In retract-complete logic: if `!_caughtThisShot`, set `_missCooldown = 0.5`. In update: decrement `_missCooldown -= dt`. In `_onTouch` launch check: block if `_missCooldown > 0`. In `_drawGirl`: multiply alpha by (0.6 if `_missCooldown > 0` else 1.0). Draw "..." above girl during cooldown.
