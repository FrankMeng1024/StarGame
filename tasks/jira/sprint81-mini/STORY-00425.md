# STORY-00425: 首通与重玩文案区分 — "首次通关！"vs"新纪录！"

**Epic**: E-008 游戏体验精化
**Sprint**: Sprint 81-mini
**Sprint Goal**: 提升游戏核心手感 — 星星捕获视觉升级、首通/重玩文案区分、下一关预告、抓空惩罚、失败统计
**Points**: 2
**Owner**: Frontend Dev

## Description
As a player, I want the result screen to show appropriate messaging for first completions vs. record-breaking replays, so that the congratulations feel genuine.

## Expected Result
First-ever completion → "首次通关！" in cyan (no "最高分:" prefix). Replay with improved score → "最高分: N ★  新纪录！" in gold. Replay without improvement → "最高分: N ★" with no badge.

## Acceptance Criteria
- [ ] AC1: When `_result.prevBest === null` (first-ever completion), the personal best line shows "首次通关！" in `#a0e0ff` (light cyan), no "最高分:" prefix.
- [ ] AC2: When `_result.prevBest !== null` AND `_result.newRecord === true`, line shows "最高分: N ★  新纪录！" with gold "新纪录！" badge — existing behavior, unchanged.
- [ ] AC3: When `_result.prevBest !== null` AND `_result.newRecord === false`, line shows "最高分: N ★" (previous best) without any badge.
- [ ] AC4: The "首次通关！" text has a subtle pulse animation (alpha oscillating 0.8-1.0 at 2Hz) for 2 seconds, then static.
- [ ] AC5: All three display states render correctly within the result card without overlapping other elements.

## Dependencies
- None
