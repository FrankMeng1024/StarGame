# STORY-00043: 少女角色精灵图动画

**Epic**: E-001 核心游戏引擎
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the girl character to have detailed animation states (idle, throw, catch) instead of basic geometric shapes, so that the character feels alive and the gameplay has visual personality.

## Expected Result
The girl character is rendered with significantly higher visual quality — either via a CC0 sprite sheet with frame animation for idle/throw/catch states, or via a substantially upgraded procedural canvas drawing with hair details, dress, glowing net, and proper proportions.

## Acceptance Criteria
- [ ] **Primary path (sprite sheet)**: If a suitable CC0/free sprite is found:
  - [ ] Sprite sheet loaded and drawn via `drawImage` with frame cycling
  - [ ] At least 3 animation states: idle (standing/gentle sway, 2+ frames), throw (arm extended upward, 2+ frames), catch (net outstretched receiving, 2+ frames)
  - [ ] Frame animation runs smoothly at gameplay speed without jitter
  - [ ] Sprite source and license documented in a comment in the drawing code (e.g. "Source: itch.io/xxx, License: CC0")
  - [ ] Sprite sheet file committed to project assets directory
- [ ] **Fallback path (upgraded procedural drawing)**: If no suitable CC0 sprite is found:
  - [ ] Hair drawn with visible strands/volume (not a single ellipse)
  - [ ] Dress/outfit with visible folds, color detail, and a distinct silhouette
  - [ ] Glowing net effect — net mesh lines and a soft glow aura around the net head
  - [ ] Proper human proportions (head-to-body ratio ~1:5 for anime style)
  - [ ] At least idle and throw states visually distinguishable (body pose changes between states)
- [ ] Whichever path: the character is visually recognizable as "a girl with a net catching stars" at 1280x720 — not an abstract shape
- [ ] Character animation syncs with gameplay state: idle when net is swinging, throw when net is extending, catch when net contacts a star
- [ ] No performance regression — character rendering at 60fps with existing game elements
- [ ] [UX] Character feels like the protagonist of the game — has visual personality and presence, not a generic placeholder
- [ ] [UX] Animation state transitions are smooth — no jarring frame jumps between idle/throw/catch

## Dependencies
- None

## Notes
Web search for CC0 sprites must happen during implementation. Candidate sources: itch.io free game assets, OpenGameArt.org, Kenney.nl. Search terms: "anime girl sprite sheet free", "character sprite CC0", etc. Developer must verify the license before using any asset. If nothing suitable is found within reasonable search time, proceed with the fallback path — the fallback must still be a significant visual upgrade over the current basic shapes.
