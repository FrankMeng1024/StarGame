# STORY-00044: 全局视觉升级 — 屏幕过渡 + 玻璃卡片 + 渐变文字

**Epic**: E-005 主界面与关卡选择UI
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want screen transitions, glass-morphism cards, and gradient text titles throughout the game UI, so that every screen feels like a premium, polished experience worthy of the "追星少女" fantasy.

## Expected Result
All major screen transitions use fade + subtle scale animations. Cards (level select, gallery, shop) use glass-morphism styling. Title text uses CSS gradient fills. Buttons have gradient fills with glow hover states.

## Acceptance Criteria

### Screen Transitions
- [ ] Navigating between major screens (menu → level select, menu → gallery, level select → gameplay, gameplay → completion, etc.) uses a fade transition (opacity 0→1) with a slight scale effect (e.g. scale 0.97→1.0)
- [ ] Transition duration is 200-400ms — fast enough to feel responsive, slow enough to be perceived
- [ ] No flash of unstyled/blank content during transitions
- [ ] Back-navigation uses the same transition (or a reverse variant)

### Glass-morphism Cards
- [ ] Level select cards use glass-morphism: `backdrop-filter: blur(10px)`, semi-transparent background (e.g. `rgba(26, 31, 78, 0.6)`), subtle luminous border (e.g. `border: 1px solid rgba(124, 92, 191, 0.3)`)
- [ ] Gallery constellation cards use the same glass-morphism treatment
- [ ] Shop item cards use the same glass-morphism treatment
- [ ] Glass effect is visible against the night-sky background — cards appear to float above the background with depth
- [ ] Cards have a subtle hover state: border glow intensifies or background lightens slightly on hover

### Gradient Text Titles
- [ ] Main menu title "追星少女" uses CSS gradient text: `background: linear-gradient(...)` + `background-clip: text` + `color: transparent`
- [ ] Gradient uses the game's palette (e.g. gold → warm orange, or purple → blue per `--primary-gradient`)
- [ ] Section headers on other screens (e.g. "星座展厅", "道具商店", "选择关卡") also use gradient text treatment
- [ ] Gradient text remains legible against the dark background

### Gradient Buttons with Glow
- [ ] All primary action buttons use gradient fills (not flat colors) — consistent with `--primary-gradient`
- [ ] Buttons have a visible glow on hover (e.g. `box-shadow: 0 0 20px rgba(124, 92, 191, 0.5)`)
- [ ] Buttons have a subtle pressed/active state (slightly darker or inset shadow)
- [ ] Button text has sufficient contrast against the gradient background

### General
- [ ] All visual upgrades work at all three viewports (1280x720, 1440x900, 1920x1080)
- [ ] No performance regression from backdrop-filter usage — if blur causes lag on lower-end systems, provide a graceful degradation (reduce blur radius or remove)
- [ ] [UX] Visual upgrades feel cohesive — glass, gradients, and transitions share the same design language (night-sky fantasy theme), not a random collection of effects
- [ ] [UX] Hover/active feedback on every interactive element (buttons, cards) — nothing feels "dead" when moused over

## Dependencies
