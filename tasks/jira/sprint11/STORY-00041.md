# STORY-00041: 完结界面布局改善

**Epic**: E-007 关卡完成体验
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the level-complete and level-fail screens to fit entirely within the viewport without scrolling, with enough space for lore text, so that the completion moment feels polished and I can read the constellation story comfortably.

## Expected Result
Level-complete and level-fail overlays fit within 100vh. Dead space is minimized. Lore text area displays at least 200 characters without scrolling; longer text appears in a styled scrollable area. Optional: auto-scroll animation for long text.

## Acceptance Criteria
- [ ] Level-complete overlay fits entirely within 100vh at primary viewport (1280x720) — no vertical page scroll needed to see all content
- [ ] Level-fail overlay fits entirely within 100vh at primary viewport (1280x720) — no vertical page scroll needed
- [ ] Canvas animation area (constellation connect animation) is reduced in height to reclaim space for text content, without losing visual impact of the animation
- [ ] Top padding / dead space above the overlay content is reduced compared to current implementation
- [ ] Lore text area shows at least 200 visible characters without requiring any scroll interaction
- [ ] When lore text exceeds the visible area, a scrollable container activates with a styled scrollbar (matching the game's night-sky theme — thin, semi-transparent, rounded)
- [ ] Optional: auto-scroll animation that slowly scrolls long lore text at a readable pace (if implemented, must be pausable by user hover/touch)
- [ ] Gold coin reward, star rating, and action buttons ("下一关" / "重试" / "返回") all remain visible without scrolling
- [ ] [UX] The transition from gameplay to completion screen feels like a rewarding moment, not a cramped info dump — visual hierarchy guides the eye from animation → result → lore → actions
- [ ] [UX] Lore text is legible (sufficient font size and contrast against the overlay background)

## Dependencies
- None

## Notes
CR-014 specifies "reduce dead space" and "styled scrollable text area showing >= 200 chars". The canvas animation area at the top of the overlay is the primary space to reclaim.
