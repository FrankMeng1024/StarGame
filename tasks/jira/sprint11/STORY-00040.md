# STORY-00040: 精致化宇宙垃圾视觉

**Epic**: E-001 核心游戏引擎
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want each type of space debris to look like a recognizable, detailed object instead of a grey blob, so that dodging them feels meaningful and the game world looks rich.

## Expected Result
All 4 debris types (meteor, satellite, rocket, cloth) are visually distinct, detailed canvas drawings with glow trails and characteristic details. Each type is immediately recognizable at gameplay speed.

## Acceptance Criteria
- [ ] **Meteor**: drawn as an irregular rocky shape with warm orange/red glow trail; surface has crater-like texture details (shadow spots); visually distinct from a circle
- [ ] **Satellite**: drawn with a rectangular body, two solar panel wings extending from sides, and a small antenna element; metallic grey/silver coloring with subtle panel line details
- [ ] **Rocket**: drawn as a burnt rocket stage — cylindrical body with a visible nozzle at one end; scorch marks (darker streaks) on the body; subtle exhaust particle trail behind nozzle end
- [ ] **Cloth**: drawn as a torn fabric/mylar sheet — jagged irregular edges, slight drift/flutter animation (shape wobbles per frame), reflective shimmer effect (alternating light/dark patches)
- [ ] Each debris type has a subtle glow trail (2-4 frame trail of semi-transparent afterimages) visible during movement
- [ ] All 4 types are visually distinguishable from each other at 1280x720 viewport during normal gameplay speed
- [ ] No performance regression — game maintains smooth animation with 5+ debris on screen simultaneously
- [ ] [UX] Each debris type communicates "dangerous/avoid" through visual weight — they should look meaningfully hazardous, not decorative
- [ ] [UX] Debris details are readable without squinting at primary viewport (1280x720) — not too small, not cluttered

## Dependencies
- None

## Notes
All drawing is canvas-based (no external image assets). Reference: CR-013 specifies "clearly recognizable as space debris" — current grey blobs fail this bar.
