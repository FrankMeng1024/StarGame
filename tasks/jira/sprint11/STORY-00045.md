# STORY-00045: 全局视觉升级 — 光标星尾 + HUD动画计时 + 商店徽章辉光

**Epic**: E-005 主界面与关卡选择UI
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want a star trail following my cursor, an animated countdown ring on the game timer, and glowing item type badges in the shop, so that every micro-interaction feels magical and the UI has life even when I'm not actively playing.

## Expected Result
Cursor leaves a fading star particle trail on all non-gameplay screens. The in-game HUD timer displays as an animated ring that depletes over time. Shop item cards show an animated glow badge for their type (被动/主动).

## Acceptance Criteria

### Cursor Star Trail
- [ ] On all UI screens (menu, level select, gallery, shop, completion — NOT during active gameplay canvas), the cursor leaves a trail of small star particles
- [ ] Trail particles are small (3-6px), gold/white colored, and fade out over ~0.5s
- [ ] Trail follows mouse movement with a slight delay/spread (particles spawn at cursor position with slight random offset)
- [ ] Trail uses CSS animations or a lightweight JS particle system — not a canvas overlay that interferes with click events
- [ ] Trail is disabled during active gameplay to avoid visual distraction and performance impact on the game canvas
- [ ] [UX] Trail feels magical and light, not cluttered — particle density is moderate (every ~30-50ms), not every frame

### Animated HUD Timer Ring
- [ ] In-game HUD timer is displayed as a circular ring (SVG or canvas arc) that visually depletes as time counts down
- [ ] Ring starts full (360 degrees) and smoothly animates to empty (0 degrees) over the level duration
- [ ] Ring color transitions as time runs low: normal color (blue/purple) → warning color (orange at <30%) → critical color (red at <15%) with a pulse animation at critical
- [ ] Numeric time remaining is displayed in the center of the ring
- [ ] Ring has a semi-transparent pill-shaped background badge (per CR-019: "semi-transparent pill badges")
- [ ] Ring animation is smooth — no visible stepping or jumps between seconds
- [ ] [UX] Timer ring provides clear at-a-glance time awareness — a player should know "plenty of time" vs "hurry" from the ring color/fill without reading the number

### Shop Badge Glow
- [ ] Shop item cards display a type badge: "被动" or "主动" label
- [ ] Badge has an animated glow effect — a soft pulsing glow around the badge border (CSS animation, ~2s cycle)
- [ ] "被动" badges use a calm blue/purple glow color
- [ ] "主动" badges use an energetic gold/orange glow color
- [ ] Glow animation is subtle — enhances the badge visibility without being distracting
- [ ] [UX] Badge glow draws the eye to the item classification, helping players quickly distinguish passive vs active items while browsing the shop

### General
- [ ] All visual upgrades work at all three viewports (1280x720, 1440x900, 1920x1080)
- [ ] No measurable performance regression — star trail, timer ring, and badge glow combined do not drop frame rate below 60fps during gameplay
- [ ] [UX] All three effects feel like they belong to the same visual language — consistent glow style, particle style, and color palette from the night-sky theme

## Dependencies
