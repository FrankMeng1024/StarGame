# STORY-00042: 画廊图片水平滚动轮播

**Epic**: E-006 星座展厅
**Sprint**: Sprint 11
**Sprint Goal**: 全方位视觉品质飞跃
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player browsing the constellation gallery, I want to see multiple real astrophotography images for each constellation in a horizontal scroll carousel, so that the gallery feels like a real astronomy experience rather than a static placeholder.

## Expected Result
Gallery detail page replaces the single static SVG star chart section with a horizontal CSS scroll carousel of real CC0/public domain astrophotography images. Each image card shows the photo plus a credit attribution line.

## Acceptance Criteria
- [ ] Gallery detail page for each constellation shows a horizontal scrollable carousel of astrophotography images
- [ ] At least 2 scrollable image cards per constellation, each with a real astrophoto (not placeholder/SVG)
- [ ] Images are sourced from CC0/public domain sources (Unsplash, Pexels, NASA, ESO, etc.) — no copyrighted images
- [ ] Each image card displays a credit attribution line below or overlaid on the image (e.g. "Photo: NASA/ESA" or "Unsplash: @photographer")
- [ ] Carousel uses CSS scroll snap: `display:flex; overflow-x:auto; scroll-snap-type:x mandatory` on the container; `scroll-snap-align:center` on each card
- [ ] Horizontal scrollbar is styled to match the game theme (thin, semi-transparent, night-sky palette) — not the browser default
- [ ] Carousel is swipeable/draggable with mouse (standard overflow-x scroll behavior)
- [ ] Images load without layout shift — container has a defined aspect ratio or min-height before images load
- [ ] [UX] Navigation into and out of the carousel is smooth — scrolling the carousel does not accidentally scroll the page vertically
- [ ] [UX] Credit text is legible but unobtrusive — does not dominate the image

## Dependencies
- None

## Notes
Actual image sourcing happens during implementation. Developer must web-search for CC0 constellation/astrophotography images and self-evaluate composition quality before using. Minimum 2 images per constellation; more is better. If a constellation has no good CC0 photos available, general astrophotography of the relevant sky region is acceptable. Images should be downloaded and bundled locally (not hotlinked) per TECH_SPEC.md asset strategy.
