# STORY-00001: 主菜单与项目骨架

**Epic**: E-005 主界面与关卡选择UI
**Sprint**: Sprint 1
**Sprint Goal**: 建立可玩的游戏核心
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to open the game and see a beautiful main menu, so that I understand what the game is about and can choose to play or view the gallery.

## Expected Result
访问 http://localhost:8080，看到夜空背景的主菜单，包含游戏标题"星捕少女"、[挑战关卡]和[星座展厅]两个按钮，按钮可以点击切换界面。

## Acceptance Criteria
- [ ] index.html 存在，访问 http://localhost:8080 返回 HTTP 200
- [ ] 页面显示中文标题"星捕少女"（字体为马善政或系统中文字体）
- [ ] 页面背景为深蓝/深紫夜空色调，有粒子星空动画（至少50个闪烁星点）
- [ ] [挑战关卡] 按钮可见，点击后切换到关卡选择界面
- [ ] [星座展厅] 按钮可见，点击后切换到展厅界面（此Sprint可为占位页）
- [ ] 鼠标光标为自定义星星形状
- [ ] 无 JS 控制台错误
- [ ] 1280×720 分辨率下无横向滚动条
- [ ] UX: 首次用户无需任何说明，5秒内理解这是星座相关游戏（视觉传达）
