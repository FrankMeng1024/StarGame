# STORY-00004: 关卡完成体验与星座介绍

**Epic**: E-007 关卡完成体验
**Sprint**: Sprint 1
**Sprint Goal**: 建立可玩的游戏核心
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a satisfying level complete screen with constellation introduction, so that I feel rewarded and learn something about the constellation I just caught.

## Expected Result
抓完7颗猎户座星星后，显示通关界面：粒子庆祝效果，星座连线动画，分数统计，猎户座简介文字，[下一关]按钮。

## Acceptance Criteria
- [ ] 抓完所有星星后，全屏显示关卡完成界面（Canvas变暗，覆盖HTML层）
- [ ] 金色星光粒子雨效果持续2秒
- [ ] 天空区域出现猎户座连线动画：7颗星依次被金线连接，连线完成后整体发光
- [ ] 结算卡显示：已抓星星数（X/7）、剩余时间（X秒）、获得金币（X枚）
- [ ] 金币计算公式正确：剩余秒数 × 10
- [ ] 显示猎户座简介（至少100字的中文介绍，包含神话故事或天文信息）
- [ ] [下一关]按钮可用，点击后解锁第2关并进入第2关游戏界面（此Sprint可为占位）
- [ ] [返回选关]按钮可用，点击后回到关卡选择，第1关显示通关状态
- [ ] 通关状态和金币计入localStorage（页面刷新后保持）
- [ ] UX: 通关画面视觉上令人愉悦，不显突兀

## Dependencies
- Depends on: STORY-00003

## Notes
连线动画是关键体验亮点，需要足够流畅（每条线0.3秒绘制，0.1秒间隔）
