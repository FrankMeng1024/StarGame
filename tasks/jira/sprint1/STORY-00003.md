# STORY-00003: 核心游戏引擎与网兜机制

**Epic**: E-001 核心游戏引擎
**Sprint**: Sprint 1
**Sprint Goal**: 建立可玩的游戏核心
**Points**: 8
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a swinging net and click to catch stars, so that the core game mechanic works and feels satisfying.

## Expected Result
进入第1关（猎户座），Canvas显示夜空背景 + 7颗猎户座星星 + 若干宇宙垃圾 + 小女孩角色 + 摆动的网兜。点击鼠标，网兜沿当前角度向上伸长，碰到第一个物体抓取并收回。抓完7颗星后触发通关流程。

## Acceptance Criteria
- [ ] Canvas 元素占满游戏区域（1280×720），背景显示场景图片或深蓝色占位
- [ ] 小女孩角色（简单图形即可）显示在屏幕底部中央
- [ ] 网兜从角色顶部自动摆动（±60°，速度约1.5秒/次完整摆动）
- [ ] 点击鼠标/空格键：网兜沿当前摆动角度向上伸长
- [ ] 伸长时碰到第一个物体：抓取该物体，开始收回（不能穿越物体继续伸长）
- [ ] 未碰到任何物体：伸到最长距离（约屏幕2/3高度）后自动收回
- [ ] 收回完成后继续摆动，可再次点击
- [ ] 猎户座7颗星按真实相对位置分布（参考DISCOVERY.md中的星座坐标，可按比例缩放）
- [ ] 星星大小按星等映射：magnitude 1→30px, 2→24px, 3→18px, 4→14px（或合理比例）
- [ ] 至少3个宇宙垃圾（陨石形状）随机分布在天空中
- [ ] 抓到星星：金色粒子效果，星星消失，HUD星星计数+1
- [ ] 抓到垃圾：灰色碎片效果，垃圾消失，不计星星
- [ ] HUD显示：关卡名"猎户座 · 第1关"，倒计时90秒，已抓/总数(0/7)
- [ ] 倒计时实时减少（1秒精度）
- [ ] 抓完7颗星 → 触发通关（此Sprint可弹出简单alert或跳转到占位通关页）
- [ ] 时间归零 → 触发失败（此Sprint可显示"关卡失败"并允许重试）
- [ ] 60fps游戏循环（Chrome DevTools performance面板可验证）
- [ ] 无JS控制台错误
