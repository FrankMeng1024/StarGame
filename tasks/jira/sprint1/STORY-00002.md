# STORY-00002: 关卡选择界面

**Epic**: E-002 关卡系统
**Sprint**: Sprint 1
**Sprint Goal**: 建立可玩的游戏核心
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see all 30 constellation levels in a grid, so that I can choose which level to play and see my progress.

## Expected Result
点击主菜单[挑战关卡]后，看到30个关卡卡片的网格。第1关（猎户座）解锁，其余29关锁定。点击解锁关卡进入游戏。

## Acceptance Criteria
- [ ] 显示30个关卡卡片，排列为6列×5行网格
- [ ] 每张卡片显示：星座中文名 + 英文名 + 难度（1-5星用星形图标表示）
- [ ] 第1关（猎户座）卡片为彩色可点击状态
- [ ] 第2-30关卡片为灰色锁定状态，悬停时显示"完成上一关解锁"提示
- [ ] 点击第1关卡片后跳转到游戏界面
- [ ] 点击锁定卡片无响应（不跳转）
- [ ] 页面顶部有[返回主菜单]按钮，可用
- [ ] 背景与主菜单一致（夜空风格）
- [ ] 30个星座名称与 DISCOVERY.md 定义完全一致
- [ ] UX: 解锁vs锁定状态视觉差异明显，一眼可辨

## Dependencies
- Depends on: STORY-00001
- Blocks: STORY-00003

## Notes
星座数据来自 js/data/constellations.js，此Sprint只需名称和难度，不需完整星图数据
