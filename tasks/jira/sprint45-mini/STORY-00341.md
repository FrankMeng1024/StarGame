# STORY-00341: 主菜单布局均衡化 — 消除拥挤/空白区域

**Epic**: Visual Polish
**Sprint**: Sprint 45-mini
**Sprint Goal**: 主菜单布局均衡化 — 消除拥挤/空白区域，title+buttons整体垂直居中
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the main menu to have balanced spacing — title, buttons, and info panel distributed evenly so nothing looks crowded or orphaned.

## Expected Result
Landscape: title block + 3 buttons vertically centered in the right column usable area. Equal breathing room above title, between title and buttons, and below buttons. No 100px+ dead zones.
Portrait: title + buttons fit within the area below the constellation (H*0.60 → bottom), no overflow, buttons proportionally wider.

## Acceptance Criteria
- [ ] **Landscape**: title block and button group are vertically centered in usable right-column height (usable = H minus safe areas minus info panel)
- [ ] **Landscape**: no dead zone > 40px between title block and buttons
- [ ] **Landscape**: no dead zone > 40px between buttons and info panel
- [ ] **Landscape**: button height responsive (not fixed), approximately usableH * 11%
- [ ] **Portrait**: buttons do NOT overflow below the screen (btn3End ≤ H - safeBottom)
- [ ] **Portrait**: title and buttons vertically centered in UI area (H*0.60 → H - safeBottom)
- [ ] **Portrait**: button width expanded to W*0.72 (was W*0.60) for better mobile proportion
- [ ] Screenshot shows visually balanced layout — no obvious crowding or emptiness

## Dependencies
None — isolated to menu.js `_loop()` layout sections

## Notes
Landscape: usableH = H - (SAFE_TOP||0) - (SAFE_BOTTOM||0) - 52 (info panel + gap)
Portrait: uiH = (H - safeB - 8) - H*0.60
Both: contentTop = areaTop + (areaH - totalContentH) / 2
totalContentH = titleBlockH + TITLE_BTN_GAP + btnGroupH
Do NOT modify _drawConBg, _drawConInfoPanel, or any other function — only the layout coordinate calculations inside _loop().
