# STORY-00369: 图鉴真实天文图片

**Epic**: Visual Polish
**Sprint**: Sprint 60-mini
**Sprint Goal**: 图鉴详情页全屏升级 + 真实天文图片
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see real astronomical photos for each constellation in the gallery detail page, so the game feels educational and visually stunning.

## Expected Result
constellations.js中所有30个星座的photos[]数组都有至少一条可用的真实天文图片URL（来自NASA APOD、ESA或Wikimedia Commons）。

## Acceptance Criteria
- [ ] 至少20个星座有可用图片URL（允许部分小星座无公开照片）
- [ ] 所有URL来自公开可访问的域名（wikimedia.org / nasa.gov / esahubble.org等）
- [ ] wx.createImage()能成功加载图片（非全黑，非空）
- [ ] 失败时显示"🌌 暂无图片"占位（非crash）
- [ ] 截图：至少2张不同星座的详情页展示真实图片

## Dependencies
STORY-00368（需要详情页先完成才能验证图片显示）

## Notes
- 用WebSearch搜索各星座英文名 + "wikipedia commons" 或 "NASA APOD"
- 优先选择 320px 缩略图（wikimedia thumb格式），避免大图超时
- constellations.js photos数组，每项为URL字符串
