# STORY-00368: 图鉴详情页全屏重构

**Epic**: Visual Polish
**Sprint**: Sprint 60-mini
**Sprint Goal**: 图鉴详情页全屏升级 + 真实天文图片
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to view constellation details in a full-screen immersive layout, so the experience feels premium and the star chart and photo are both visible and large.

## Expected Result
图鉴详情页从底部抽屉改为全屏淡入，左右分栏布局：左40%星图+名称，右60%天文图片+描述+神话。

## Acceptance Criteria
- [ ] 点击图鉴列表项后，全屏详情页淡入（alpha 0→1，约300ms）
- [ ] 左侧40%区域：星图（r=100px），中文名/英文名，星座符号
- [ ] 右侧60%区域：天文图片（高160px），描述文字，神话故事（可滚动）
- [ ] 顶部Header：drawHeaderBar，左侧"← 返回图鉴"按钮
- [ ] 右侧内容区支持触摸拖动滚动
- [ ] 图片加载中显示旋转星形占位符
- [ ] 图片加载失败显示"暂无图片"文字（非emoji主视觉）
- [ ] 截图：详情页截图一张

## Dependencies
无（gallery.js已有_drawDrawer()实现，本Story替换之）

## Notes
- 替换_drawer状态机为_detail状态机
- 新状态：`_detail = { idx, phase, alpha, scrollY, scrollTarget }`
- phase: 'in'(淡入中), 'show'(显示中), 'out'(淡出中)
- 横屏 844×390，左边界约 44px 内边距
