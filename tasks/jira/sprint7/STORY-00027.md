# STORY-00027: Scene transition ceremony

**Epic**: E-002 (关卡系统)
**Sprint**: Sprint 7
**Sprint Goal**: 展厅完整度 + 场景体验打磨
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player starting level 6 (or 11, 16, 21, 26) for the first time, I want a brief visual acknowledgment that I have entered a new location — so the scene progression feels intentional and the world-building registers, not just passes by unnoticed.

## Expected Result
When the game engine starts a level whose scene index differs from the previously played level's scene index, a 2-3 second overlay appears on the game canvas at game start: the NZ location name (e.g. "库克山 · 山顶雪景") fades in and out. This only fires on first entry to a new scene group — not on retry or replay.

## Acceptance Criteria
- [ ] Starting level 6 (first level of Scene 1) shows a brief scene-name overlay at game start
- [ ] Starting level 11, 16, 21, 26 also shows the overlay (each new scene boundary)
- [ ] The overlay shows the NZ location name from `SCENE_PALETTES[sceneIdx].name`
- [ ] Overlay fades in over 0.5s, holds for 1.5s, fades out over 0.5s (total ~2.5s)
- [ ] Game timer does NOT count down during the overlay — timer starts after fade-out completes
- [ ] Retrying a failed level does NOT show the overlay again (scene already seen)
- [ ] Replaying an already-completed level does NOT show the overlay again
- [ ] The overlay is purely Canvas-rendered (no DOM overlay element needed)
- [ ] Zero console errors

## Dependencies
- Depends on: STORY-00022 (SCENE_PALETTES with `.name` field)

## Notes
Track seen scenes in `state.js` as a Set `seenScenes` (persisted to localStorage). On engine start: `if (!state.seenScenes.has(sceneIdx)) { show overlay; state.seenScenes.add(sceneIdx); }`. Timer freeze: pause `this.timeLeft` decrement during overlay phase.
