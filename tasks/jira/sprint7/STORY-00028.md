# STORY-00028: Level select scene group dividers

**Epic**: E-005 (主界面与关卡选择UI)
**Sprint**: Sprint 7
**Sprint Goal**: 展厅完整度 + 场景体验打磨
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player browsing the level select screen, I want to see visual groupings that show which levels share a sky scene — so the 30-level grid feels like a structured journey through 6 New Zealand locations, not a flat undifferentiated list.

## Expected Result
The level-select grid has 6 labeled section dividers, one before each group of 5 levels. Each divider shows: the NZ location name (from `SCENE_PALETTES[sceneIdx].name`) and a small color swatch matching the scene's sky color. The divider spans the full grid width and has a subtle separator line.

## Acceptance Criteria
- [ ] Level grid is visually divided into 6 labeled groups: levels 1-5, 6-10, 11-15, 16-20, 21-25, 26-30
- [ ] Each group header shows the NZ location name (e.g. "特卡波湖 · 牧羊人小屋")
- [ ] Each group header has a color indicator (dot or strip) using `scene.sky1` as the accent color
- [ ] Scene 4 group header visually hints at aurora (teal accent, optionally small "极光" badge)
- [ ] Dividers are non-interactive (no click behavior)
- [ ] Dividers render correctly on fresh state (only level 1 unlocked) and on any partially unlocked state
- [ ] Layout remains correct at 1280×720 and 1440×900 viewports
- [ ] Zero console errors

## Dependencies
- Depends on: STORY-00022 (SCENE_PALETTES with `.name` and `.sky1` fields)

## Notes
Inject dividers into the level grid during `initLevels()` and `refreshLevels()`. Dividers are `div.scene-divider` elements with `grid-column: 1 / -1` so they span full width. Insert before index 0, 5, 10, 15, 20, 25 in the CONSTELLATIONS array.
