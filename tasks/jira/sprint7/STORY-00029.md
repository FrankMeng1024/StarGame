# STORY-00029: Polish — star map overlay contrast + passive item HUD indicator

**Epic**: E-003 (道具系统)
**Sprint**: Sprint 7
**Sprint Goal**: 展厅完整度 + 场景体验打磨
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
Bundle two UX Low polish items that share a theme of "I can't tell what's active":
1. Star map overlay (gold constellation lines) loses contrast on Scene 4 aurora (bright teal background). Switch overlay line color to white with slight glow on aurora scenes, keep gold on dark scenes.
2. After the passive item toast fades (~3.5s), there is no persistent HUD indicator of which passive items are active this level. Add a small persistent row showing active passive item icons below the main HUD.

## Expected Result
1. In Scene 4 (aurora), star_map overlay lines render in white/light-blue instead of gold — legible against teal backdrop.
2. When passive items are active, small icons (emoji or text) appear in a persistent strip in the HUD for the full level duration.

## Acceptance Criteria
- [ ] Star map overlay on Scene 4 (aurora): lines are visibly legible — not lost against the teal aurora background
- [ ] Star map overlay on Scene 0 (dark navy): lines remain gold (no change from current behavior)
- [ ] Passive item HUD: when at least one passive item is active, a compact icon row appears below the main HUD stats row
- [ ] Passive item HUD shows icons for each active passive item (net_speed ⚡, star_magnet 🧲, shrink_debris 🔬, double_coins 🪙, star_map 🗺️, astro_gloves 🧤)
- [ ] Passive item HUD is visible for the full level duration (not just during the toast)
- [ ] Passive item HUD does not appear when no passive items are active (empty state hidden)
- [ ] Zero console errors

## Dependencies
- None

## Notes
For star map color: pass `sceneIdx` to the star map drawing function; if `scene.aurora === true`, use `rgba(220,240,255,0.7)` for line color instead of `rgba(255,215,0,0.8)`.
For persistent HUD: `engine.js` already builds `this.activeItems` Set in the constructor. Read it to render a `<div id="hud-active-items">` that stays visible. This element already exists in the HTML as `#hud-active-items` — just populate it at game start.
