# STORY-00026: Gallery detail — canvas star portrait

**Epic**: E-006 (星座展厅)
**Sprint**: Sprint 7
**Sprint Goal**: 展厅完整度 + 场景体验打磨
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player who has unlocked a constellation, I want the gallery detail page to show a beautiful rendered star map of that constellation — not just a text description — so visiting the gallery feels like a reward and builds my mental picture of the constellation I caught.

## Expected Result
The gallery detail page (`#screen-gallery-detail`) replaces its empty detail-hero area with a 300×300 canvas rendering of the constellation: dark sky background, star dots sized by magnitude, colored by type, connected by golden lines, with the constellation name centered below. Uses the existing `CONSTELLATIONS[idx].stars` and `CONSTELLATIONS[idx].lines` data.

## Acceptance Criteria
- [ ] Gallery detail page shows a canvas element (300×300 or similar) rendering the constellation star map
- [ ] Stars are drawn at normalized positions with size proportional to magnitude (same mapping as `complete.js`)
- [ ] Stars are colored by spectral type (same color mapping as `complete.js`)
- [ ] Constellation lines are drawn in gold/golden connecting the correct star pairs
- [ ] Canvas background matches the scene palette of the level that constellation belongs to (Scene 0 for levels 1-5, etc.)
- [ ] Clicking a locked constellation in gallery does NOT show a portrait (locked cards remain non-clickable)
- [ ] Clicking an unlocked constellation shows the detail page with the canvas portrait
- [ ] The portrait renders within 200ms of page load (no async lag)
- [ ] Zero console errors

## Dependencies
- Depends on: STORY-00022 (SCENE_PALETTES — needed for background color)

## Notes
Reuse `magToRadius` and `typeToColor` already exported from `js/data/constellations.js`. The canvas portrait is static (no animation needed) — draw once on screen show.
