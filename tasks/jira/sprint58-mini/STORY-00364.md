# STORY-00364: 游戏内小女孩角色视觉优化

**Epic**: Visual Polish
**Sprint**: Sprint 58-mini
**Sprint Goal**: 游戏角色美观 + 星星居中不偏移
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the girl character to look beautiful and well-proportioned, so the game feels premium and thematically consistent with the deep-space aesthetic.

## Expected Result
游戏内小女孩角色比例美观、宇航服配色契合深空主题、站姿自然。

## Acceptance Criteria
- [ ] 头身比1:2.5（头部圆半径约占角色总高度的29%），五官有细节（眼睛、嘴巴、刘海）
- [ ] 宇航服主色为深紫蓝（#3a1f6b）+金色高光（#ffd700），与深空主题一致
- [ ] 站姿自然，脚踩平台，挥网时有手臂延伸动感
- [ ] 角色高度120-130px（在375px高的横屏下清晰可辨）
- [ ] 截图：游戏内运行截图，角色清晰可见

## Dependencies
无（game.js已有角色绘制函数）

## Notes
需重绘game.js中的 _drawGirl() 或相关角色绘制代码，保持canvas路径绘制方式（不引入外部图片资源）。
