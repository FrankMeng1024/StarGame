# STORY-00365: 游戏内星星居中 — 散布区域修正

**Epic**: Visual Polish
**Sprint**: Sprint 58-mini
**Sprint Goal**: 游戏角色美观 + 星星居中不偏移
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the stars to be distributed evenly across the visible game area, so they don't cluster to one side or hide behind UI elements.

## Expected Result
星星均匀散布于可视区域中央，不与HUD或小女孩区域重叠，X/Y范围明确。

## Acceptance Criteria
- [ ] 星星X散布范围为 [W*0.05, W*0.90]，Y散布范围为 [H*0.08, H*0.65]
- [ ] 不与左上角HUD（计时器/星数计数器）重叠
- [ ] 不与底部小女孩区域（底部18% = Y > H*0.82）重叠
- [ ] 初始生成时均匀分布，避免全部堆在左侧或右侧
- [ ] 截图：游戏内运行截图，可见星星分布于屏幕中央区域

## Dependencies
无（game.js已有星星生成逻辑）

## Notes
需修改game.js中星星生成的坐标范围，找到 _spawnStar() 或 _initStars() 相关函数。
