# STORY-00271: 扫码黑屏修复 — Canvas尺寸保障

**Epic**: E-005 核心游戏体验
**Sprint**: Sprint 21-mini
**Sprint Goal**: 修复真机3个Blocker：按钮无法点击+黑屏扫码+首页按钮视觉优化
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the game to show the home screen immediately when I scan the QR code, so that I don't see a black screen on launch.

## Expected Result
QR code launch on any iPhone/Android shows the game home screen within 2 seconds, never a black screen.

## Acceptance Criteria
- [ ] game.js waits for canvas to have non-zero width before starting render loop
- [ ] If canvas.width = 0 on first tick, game.js retries up to 10 times (100ms intervals) before giving up
- [ ] screenW is always ≥ windowWidth (never 0) when passed to initGlobals
- [ ] The intro animation renders correctly on first launch (no blank first frame)
- [ ] No black screen reported in DevTools console errors on simulated low-end device

## Root Cause (hypothesis)
WeChat QR scan launch: `wx.createCanvas()` or `onLaunch` fires before the canvas element is fully initialized. `canvas.width` may be 0 at the moment `game.js` reads it. The fallback `|| sysInfo.windowWidth` may not be applied in the right place or the canvas itself may have 0×0 actual render area.

## Dependencies
- Blocked by: STORY-00269 (stable base before adding timing logic)

## Notes
Check game.js lines 21-27 where canvas.width is read. Consider adding:
```js
function waitForCanvas(cb, retries=10) {
  if (canvas.width > 0) { cb(); return; }
  if (retries <= 0) { cb(); return; } // give up, use sysInfo fallback
  setTimeout(() => waitForCanvas(cb, retries - 1), 100);
}
```
Also verify canvas.height fallback covers windowHeight.
