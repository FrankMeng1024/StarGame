## Description
As a player, I want the home screen buttons to look polished and attractive, so that the game feels professional and inviting.

Home screen buttons have rich gradients, clear labels, visible depth/shadow, and a premium feel consistent with the star-catching theme.

## Acceptance Criteria
- [ ] START/LEVELS/GALLERY/SHOP buttons use vibrant gradient fills (not flat colors)
- [ ] Buttons have visible border or glow effect matching purple/star theme
- [ ] Button text is large, clear, and high-contrast against button background
- [ ] Buttons have a rounded-rect shape with smooth corners (radius ≥ 10)
- [ ] Visual hierarchy is clear: START is the primary CTA, others are secondary
- [ ] No button appears as a plain grey/default rectangle
