## Description
As a player, I want the victory result screen to feel celebratory and premium, so that completing a constellation feels like a real achievement.

## Expected Result
Victory card has a gold border with animated shimmer (流光), and subtle constellation line decoration as card background detail.

## Acceptance Criteria
- [ ] Victory card border: gold `#ffd700` strokeRect at card edges, lineWidth 2, subtle glow `shadowColor: '#ffcc00', shadowBlur: 8`
- [ ] Shimmer effect: a thin light bar (`rgba(255,255,255,0.3)`, width ~20px) sweeps across the card from left to right once, on victory phase start. Duration ~0.8s (48 frames at 60fps).
- [ ] Shimmer state: `_shimmerX` starts at `cardX`, advances `+cardW/48` per frame until `_shimmerX >= cardX + cardW`, then stops
- [ ] Constellation line decoration: faint version of the current constellation's star lines drawn as card background (alpha 0.08-0.12), scaled to fit inside card area
- [ ] "星座揭秘！" title: text color `#ffd700` (gold), `shadowColor: '#ffaa00'`, `shadowBlur: 12`
- [ ] UX AC: First-time player seeing victory card immediately reads "this is special / premium" without explanation

## Dependencies
- None

## Notes
Current victory card uses plain white title text. The shimmer requires a new state variable `let _shimmerX = null;` reset to `cardX` when victory phase renders frame 0.
