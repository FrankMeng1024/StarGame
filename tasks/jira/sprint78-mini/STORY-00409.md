## Description

## Expected Result
When combo x3+ fires, "+5s" popup appears near the timer ring (center-top area) rather than in the top-left corner.

- [ ] "+5s" popup X position changed from `W * 0.08` to `W * 0.5` (or near the timer ring at `W/2`)

- [ ] Visual: same green #44ff88 color, same 1.5s fade, same upward float
- [ ] The combo popup ("x3 连击!!") at H*0.25 remains unchanged
- [ ] UX AC: Player can visually trace the line from combo popup (center) to "+5s" indicator (also near center-top) in a single glance

- None (1-line coordinate change)
