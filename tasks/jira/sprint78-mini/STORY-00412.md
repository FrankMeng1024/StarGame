# STORY-00412: 关卡选关页完成度可视化 — 进度环+解锁提示

**Epic**: E-003 关卡选择
**Sprint**: Sprint 78-mini
**Sprint Goal**: 结算页深空主题完成 + 游戏性探究
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see my overall progress in the level select screen at a glance, so that I feel motivated to continue and know how far I've come.

## Expected Result
Level select screen shows a compact progress indicator (e.g. "已解锁 X/30 星座") and each completed constellation node has a subtle "complete" glow effect to make progress tangible.

## Acceptance Criteria
- [ ] Progress text: `"进度: X/30 星座"` drawn at top of level select screen (e.g. H*0.05, right-aligned), font 11px, color rgba(255,220,100,0.8)
- [ ] X = count of constellations where player has at least 1 level completed (check `state.getScore(conIdx, 0)?.stars > 0`)
- [ ] Completed constellation nodes: add a gold outer glow ring (radius +6, rgba(255,215,0,0.25), lineWidth 3) when all 3 levels of the constellation are 3-star completed
- [ ] Non-intrusive: glow only for fully-completed (all 3 levels 3-star), not just started
- [ ] UX AC: Player can scan the screen and immediately identify which constellations are fully mastered vs partially done vs untouched

## Dependencies
- None

## Notes
The levels.js screen already draws constellation nodes. Add glow in the node draw loop after existing gold ring (which fires on single-level completion).
Progress count: `state.getScore(conIdx, lvlIdx)` where conIdx 0-29, lvlIdx 0-2. A constellation is "started" if any level has stars>0. Use this for the X/30 count.
"Fully mastered" = all 3 levels have stars >= 1 (or stars === 3 for strictest criteria — use stars >= 1 for accessibility).
