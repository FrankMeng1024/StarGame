# STORY-00413: 游戏内连击链断裂视觉反馈 — 障碍物碰撞闪红

**Epic**: E-009 游戏性核心
**Sprint**: Sprint 78-mini
**Sprint Goal**: 结算页深空主题完成 + 游戏性探究
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want to see a clear visual signal when I break my combo by hitting debris, so that I understand my mistake instantly and learn to avoid it.

## Expected Result
When a debris collision resets the combo, the screen flashes red briefly (similar to the existing 75% milestone shake, but distinct — red flash not shake) for 0.2s.

## Acceptance Criteria
- [ ] New state variable `_comboBreakFlash = 0` (frame countdown, initialized to 0)
- [ ] When debris collision resets combo (i.e. `_comboCount >= 2` before reset, meaning a real combo was broken): set `_comboBreakFlash = 12` (0.2s at 60fps)
- [ ] Each frame: if `_comboBreakFlash > 0`, draw a full-screen red overlay `rgba(200, 30, 30, alpha)` where `alpha = (_comboBreakFlash / 12) * 0.18` (max alpha 0.18 — subtle)
- [ ] Overlay drawn over game world but under HUD and popups
- [ ] `_comboBreakFlash` decrements by 1 each frame until 0
- [ ] Reset `_comboBreakFlash = 0` in `_resetGameState`
- [ ] Only fires when an actual combo (≥2) was broken — does NOT fire on first debris hit with no combo active
- [ ] UX AC: Player who loses a x3 streak to debris sees a brief "ouch" flash that reinforces the punishment signal without being annoying

## Dependencies
- None

## Notes
The combo reset currently happens in `_checkCollisions` when debris hits. The condition is: debris hit AND `_comboCount >= 2`.
The overlay draw: place in the render function between world draw and HUD draw.
This flash is distinct from the 75% shake (_shakeFrames) — no screen offset, just color overlay.
