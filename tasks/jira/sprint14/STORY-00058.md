# STORY-00058: 真实图片资源替换 — 角色、垃圾、网兜、天文摄影

**Epic**: E-003 / E-006
**Sprint**: Sprint 14
**Sprint Goal**: 游戏体验全面提升
**Points**: 8
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want all game visuals to use real, high-quality images instead of programmer art, so the game looks and feels polished and professional.

## Expected Result
- 少女角色 replaced with a real anime-style sprite (found via WebSearch on itch.io/OpenGameArt/similar CC0 sources), or significantly improved procedural drawing if no suitable sprite found
- 4 debris types replaced with found images (CC0 space debris / asteroid sprites)
- Net shape replaced with a clearly recognizable catching net image or clean canvas drawing
- Photo carousel URLs updated to actually-working, accessible URLs (tested before embedding) sourced via WebSearch

## Acceptance Criteria
- [ ] 少女角色在游戏内视觉上明显像动漫少女，而不是几何形状 (idle state visible in game screenshot)
- [ ] 至少2种垃圾类型使用找到的真实图片或明显改善的贴图
- [ ] 网兜在视觉上明显是网兜形状（不是直线也不是模糊图形）
- [ ] 展馆天文摄影区域至少5张图片可以实际显示（不是✦占位符）for at least 3 constellations
- [ ] 所有新图片资源无版权问题（CC0 / public domain / open license，来源记录在代码注释中）
- [ ] 图片加载失败时仍有优雅降级（✦占位符或默认图）
- [ ] 游戏帧率维持60fps（图片预加载在游戏启动时完成）
- [ ] Zero console errors after image loading

## Dependencies
- Requires WebSearch to find actual working URLs / sprites
- Blocks: none (can be developed in parallel with other stories)

## Notes
CR-032. Use context7 + WebSearch to find CC0 sprites. For photos: test each URL with a HEAD request before embedding. NASA APOD URLs, ESA, or Wikimedia commons direct file links are preferred.
