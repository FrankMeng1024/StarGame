# STORY-00063: 背景音乐丰富化 — 旋律层 + 星空拨弦音效

**Epic**: E-001
**Sprint**: Sprint 14
**Sprint Goal**: 游戏体验全面提升
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the background music to feel alive and ethereal, not like a mechanical 4-chord loop, so the game atmosphere is immersive.

## Expected Result
- A simple pentatonic melody layer plays over the existing chord progression
- A soft twinkling arpeggio layer (random pentatonic notes, very soft) creates starfield ambience
- Subtle rhythm variation (occasional beat drop or slight pause) prevents metronomic feel
- Overall character: ethereal, space-like, alive

## Acceptance Criteria
- [ ] 背景音乐有可辨认的旋律线（单音序列叠加在和弦上），不只是纯和弦
- [ ] 有"星光拨弦"效果（高音区轻柔的随机五声音阶音符，非常轻柔）
- [ ] 音乐循环不完全相同（每隔一段有轻微变化，使人感觉"活"而不是机器节拍）
- [ ] 总体音量平衡：旋律层 < 和弦层，拨弦层 < 旋律层
- [ ] 静音按钮依然有效（mute切断所有音频）
- [ ] Zero console errors, no audio glitches

## Dependencies
- Depends on: none

## Notes
CR-044. All Web Audio API — no external audio files needed. Add melody and twinkle generators to `js/audio.js`. Pentatonic scale in A minor: A C D E G (or A3 C4 D4 E4 G4). Melody: step through the scale in a simple pattern (e.g., E-D-C-A-C-D-E-G) over 2 chord cycles. Twinkle: `setInterval` picking random pentatonic notes with `oscillator.type = 'triangle'`, `gain = 0.015`, very short decay (0.3s).
