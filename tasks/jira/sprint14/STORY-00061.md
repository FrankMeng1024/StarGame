# STORY-00061: 内容逻辑修复 — 失败界面 + 展馆解锁 + 商店入口 + 关卡网格

**Epic**: E-004 / E-005 / E-006
**Sprint**: Sprint 14
**Sprint Goal**: 游戏体验全面提升
**Points**: 4
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want: (1) failing a level to show only retry options, not the constellation story; (2) gallery detail to require actually winning a level, not just unlocking it; (3) the shop to be accessible from the main menu and level select; (4) the level grid to be a clean 6×5 layout with no empty gap.

## Expected Result
- Fail screen: hides lore, photo, and shows only stats + Retry + Back to Levels
- Gallery: a constellation's detail requires `hasCompleted(idx)` (winning), not just `isUnlocked(idx)`
- Shop accessible from main menu (new button) and from level select screen
- Level grid: 6 columns × 5 rows (30 cards), no scene-divider gap

## Acceptance Criteria
- [ ] 关卡失败界面：看不到星座神话故事和图片，只有"重试"和"返回选关"按钮
- [ ] 星座展馆：仅通关（胜利）的关卡对应的星座可点进详情页；仅开启未通关的显示为"未探索"
- [ ] state模块新增hasCompleted(idx)方法，基于localStorage中的最高分记录（>0 = completed）
- [ ] 主菜单有"道具商店"按钮，可直接进入商店
- [ ] 关卡选择界面有商店入口按钮
- [ ] 商店返回按钮根据来源返回（主菜单→返回主菜单，关卡选择→返回选关）
- [ ] 关卡网格为6列×5行，30张卡片整齐填满，无空格
- [ ] 场景分隔线（scene-divider）从网格中移除
- [ ] Zero console errors after all changes
