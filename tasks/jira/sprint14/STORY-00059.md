# STORY-00059: 游戏机制修复 — 垃圾减速拖拽 + 炸弹逻辑 + 道具槽同类多选

**Epic**: E-003
**Sprint**: Sprint 14
**Sprint Goal**: 游戏体验全面提升
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want debris catching to feel strategic (slow retract gives me time to bomb it), and I want to bring multiple copies of the same item type (e.g., 3 bombs), so I have real tactical choices.

## Expected Result
- Catching debris slows retraction to 30% speed instead of instant time penalty
- space_bomb now destroys only the currently held debris (not all screen debris)
- Item selection allows same type ×3 (e.g., 3× space_bomb occupying all 3 slots)
- glove item prevents slow retract (retract at normal speed with glove active)

## Acceptance Criteria
- [ ] 抓到垃圾后网兜明显减速（肉眼可见比正常慢），不扣时间
- [ ] 持有垃圾时按炸弹道具键，垃圾消失，网兜恢复正常速度
- [ ] 未持有垃圾时按炸弹道具键，无效果（或炸最近垃圾作为备选）
- [ ] 装备glove道具后抓到垃圾速度不变（无慢速惩罚）
- [ ] 道具选择界面允许选择3个相同类型道具（如3×宇宙炸弹），分配到槽1/2/3
- [ ] 道具选择界面清晰展示每种道具的持有数量，不超过持有量
- [ ] 道具栏（HUD）正确显示3个炸弹槽，各自可独立触发
