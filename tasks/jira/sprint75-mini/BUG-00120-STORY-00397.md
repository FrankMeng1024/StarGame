# BUG-00120-STORY-00397: _initStars missing closing brace — all functions after line 424 nested inside

**Priority**: Blocker
**Sprint**: Sprint 75-mini
**Opened by**: QA
**Status**: Verified

## Description
STORY-00397 implementation added `_hudStarFlashT = 0;` to `_initStars()` but did not add a closing `}` before `function _initDebris`. This caused every function from line 425 onward to be nested inside `_initStars`, making them inaccessible at module scope.

## Steps to Reproduce
Open game.js and observe that `function _initDebris`, `function _drawGirl`, `function _drawNet`, etc. are all inside `_initStars` with no closing brace.

## Expected
`_initStars` closes with `}` after setting `_hudStarFlashT = 0`.

## Actual
No `}` between `_hudStarFlashT = 0;` and `function _initDebris(W, H) {`.

## Root Cause
Edit to insert `_hudStarFlashT = 0;` into `_initStars` did not include the closing brace from the original end of the function.

## Fix
Added `}` on line 424 to close `_initStars` before `_initDebris`. Committed.
