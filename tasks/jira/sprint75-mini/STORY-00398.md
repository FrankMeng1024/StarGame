# STORY-00398: 网兜发射手感微调 — 摆中心偏移修正 + 锁角视觉提示

**Epic**: 游戏手感
**Sprint**: Sprint 75-mini
**Sprint Goal**: 游戏手感精化 — 左臂自然摆动 + 星星抓取动画反馈 + CR-144障碍物系统验收
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the net to feel responsive and predictable — with a visible cue that tells me where the net is aimed before I launch, so I can time my shot skillfully.

## Expected Result
- 摆动时网兜头部有一条细瞄准线（dim，虚线），从角色手部延伸到网兜最大长度，指示当前摆角方向
- 此瞄准线仅在swing状态显示，extend/retract时不显示
- 摆动中心角保持0（上方），不做偏移

## Acceptance Criteria
- [ ] swing状态：从右手坐标（_skelRHandX/Y）沿当前_netAngle方向画一条虚线，长度=_netMaxLen，颜色rgba(255,215,0,0.12)，lineWidth=1，setLineDash([6,6])
- [ ] extend/retract状态：瞄准线不显示（_netState !== 'swing'时跳过绘制）
- [ ] 瞄准线在网兜本体和星星层之下绘制（drawOrder：background→guide→stars→debris→net→girl）
- [ ] 不影响实际网兜物理（只是视觉辅助）

## Dependencies
- STORY-00396（右手坐标_skelRHandX/Y确保正确导出）

## Notes
当前_skelRHandX/_skelRHandY在_drawGirl最后被设置：
  _skelRHandX = wx2;  // hand position
  _skelRHandY = wy2;

瞄准线绘制函数加在_drawNet()开头（在其他绘制之前）：
  if (_netState === 'swing' && _skelRHandX > 0) {
    ctx.save();
    ctx.strokeStyle = 'rgba(255,215,0,0.12)';
    ctx.lineWidth = 1;
    ctx.setLineDash([6, 6]);
    ctx.beginPath();
    ctx.moveTo(_skelRHandX, _skelRHandY);
    ctx.lineTo(_skelRHandX + Math.sin(_netAngle) * _netMaxLen,
               _skelRHandY - Math.cos(_netAngle) * _netMaxLen);
    ctx.stroke();
    ctx.setLineDash([]);
    ctx.restore();
  }

注意：瞄准线仅供辅助，需测试不喧宾夺主（如果视觉感觉太突出，改rgba alpha 0.08或更低）。
