## Description
As a player, I want to see the girl's left arm swing naturally with the net so that the character feels alive and physically grounded.

## Expected Result
During swing state, the left arm gently sways in the opposite direction of the net swing (counter-pendulum effect, amplitude ~20% of right arm swing). This gives the character natural balance dynamics.

## Acceptance Criteria
- [ ] swing状态下，左臂lUpper角度随_netAngle做轻微反向摇摆：lUpper_swing = 15 + sin(_netAngle) * (-8)，范围约7°~23°
- [ ] 摆幅系数可配置（常量SKEL_LEFT_SWING_FACTOR = 0.3，即右臂摆幅的30%）
- [ ] extend/retract/catch状态下左臂保持原有固定pose，不受_netAngle影响
- [ ] 过渡（swing↔extend）平滑，无跳变（现有_skelBlendT机制覆盖）
- [ ] 代码改动仅在_drawGirl()中的lUpper计算处（约5行），不影响其他逻辑

## Dependencies
- 无

## Notes
当前代码（game.js ~1595行）：
  const POSES_SKEL = { swing: { lUpper: 15, lLower: -10, ... } }
  lUpper = lerp(swingPose.lUpper, pose.lUpper, et);

修改：在swing状态计算后，为lUpper叠加摆动分量：
  if (swingWeight > 0) {
    const netDeg = _netAngle * 180 / Math.PI;
    // Left arm counter-sways (opposite direction, 30% amplitude)
    lUpper += netDeg * (-SKEL_LEFT_SWING_FACTOR) * swingWeight;
  }

注意：POSES_SKEL.swing.lUpper基准值是15，netDeg范围约±80°，
乘以-0.3得到约±24°的摆动叠加，最终lUpper范围约-9°~39°，视觉自然。
