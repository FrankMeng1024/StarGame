# STORY-00397: 抓星反馈升级 — HUD星数弹跳动画 + 星星渐隐消失

**Epic**: 游戏手感
**Sprint**: Sprint 75-mini
**Sprint Goal**: 游戏手感精化 — 左臂自然摆动 + 星星抓取动画反馈 + CR-144障碍物系统验收
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want satisfying visual feedback when I catch a star — the HUD count should bounce and the star should fade out gracefully rather than disappearing instantly.

## Expected Result
- HUD星数（"X/N"显示）在每次+1时有0.2s的scale弹跳（1.0→1.4→1.0）
- 被抓的星星不立刻消失，而是scale 1.0→0快速渐隐（0.25s），同时alpha 1→0
- 现有catch粒子爆发保持不变（这个Story只增加，不改变现有效果）

## Acceptance Criteria
- [ ] 抓到星星的瞬间，HUD中"已抓/总数"文字有弹跳动画（scale >1再回到1），持续200ms
- [ ] HUD弹跳不影响其他HUD元素（timer、coin计数不跳动）
- [ ] 被抓星星：caught标记后开始渐隐动画，alpha从1→0历时250ms，消失过程平滑
- [ ] 若同一帧有多颗星被抓（边界情况），每颗独立渐隐，不互相干扰
- [ ] 渐隐期间星星不可再被网兜再次抓取（已有caught检查覆盖）

## Dependencies
- 无

## Notes
实现要点：
1. HUD弹跳：增加 _caughtFlashT（剩余ms），每帧减少dt*60。drawHUD时：
   const hudScale = 1 + Math.max(0, _caughtFlashT / 200) * 0.4 * Math.sin(_caughtFlashT/200*Math.PI)
   ctx.save(); ctx.translate(starCountX, starCountY); ctx.scale(hudScale, hudScale); ... ctx.restore()
   抓星时：_caughtFlashT = 200;

2. 星星渐隐：在_stars数组中的star对象增加 fadeAlpha: 1.0 和 fadeMs: 0。
   caught时设 s.fadeMs = 250，每帧 s.fadeAlpha = Math.max(0, s.fadeMs / 250)，s.fadeMs -= dt*60。
   _drawStars()中用 ctx.globalAlpha = s.caught ? s.fadeAlpha : alpha_from_twinkle
   当 s.fadeMs <= 0 后 globalAlpha=0（完全隐藏）。
