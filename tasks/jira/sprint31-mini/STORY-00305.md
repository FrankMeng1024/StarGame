# STORY-00305: 展厅详情页全面重设计 — 手机比例 + 图片显示

**Epic**: Mini端真机质量修复
**Sprint**: Sprint 31-mini
**Sprint Goal**: 通关界面体验全面修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the gallery detail page to feel like it was designed for mobile — proper proportions, readable text, and constellation photos that actually load and display.

## Expected Result
展厅详情页：
1. 整体布局像手机APP，不像缩小的桌面网页
2. 星座照片能正常显示（不显示"加载中..."或错误）
3. 内容比例：图标小一点，星图适中，文字可读，图片占据大部分空间

## Acceptance Criteria
- [ ] **照片加载**: 展厅详情页照片区域显示真实照片（不是"加载中..."或空白）
  - 调查：`_loadPhotoAtPos(url, i, detailIdx)` 的url来源是否正确
  - `CONSTELLATIONS[idx].photos` 数组中的URL是否可以从小游戏访问（需wx.createImage）
  - 确认照片URLs格式正确（不是相对路径，而是完整HTTPS URL）
  - Playwright截图：展厅详情页显示至少1张星座天文照片
- [ ] **布局比例（对标HTML展厅）**:
  - 大图标(52px emoji)→减小到36px，节省空间
  - 星图(CHART_SIZE)：占屏幕宽度的60-70%（当前可能偏大）
  - 照片高度：160px已合理，保持
  - 文字行距/字号适合手机阅读（已有13px，确认）
- [ ] **全屏滚动**: 详情内容可以顺滑滚动，不卡顿，不跳出屏幕
- [ ] Playwright截图：展厅详情页显示：星座名+英文名+info pills+星图+照片+文字介绍
- [ ] 与HTML版gallery.js对比：布局结构对齐

## Notes
照片URL调查重点：
- mini分支中`CONSTELLATIONS[idx].photos`数组的内容
- `_loadPhotoAtPos`调用`wx.createImage()`加载，这在小游戏内有效
- 如果URL是CDN的HTTPS链接，应该可以加载；如果是相对路径会失败
- 需要读取`miniprogram/js/data/constellations.js`确认photos字段
