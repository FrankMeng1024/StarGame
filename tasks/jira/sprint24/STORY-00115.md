# STORY-00115: 地理定位星空主页 — 位置获取与星座可见性计算

**Epic**: E-008 沉浸式体验升级
**Sprint**: Sprint 24
**Sprint Goal**: 为追星少女注入"活的星空"灵魂
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家, I want the main menu to detect my geographic location and local time, so that I can see which constellations are actually visible in my sky tonight.

## Expected Result
主菜单加载时请求 Geolocation API。若用户授权，获取纬度/经度；若拒绝或不支持，使用默认坐标（新西兰特卡波：lat=-44.0, lon=170.5）。根据当前本地时间和纬度，计算哪4-6个星座当前在地平线以上（高度角 > 15°）。将结果传递给渲染模块（STORY-00116）。

## Acceptance Criteria
- [ ] 主菜单初始化时调用 `navigator.geolocation.getCurrentPosition()`
- [ ] 权限拒绝或API不存在时静默降级至默认坐标，无错误抛出，无UI提示
- [ ] 使用赤经赤纬（从 constellations.js 中各星座的 `region` 字段或硬编码中心坐标）结合当前 LST（本地恒星时）计算高度角
- [ ] 筛选高度角 > 15° 的星座，取4-6个（按高度角降序，优先显示最高的）
- [ ] 若可见星座少于4个（极端情况），用当前季节最亮星座补齐至4个
- [ ] 将可见星座列表和地理坐标传给渲染函数
- [ ] UX：主菜单出现一行小字 "📍 当前星空 · 北纬XX°"（或"默认：新西兰"）

## Dependencies
- Blocks: STORY-00116

## Notes
天文计算参考：赤经(RA)→时角(HA) = LST - RA；高度角 sin(alt) = sin(dec)·sin(lat) + cos(dec)·cos(lat)·cos(HA)。各星座中心坐标需硬编码在新模块 `js/data/visibility.js` 中（不修改 constellations.js）。
