# STORY-00116: 地理定位星空主页 — 动态星座渲染

**Epic**: E-008 沉浸式体验升级
**Sprint**: Sprint 24
**Sprint Goal**: 为追星少女注入"活的星空"灵魂
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家, I want to see the visible constellations rendered as glowing animated star patterns on the main menu background, so that the menu feels alive and connected to tonight's real sky.

## Expected Result
主菜单背景 canvas（star-canvas 或新增 overlay canvas）上，将STORY-00115传来的4-6个可见星座渲染为柔光动态星图：每个星座显示连线 + 各星点，星点以相位偏移的正弦函数闪烁，整体叠加在现有 starfield 之上（半透明，不遮挡标题按钮）。

## Acceptance Criteria
- [ ] 在 `star-canvas` 上叠加渲染（或新增 `menu-sky-canvas` z-index 介于 star-canvas 和 #app 之间）
- [ ] 每个可见星座绘制：星点（圆点，按 mag 缩放，直径4-10px）+ 连线（rgba金色，opacity 0.3-0.5）
- [ ] 星点闪烁：每颗星的 alpha 按 `0.4 + 0.5 * |sin(t * speed + phase)|` 驱动，speed 和 phase 各不相同（伪随机，基于 star index seed）
- [ ] 星座分散排布在屏幕不同区域（按各星座在天球上的方位角大致映射到屏幕X轴，仰角映射到屏幕Y轴，不与主菜单按钮区重叠）
- [ ] 进入其他屏幕时停止渲染（不消耗RAF）；返回主菜单时恢复
- [ ] 主菜单左下角或右下角显示小字标注最多2个星座名（中文）：如 "今晚可见：猎户座 · 大熊座"
- [ ] 全屏截图：星座轮廓清晰可辨，闪烁动画流畅，不遮挡游戏标题和按钮

## Dependencies
- Depends on: STORY-00115

## Notes
渲染逻辑新建 `js/screens/menu-sky.js`。`initMenuSky(constellations, lat)` 启动动画；`stopMenuSky()` 停止。在 menu.js 的 init 中调用，在 navigate 离开 menu 时调用 stop。星座在屏幕上的布局使用简单线性映射，不需要精确天文投影。
