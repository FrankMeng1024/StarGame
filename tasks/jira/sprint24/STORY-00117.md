# STORY-00117: 全通成就页 + 第30关边界处理

**Epic**: E-008 沉浸式体验升级
**Sprint**: Sprint 24
**Sprint Goal**: 为追星少女注入"活的星空"灵魂
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a 玩家 who has completed all 30 constellations, I want to see a special achievement screen celebrating my full completion, so that there is a meaningful emotional endpoint to the journey.

## Expected Result
完成第30个星座后，关卡完成界面的"下一关"按钮替换为"查看全天星图 →"。点击进入全通成就页：一个圆形天球投影显示所有30个星座轮廓（完成的金色发光，未完成的浅灰），中央显示"100% 追星少女"徽章动画。主菜单新增入口（仅在全通后可见）。

## Acceptance Criteria
- [ ] `state.hasCompleted(29)` 为 true 时（或 unlockedLevels 包含所有30个），关卡完成界面"下一关"按钮文本改为"查看全天星图 →"，点击导航至新屏幕 `screen-achievement`
- [ ] 若未全通，第30关完成后"下一关"按钮显示为不可用（disabled/grey），提示"已是最后一关"——不崩溃，不空指针
- [ ] `screen-achievement` 屏幕包含：全部30个星座小图标+名称（金色=完成，灰色=未完成）排列为6×5网格，与关卡选择网格风格一致
- [ ] 屏幕中央顶部显示完成进度 "30/30 ★" 或"全部解锁"徽章（CSS动画 scale 0→1.1→1，duration 600ms）
- [ ] 底部按钮：[返回主菜单]
- [ ] 主菜单在全通后显示额外入口按钮"🌌 全天星图"（仅全通后 visible）
- [ ] UX：成就页背景为深空渐变，全部30个星座图标在网格中有 hover 发光效果
