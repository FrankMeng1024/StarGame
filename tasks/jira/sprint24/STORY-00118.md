# STORY-00118: 首次启动开场动画

**Epic**: E-008 沉浸式体验升级
**Sprint**: Sprint 24
**Sprint Goal**: 为追星少女注入"活的星空"灵魂
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a first-time player, I want to see a short cinematic intro before the main menu, so that the game's theme and atmosphere are established before I start playing.

## Expected Result
首次访问（localStorage 中无 `starcatcher_intro_seen` 标记）时，进入主菜单前播放约12秒开场动画：Canvas 上一个网兜从右侧扫入，抓住一颗金色星星，接着4条连线依次亮起形成一个简单星座图（如猎户腰带三星+两侧），每条线亮起时播放一个音符。动画结束后淡出，进入正常主菜单。右上角始终显示"跳过 ›"按钮。

## Acceptance Criteria
- [ ] 仅在首次访问时播放（`localStorage.getItem('starcatcher_intro_seen')` 为 null）
- [ ] 动画完成或点击"跳过"后，设置 `localStorage.setItem('starcatcher_intro_seen', '1')`
- [ ] 动画时长约12秒，分3段：(1) 星空飘入背景星 2s, (2) 网兜从屏幕右侧扫入、接触星星、粒子爆发 4s, (3) 4条连线依次亮起（每条0.8s间隔）+ 标题渐显 6s
- [ ] 每条连线亮起时调用 `playRevealNote(idx, 4)`（复用现有音频函数）
- [ ] "跳过 ›"按钮始终可见（z-index 最高），点击立即跳到主菜单
- [ ] 动画使用独立 Canvas 或复用现有 star-canvas + overlay div，不污染游戏状态
- [ ] 动画结束后所有临时DOM元素清理干净，无残留事件监听
- [ ] localStorage 写入失败时静默处理（复用 Q5 的降级逻辑），失败后下次仍会播放动画（可接受）

## Dependencies
- 无硬依赖，可并行开发

## Notes
新建 `js/intro.js`，export `playIntro(): Promise<void>`。在 main.js `init()` 中，`state.load()` 后、`showScreen('menu')` 前，判断是否需要播放。网兜图形复用 engine.js 中现有的 `drawNet` 逻辑，或直接手写简化版（三角形网兜 + 绳子弧线）。
