# STORY-00047: 宇宙垃圾旋转动画修复

**Epic**: E-001
**Sprint**: Sprint 12
**Sprint Goal**: 游戏玩法体验修复
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want debris objects to visibly rotate/spin during gameplay, so that they look alive and dangerous rather than static.

## Expected Result
All 4 debris types (meteor, satellite, rocket, cloth) rotate continuously during gameplay with type-specific speeds and directions.

## Acceptance Criteria
- [ ] Meteor/asteroid: rotates at ~0.015 rad/frame (slow tumble)
- [ ] Satellite: rotates at ~0.02 rad/frame (medium spin)
- [ ] Rocket: rotates at ~0.01 rad/frame (slow rotation)
- [ ] Cloth/mylar: oscillates (uses Math.sin for flutter effect, amplitude 0.3 rad)
- [ ] Rotation is visually obvious in a screenshot taken after 2+ seconds of gameplay
- [ ] Caught debris stops rotating (it disappears anyway, but `caught` flag is the gate)
- [ ] Zero console errors

## Dependencies
- None

## Notes
Codebase analysis shows `d.angle` property exists and `d.spinSpeed` is incremented each frame (engine.js line 770: `d.angle += d.spinSpeed`). But `spinSpeed` may be initialized to 0 or very small values. Check engine.js debris constructor (~line 495) for `spinSpeed` initialization. If spinSpeed is non-zero but rotation not visible, the draw functions may not be using `ctx.translate/rotate` — check each of drawMeteor, drawSatellite, drawRocket, drawCloth. Fix whichever step is missing.
