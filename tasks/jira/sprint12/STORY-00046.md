# STORY-00046: 游戏内淡淡星座连线

**Epic**: E-001
**Sprint**: Sprint 12
**Sprint Goal**: 游戏玩法体验修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want to see faint constellation guide lines in the game canvas at all times, so that I can understand the constellation shape I'm building as I catch stars.

## Expected Result
Faint gold lines are always visible connecting the constellation's star positions. Lines slightly brighten as adjacent stars are caught. Player can see the full constellation shape without needing any item.

## Acceptance Criteria
- [ ] Constellation guide lines rendered at all times during gameplay (not gated behind star_map item)
- [ ] Line style: `rgba(255, 215, 0, 0.12)` gold, `lineWidth: 0.8`, no glow/shadow
- [ ] Lines drawn between star pairs per constellation's `lines` array (same data used by star_map)
- [ ] When both endpoints of a line are caught (dim dots), that line brightens to `rgba(255, 215, 0, 0.28)` 
- [ ] Lines drawn BEHIND stars (rendered before star objects in draw order)
- [ ] star_map item effect upgraded: instead of just showing lines (already always visible), star_map now shows star NAME labels next to each star for its duration
- [ ] Zero console errors after implementation

## Dependencies
- None

## Notes
engine.js `_drawStarMap()` currently only runs when star_map slot is active (line 905). Extract the line-drawing logic to a new `_drawConstellationGuide()` function that always runs. Move the star labels (text) to the star_map item activation only.
