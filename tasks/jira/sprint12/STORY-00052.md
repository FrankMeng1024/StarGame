## Description
As a player, I want to discover the background theme change naturally as I progress through levels, so that it feels like a pleasant surprise instead of a labeled transition.

## Expected Result
Scene dividers in the level select grid remain as visual separators but show no text (no location name, no aurora tag).

## Acceptance Criteria
- [ ] `.scene-divider` elements still present (preserve grid spacing function)
- [ ] No `.scene-divider-name` text visible (element removed or hidden)
- [ ] No `.scene-aurora-tag` visible (element removed or hidden)
- [ ] The colored dot (`.scene-divider-dot`) may remain or be replaced with a thin line separator — either is acceptable, as long as no text is shown
- [ ] Preferred: replace the divider with a simple thin horizontal rule (`border-top: 1px solid rgba(255,255,255,0.08)`) spanning full grid width, with 8px vertical padding — no dot, no text
- [ ] Zero console errors

## Dependencies
- None

## Notes
levels.js lines 18-27: the divider innerHTML includes `scene.name` text. Remove the name span. The aurora tag also reveals information about the scene — remove it too. The divider itself (as a grid layout element) should stay so the 30 cards don't reflow unexpectedly.
