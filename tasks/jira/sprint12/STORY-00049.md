# STORY-00049: 网兜形状升级

**Epic**: E-001
**Sprint**: Sprint 12
**Sprint Goal**: 游戏玩法体验修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the net to look like an actual butterfly/fishing net bag, so that the game's core visual metaphor is clear and satisfying.

## Expected Result
The net is a visible teardrop/bag shape with mesh lines inside. It opens wide when flying and closes as it retracts. Catching a star causes a brief visual bulge.

## Acceptance Criteria
- [ ] Net bag drawn as a teardrop/oval shape (not just a circle outline): wider at mouth (top), tapering to a point at bottom
- [ ] Mesh pattern inside: 4-5 horizontal arcs + 4-5 vertical lines creating a net grid effect
- [ ] Net mouth: a visible ring/hoop at the opening (thicker stroke, golden color)
- [ ] Colors: golden/amber frame (`#f0c040`), semi-transparent cream mesh fills (`rgba(255,240,180,0.25)`)
- [ ] When net is extending: bag shape is open wide (deformed toward travel direction)
- [ ] When net is retracting: bag shape contracts slightly
- [ ] Rope from pole tip to net mouth: visible, slightly curved
- [ ] Net visually readable at 18-24px radius (current size) — enough detail to be recognizable
- [ ] Zero console errors

## Dependencies
- None

## Notes
Currently `_drawNet()` draws a circle with 4 cross lines (18px radius). Replace with a proper bag shape: draw a teardrop path using bezier curves, add horizontal arc lines inside at equal intervals, draw vertical center line. The mouth ring should be thicker (`lineWidth: 2`). When `netState === 'returning'` and a star was caught, briefly inflate the bag width by 20%.
