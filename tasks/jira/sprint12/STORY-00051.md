# STORY-00051: 通关界面重设计

**Epic**: E-007
**Sprint**: Sprint 12
**Sprint Goal**: 游戏玩法体验修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the level-complete screen to feel like an "unlock card" where the constellation story and photo are the focus, not the game stats, so that the educational reward feels meaningful.

## Expected Result
Complete screen: single-line compact header → photo highlight → lore text (dominant) → compact stats → CTA shop button. Everything fits in 100vh.

## Acceptance Criteria
- [ ] Top header: single compact row — "★★★ 关卡完成！" (or star count + title), max 52px height total including margin
- [ ] Stats row: coins + time + caught in ONE horizontal row below header, small text (14px), max 36px height
- [ ] Photo: one astrophoto from constellation's photo array shown below stats, `max-height: 180px`, `border-radius: 12px`, object-fit:cover — if no photo available, show small SVG star icon placeholder (not blank)
- [ ] Lore text: dominant section, min 40% of remaining screen height, `font-size: 15px`, styled scrollable container (custom scrollbar)
- [ ] Constellation portrait canvas removed or reduced to max 100×100px (tucked beside the title row)
- [ ] "去商店 →" button: prominent CTA at bottom, `min-height: 52px`, gradient fill, full width minus padding
- [ ] "下一关" and "返回选关" as secondary smaller buttons below the shop CTA
- [ ] Entire screen fits 100vh without any external scroll
- [ ] New record badge (if applicable) shown inline within the title row, not as a separate large element
- [ ] Zero console errors

## Dependencies
- None

## Notes
complete.js currently has a large constellation canvas animation (160×160) and prominent title section. The canvas animation can be reduced to 80×80 and shown inline in the header row. The lore section needs more vertical space — this means the upper elements must be compressed. Photo: use `CONSTELLATION_PHOTOS[con.nameEn]?.[0]` to get the first photo URL; if undefined, show a star placeholder.
