# STORY-00050: 游戏内暂停/重试/退出

**Epic**: E-001
**Sprint**: Sprint 12
**Sprint Goal**: 游戏玩法体验修复
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want to be able to pause, retry, and exit during a game session, so that I have control over my gameplay experience.

## Expected Result
A pause button is visible in the HUD. Pressing it or Escape shows a pause overlay with Retry and Exit options. The game loop is frozen during pause.

## Acceptance Criteria
- [ ] Small pause button (⏸ icon, ~32px, semi-transparent) visible in HUD corner (top-right, not overlapping ring timer or slot buttons)
- [ ] Pressing ⏸ button OR Escape key opens pause overlay
- [ ] Pause overlay: semi-transparent dark overlay covering canvas, "游戏暂停" title, two buttons: "重新开始" and "返回关卡"
- [ ] Game loop is suspended while paused (timer stops counting, net stops swinging, objects freeze)
- [ ] "重新开始" button: restarts the current level from scratch (same as re-navigating to game with same level index)
- [ ] "返回关卡" button: shows inline confirmation "确认退出?" with Yes (✓) and No (✗) buttons — NO browser confirm() dialog
- [ ] Confirming exit navigates to levels screen
- [ ] Pressing Escape while paused resumes game (second Escape = resume)
- [ ] Pause button changes to ▶ icon when paused
- [ ] All pause/overlay UI styled consistently with game HUD (dark glass, rounded, gradient buttons)
- [ ] Zero console errors

## Dependencies
- None

## Notes
The game loop in engine.js uses `requestAnimationFrame` (RAF). Pause = set a `this._paused = true` flag; in `_loop()`, if `_paused` return early (skip RAF reschedule). Resume = set `_paused = false`, reset `lastTick = performance.now()`, restart RAF. The pause button and overlay should be in the HTML (inside `#screen-game`) not drawn on canvas. game.js or a new pause.js module handles the overlay and button events.
