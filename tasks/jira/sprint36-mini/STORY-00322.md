## Description
As a player, I want the victory/fail screen to be clean, well-organized, with no overlapping buttons and a readable layout.

## Expected Result
Victory card: compact single-line title, stats row, photo area, story text, 3 non-overlapping buttons. Fail card: title + stats + 2 buttons. All content within screen bounds.

- [ ] 标题区(32px)：胜利="✦ 关卡完成！"，失败="⏰ 时间到了！"，22px，一行显示

- [ ] 故事区：高度自适应，Canvas clip截断，底部渐隐
- [ ] 按钮区(52px)：胜利3按钮（下一关/重玩/选关），失败2按钮（重试/选关），均匀分布，高度36px
- [ ] 所有按钮文字14px，不超出边界
