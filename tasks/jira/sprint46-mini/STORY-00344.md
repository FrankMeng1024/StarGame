# STORY-00344: 三星评级机制改为捕获率

**Epic**: Game Mechanics
**Sprint**: Sprint 46-mini
**Sprint Goal**: 选关界面视觉全面升级
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want star ratings to reflect how many stars I caught, not how much time was left, so 3-stars feels earned by skill rather than luck of timing.

## Expected Result
Victory star rating based on catch ratio: 3★ = ≥90% caught, 2★ = ≥60%, 1★ = <60%.

## Acceptance Criteria
- [ ] `_triggerResult()` in game.js computes stars from `caught/total` ratio, not from coins/timeLeft
- [ ] 3★ threshold: catchRate >= 0.90
- [ ] 2★ threshold: catchRate >= 0.60
- [ ] 1★: below 0.60 (but still victory)
- [ ] coins calculation unchanged (still used for shop)
- [ ] Code comment explains the new formula

## Dependencies
None

## Notes
Old: `coins = floor(timeLeft)*10; stars = coins>=300?3 : coins>=100?2 : 1`
New: `catchRate = caught/total; stars = catchRate>=0.90?3 : catchRate>=0.60?2 : 1`
Edge case: total=0 → stars=1 (avoid divide-by-zero).
