# STORY-00343: 选关卡片重设计 — 更大更清晰

**Epic**: Visual Polish
**Sprint**: Sprint 46-mini
**Sprint Goal**: 选关界面视觉全面升级
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want level select cards to be larger and more readable, with clear constellation icons and star ratings, so I can easily identify and choose levels.

## Expected Result
Landscape 4-column grid with tall cards (~197×246px). Emoji icon large and centered. Star rating shown centered at card bottom (★★★ or ☆☆☆). No time display. Difficulty bar retained.

## Acceptance Criteria
- [ ] Landscape: 4 columns (was 6). Portrait: 3 columns (was 5)
- [ ] Cards non-square: height = width × 1.25
- [ ] No time display (⏱ row removed entirely)
- [ ] Star rating: centered bottom row, shows ☆☆☆ for unplayed, ★★★ for 3-star
- [ ] Star character font size: ~18% of card width
- [ ] Emoji icon font size: ~35% of card width
- [ ] Difficulty color bar retained (5px thick)
- [ ] Screenshot visually cleaner than before

## Dependencies
None
