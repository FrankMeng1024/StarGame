## Description

## Acceptance Criteria

- [ ] Title style (gold color, glow) matches main menu title aesthetic
- [ ] menu.js font loading block has comment: `// ⛔ 禁止修改：字体风格已定稿，与开场动画一致`
- [ ] intro.js font loading block has same comment
- [ ] Screenshot shows visually consistent font across menu and level select
