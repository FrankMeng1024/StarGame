# STORY-00355: 星座居中显示 + 关卡时间合理性修复

**Epic**: Bug Fix
**Sprint**: Sprint 53-mini
**Sprint Goal**: 星座居中 + 关卡时间合理性
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want constellation stars to be centered in the play area, not offset to corners.

## Acceptance Criteria
- [ ] All 30 constellations have their centroid mapped to sky area center (0.5, 0.5)
- [ ] No star appears at the edge of the play area when centroid is off-center
- [ ] Level 26 (14 stars) gets adequate time: base 50s + 7×5s bonus = 85s
- [ ] Level 28 (11 stars) gets adequate time: base 50s + 4×5s bonus = 70s
- [ ] All levels: seconds-per-star ≥ 5.0s for playability

## Notes
- Root cause: `_initStars` used `s.x * (skyX1-skyX0)` directly without centering
- Fix: compute centroid of all star normalized coords, shift so centroid → (0.5, 0.5)
- Applied `Math.max(0.05, Math.min(0.95, ...))` clamp to prevent off-screen placement
- Timing formula: `baseTime + Math.max(0, (starCount - 7) * 5)` seconds bonus per extra star beyond 7
