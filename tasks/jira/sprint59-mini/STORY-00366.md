# STORY-00366: 障碍物驱动游戏难度系统重构

**Epic**: Gameplay Depth
**Sprint**: Sprint 59-mini
**Sprint Goal**: 障碍物驱动游戏难度 + 深空风格通关/失败UI
**Points**: 8
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a player, I want the game difficulty to come from obstacles and spatial challenges rather than just shorter timers, so the game feels progressively deeper and more strategic.

## Expected Result
难度随关卡提升体现在障碍物种类和数量上，时间保持相对宽松，玩家通过技巧绕避而非赶时间。

## Acceptance Criteria
- [ ] 新增"磁场干扰区"障碍（半透明紫色圆形，网兜进入时角度偏转±15°~30°）
- [ ] 新增"碎片云"障碍（3颗小碎片漂移聚集，触碰网兜重置网兜）
- [ ] 难度分级：1级0障碍120s / 2级1-2障碍100s / 3级2-3障碍90s / 4级3-4障碍+碎片云80s / 5级4-5障碍+多碎片云70s
- [ ] 障碍物不出现在初始星星位置上（最小间距50px）
- [ ] 磁场干扰区有视觉提示（半透明紫色渐变 + 旋转虚线边框动画）
- [ ] 截图：3级以上关卡运行截图，可见障碍物与星星共存

## Dependencies
无（game.js已有障碍物系统基础）

## Notes
需在game.js中读取constellation难度等级并据此生成障碍物。磁场偏转在_updateNetHead()中实现。
