# STORY-00223: 展厅详情prev/next手势 + 商店返回levels一致性验证

**Epic**: E-006 星座展厅
**Sprint**: Sprint 5-mini
**Sprint Goal**: 道具效果生效 + 关卡体验完整化
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the gallery detail navigation to be smooth and consistent so that browsing constellations feels natural.

## Expected Result
Gallery detail prev/next buttons work correctly between unlocked constellations only (skipping locked ones). Shop and gallery 返回 button correctly goes to levels screen.

## Acceptance Criteria
- [x] Gallery detail "上一个" button skips locked constellations (jumps to previous unlocked idx)
- [x] Gallery detail "下一个" button skips locked constellations (jumps to next unlocked idx)
- [x] If no unlocked constellation in direction, button is hidden (verified and corrected from simple idx check to unlocked check)
- [x] Tapping detail 返回 → goes to levels (via gallery list — confirmed correct)
- [x] Tapping shop 返回 → goes to levels (confirmed)

## Dependencies
- Depends on: STORY-00217 (gallery — Done)
- Depends on: STORY-00218 (shop — Done)

## Notes
Sprint 4-mini gallery detail prev/next navigates by index without checking unlocked state. On a fresh save (only idx 0 unlocked), _detailPrevRect would still show/hide correctly (idx=0 → no prev button), but _detailNextRect would show "下一个" to idx 1 which is locked — showing a mostly-empty locked detail view. This may be intended (locked constellation shows "🔒 完成关卡后解锁") but should be verified as acceptable UX.
This story is a 1-point verification/minor polish story bundled with STORY-00222.
