# STORY-00222: 帧率无关性补完 — 剩余3个帧计数改为dt

**Epic**: E-004 技术质量
**Sprint**: Sprint 5-mini
**Sprint Goal**: 道具效果生效 + 关卡体验完整化
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a developer, I want all game physics and timers to be frame-rate independent so that the game feels consistent on both 30fps and 60fps devices.

## Expected Result
The three remaining frame-count-based systems in game.js are converted to dt-based updates.

## Acceptance Criteria
- [x] _timerFlash: convert from frame count to time-based (dt seconds) — `_timerFlash -= dt; if (_timerFlash < 0) _timerFlash = 0`
- [x] _updateParticles: particle lifetime decremented by dt not by 1 — `p.life -= dt * 60` to maintain same visual duration
- [x] debris spin: `d.angle += d.spin * scale` where `scale = dt * 60` (already pattern for other physics in game.js)
- [x] No console errors
- [x] Visual: particles and debris behave the same at 60fps as before

## Dependencies
- None (Arch Medium backlog item)

## Notes
Arch identified these 3 remaining frame-count systems in Sprint 3-mini review. The pattern `scale = dt * 60` is already used for swing and net speed. Particles: currently `p.life -= 1` should become `p.life -= dt * 60`. Timer flash: currently counting frames, should count seconds.
