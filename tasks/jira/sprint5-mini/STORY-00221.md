# STORY-00221: 道具效果生效 — 6种道具在游戏中实际起作用

**Epic**: E-003 道具系统
**Sprint**: Sprint 5-mini
**Sprint Goal**: 道具效果生效 + 关卡体验完整化
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the items I purchased in the shop to actually work in the game so that buying items is meaningful.

## Expected Result
Before entering a level, player is prompted to select items from inventory. Selected items apply their effect during the level. Each item has a visible effect.

## Acceptance Criteria
- [x] Item selection overlay shown before game starts (after tapping a level card): shows owned items with "使用" toggle
- [x] state.selectedItems populated with toggled items
- [x] speed (网兜加速): NET_SPEED multiplier ×1.5 when item active
- [x] enlarge (网兜扩大): net head radius ×1.5 when item active (visual + collision)
- [x] bomb (宇宙炸弹): tap during game clears all debris once; button visible in HUD when active; explosion particle feedback
- [x] time_ext (时间延长): +15 seconds added to initial timer
- [x] shrink (缩小垃圾): debris radius ×0.5 when item active
- [x] double_coins (双倍金币): coins calculation ×2 at settlement; "×2" annotation shown on result card
- [x] Item consumed (state.useItem) after level ends (win OR lose) if it was selected; state.selectedItems cleared
- [x] If no items in inventory, skip selection overlay and go directly to game
- [x] No console errors on item selection or effect application

## Dependencies
- Depends on: STORY-00218 (shop — Done)

## Notes
Item selection overlay is Canvas-drawn (same style as other overlays). state.selectedItems is an array of item IDs. Effects applied at showGame() start by reading state.selectedItems. After result, game.js calls state.useItem(id) for each selected item.
The web version (js/screens/game.js) has item effects already implemented — reference for effect magnitudes.
