# STORY-00257: 网兜全面重绘 — 真实网袋形状 + 弧光尾迹

**Epic**: Mini 视觉精品化

**Points**: 3
**Owner**: Frontend Dev

## Description
As a player, I want to see a real butterfly/fishing net bag shape that extends and retracts with a glowing arc trail, so that throwing the net feels magical and satisfying.

## Expected Result
Net displays as a triangular mesh bag (not a dot). When launched, a glowing trail follows the rope head. Catching a star briefly flashes the net gold.

## Acceptance Criteria
- [ ] Net bag shape visible during extension: bezier bag outline with mesh cross-lines inside
- [ ] Mouth ring (ellipse) at bag opening, color #ffd700, shadowBlur 6
- [ ] Stub state (swinging): compact closed bag visible even when not launched
- [ ] Arc trail: 8-10 fading white circles behind rope head during extension
- [ ] Catch flash: 2-3 frames of bright gold overlay on bag after catching a star
- [ ] Rope color: warm brown #c8874a; mesh lines: rgba(255,215,100,0.55)
- [ ] Net collision detection unchanged — _netHeadX/_netHeadY still accurate

## Dependencies
None
