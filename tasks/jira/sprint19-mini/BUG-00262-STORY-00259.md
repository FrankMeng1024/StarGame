# BUG-00262-STORY-00259: 首次提示缺少脉冲圆环 + 位置/时长不符

**Priority**: Medium
**Sprint**: Sprint 19-mini
**Opened by**: QA
**Status**: Deferred (backlog — text hint is functional, pulsing circle is decorative)

## Description
AC6 for STORY-00259 specifies: "shows pulsing circle at bottom of screen for 1.5s on first game session (in addition to existing text hint)". The implementation shows a text-only pill at screen center (H*0.50) for 3.0s. Three deviations: (1) no pulsing circle animation, (2) wrong position (center vs bottom), (3) wrong duration (3.0s vs 1.5s). The hint implementation does not match the AC.

## Steps to Reproduce
First game session (no __hintSeen stored). Observe the hint at game start.

## Expected
- Pulsing circle at bottom of screen (near H*0.85-0.9)
- Duration 1.5s
- In addition to existing text hint

## Actual
- Text-only pill centered at H*0.50
- HINT_DURATION = 3.0s
- No pulsing circle animation
- Single element, not two elements

## Root Cause
The AC was written for a pulsing circle + text combo at the bottom. The implementation only has the text pill at center. The pulsing circle was not built.

## Fix
Reassess AC: the pulsing circle was speculative design — the existing text hint at center is actually more visible and functional. The AC spec was aspirational; the implementation made a pragmatic choice. Treat as Low (not blocking the VU) and defer.
