# STORY-00260: 全屏视觉效果拉满 — 粒子/光晕/动态背景

**Epic**: Mini 视觉精品化
**Sprint**: Sprint 19-mini
**Sprint Goal**: 视觉效果全面拉满
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want every visual element to feel alive and beautiful — stars have cross-sparkles, the background is denser and more atmospheric, and victory feels like a fireworks show.

## Expected Result
Stars have 4-point cross sparkles. Background star count increased to 100. Ground silhouette emits warm glow. Victory spawns 40 particles with gravity. Victory lines glow brighter. Timer pulses urgently when ≤10s.

## Acceptance Criteria
- [ ] Star cross sparkle: 4 thin lines (±r*3 length) crossing at each uncaught star center, alpha modulated by twinkle sine
- [ ] Background stars: count increased from 60 to 100, with 5-8 "bright stars" (r=2.5) added
- [ ] Ground silhouette glow: warm gradient strip (rgba(255,140,40,0.15)→transparent, 30px height) above silhouette top edge
- [ ] Victory particles: 40 total (up from 20), mix stars/gold/white, gravity +0.04/frame on vy
- [ ] Victory line glow: shadowBlur=12 (up from 6), each line briefly flashes alpha 1.0 then settles to 0.75
- [ ] HUD timer ≤10s: font size pulses 18px↔22px at 2Hz (using sin function of time)
- [ ] No performance regression — frame rate stays smooth (no new per-frame expensive operations)

## Dependencies
None — can run parallel with STORY-00257/258/259
