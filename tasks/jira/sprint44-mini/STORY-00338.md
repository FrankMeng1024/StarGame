## Description
As a player, I want the main menu title "追星少女" to use the same calligraphy font as the opening animation, so the transition from intro to menu feels visually cohesive.

## Expected Result
Main menu title "追星少女" renders in Ma Shan Zheng calligraphy font (or serif fallback), color `#e8d5ff`, shadow `#b090ff`, matching the intro Phase 3 style exactly. No more gold gradient sans-serif title.

## Acceptance Criteria
- [ ] `wx.loadFontFace()` called in `showMenu()` with Ma Shan Zheng CDN URL, same defensive try/catch as intro.js
- [ ] Menu title font: `bold ${size}px 'Ma Shan Zheng', serif` (not sans-serif)
- [ ] Title text: `'追星少女'` tight (no spaces), color `#e8d5ff`
- [ ] Title shadow: `shadowColor='#b090ff'`, `shadowBlur=18`
- [ ] Font size responsive: portrait `≈H*0.045`, landscape `≈H*0.052`
- [ ] Subtitle "探索88星座的奇妙旅程" unchanged (sans-serif ok for functional subtitle)
- [ ] Screenshot shows calligraphic title consistent with intro Phase 3 style

## Dependencies
None — isolated to menu.js title rendering + font loading
