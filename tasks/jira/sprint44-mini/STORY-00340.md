## Description
As a player, I want the main menu background starfield to have the same natural, varied quality as the opening animation — dense, multi-sized stars with no diagonal patterns.

## Expected Result
Background starfield: 168 stars (105 tiny r=0.4-0.7 + 45 medium r=1.0-1.5 + 18 large r=1.8-2.6), sin-hash coordinates, unique per session. No diagonal streaks. Each size tier has independent twinkle phase.

## Acceptance Criteria
- [ ] `initBgStars()` in canvas-utils.js uses sin-hash function for x/y coordinates (same formula as intro.js)
- [ ] Total count: 168 stars (105+45+18)
- [ ] 3 size tiers with distinct radius ranges: tiny 0.4-0.7, medium 1.0-1.5, large 1.8-2.6
- [ ] Each tier uses different seed offsets so no position pattern overlap
- [ ] Seed base includes `Date.now()` component so each `initBgStars()` call produces different layout
- [ ] Screenshot shows no visible diagonal streak or grid
- [ ] Large stars retain soft glow (shadowBlur) from current implementation

## Dependencies
None — isolated to canvas-utils.js `initBgStars()`

## Notes
The hash function used in intro.js: `function _h(n) { return Math.abs((Math.sin(n * 127.1 + 311.7) * 43758.5453) % 1); }`
Add a seed parameter to initBgStars: `initBgStars(w, h, seed=0)` where seed=Date.now()%10000.
Tiny: seeds i+seed, i+1000+seed, i+2000+seed, i+3000+seed, i+4000+seed, i+5000+seed
Medium: seeds i+200+seed ... Large: seeds i+400+seed ...
