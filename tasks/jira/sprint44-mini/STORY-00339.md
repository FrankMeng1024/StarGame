## Description
As a player, I want to see a different constellation every time I enter the main menu, with stars appearing one by one, so the menu feels alive and surprising.

## Expected Result
Each `showMenu()` call picks a random constellation (different from the previous one). Stars appear one-by-one with a 0.12s stagger and brief pulse animation on reveal. Lines draw only after both endpoint stars are visible.

## Acceptance Criteria
- [ ] `_pickCon()` uses `Math.random()` instead of `dayOfYear % length`
- [ ] Consecutive duplicate avoided: if same index as previous, +1 mod length
- [ ] Each star has `revealTime = i * 0.12s` starting from menu open
- [ ] Stars hidden until `elapsed >= revealTime`; at reveal, scale pulses 1.0 → 1.4 → 1.0 over 0.3s
- [ ] Constellation lines only drawn after both endpoint stars revealed (same logic as intro.js Phase 2)
- [ ] `_menuStartTime` tracked in module state, reset on each `showMenu()` call
- [ ] Two consecutive menu visits (navigate away and back) show different constellations
