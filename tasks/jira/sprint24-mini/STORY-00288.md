# STORY-00288: 关卡选择卡片缩小

**Epic**: 用户体验修复
**Sprint**: Sprint 24-mini
**Sprint Goal**: 用户反馈8项修复
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player, I want the level select cards to be smaller and more refined, showing more levels at once and feeling less blocky.

## Expected Result
In landscape mode, 6 cards per row (was 5), each card ~96px. Constellation identifier uses text abbreviation not emoji. Overall layout feels like a refined grid.

## Acceptance Criteria
- [ ] COLS = 6 in landscape mode (was 5 after STORY-00281 change)
- [ ] Name text font size = max(7, min(9, w*0.14)) (was max(8, min(10, w*0.16)))
- [ ] Constellation icon: first 2 characters of nameZh (e.g. "白羊" from "白羊座") in small font — no emoji
- [ ] Level number position: y + h*0.45 when icon shown, y + h*0.40 when no icon
- [ ] Name position: y + h*0.70 (was h*0.72)

## Dependencies
None

## Notes
The emoji icon (c.icon field) renders differently across WeChat versions. Text abbreviation is more reliable and looks cleaner.
