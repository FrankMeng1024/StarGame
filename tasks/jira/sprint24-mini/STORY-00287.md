## Description
As a player, I want the menu buttons to be smaller and more elegant, not obscuring the constellation background.

- [ ] Portrait mode BH = 36 (was 40), fontSize = 15px
- [ ] rightW = W - rightX - (G.SAFE_RIGHT || 0) - 16 (was -20, slight improvement)
- [ ] No buttons overlap each other or the title text at W=667, H=375
