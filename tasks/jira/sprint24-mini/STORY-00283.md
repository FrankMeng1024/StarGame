# STORY-00283: 登录动画首帧可见修复

**Epic**: 用户体验修复
**Sprint**: Sprint 24-mini
**Sprint Goal**: 用户反馈8项修复
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a player launching the game, I want to see the meteor shower animation immediately from the first frame, so the opening experience feels cinematic and not broken.

## Expected Result
Opening the game shows visible falling meteors within 0.5 seconds of launch. The intro animation is clearly visible and engaging.

## Acceptance Criteria
- [ ] At least 4 meteors are pre-spawned with born=0 so they appear from frame 1
- [ ] Meteor alpha minimum raised to 0.85 (no more dim meteors)
- [ ] trailFactor increased to 0.28 for longer, more visible trails
- [ ] Constellation reveal starts at t=2s (was t=3s)
- [ ] Skip hint "✦ 轻触跳过" visible from frame 1 (not after 1s delay)

## Dependencies
None

## Notes
Root issue: initial meteors had staggered born times (0-12000ms) making the first 2s appear empty.
