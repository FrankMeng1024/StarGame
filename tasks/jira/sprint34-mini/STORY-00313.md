# STORY-00313: 主菜单视觉对标 — 按钮深色pill样式+星座居中

**Epic**: E-033 跨平台对标
**Sprint**: Sprint 34-mini
**Sprint Goal**: 补全证据缺口 + 主菜单视觉对标
**Points**: 2
**Owner**: Frontend Dev

## Description
As a player, I want the mini-game main menu to visually match the web version, so both platforms feel like the same polished product.

## Expected Result
Mini main menu buttons use the same dark semi-transparent pill style as the web version. The visual distinction between mini's bright purple and web's dark style is eliminated.

## Acceptance Criteria
- [ ] Main menu buttons (挑战关卡/星座图鉴/道具商店) use dark semi-transparent fill (matching web's dark pill style) instead of bright solid purple
- [ ] Primary button (挑战关卡) has a subtle gradient highlight to distinguish it as the CTA
- [ ] Button text remains white and legible against the dark fill
- [ ] Layout and spacing unchanged — only fill color/style changes
- [ ] Screenshot confirms visual parity with web menu button style

## Dependencies
- None
